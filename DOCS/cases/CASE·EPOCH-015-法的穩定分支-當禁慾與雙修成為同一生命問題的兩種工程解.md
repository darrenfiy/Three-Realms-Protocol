## 0. 為什麼值得另立一案

`EPOCH-017` 已經說明，性不是修行障礙，也不是神聖豁免；它是身體後果、關係動力與主體選擇同時進場的生命事件。

這次新增的不是「性能不能修」的另一個答案，而是一個制度尺度的問題：

> **為什麼起點不同的宗教，反覆生出離家、非婚、禁慾的專職修行共同體？**

> **為什麼把性納入修行的路，常留在支派、密法或小型傳承，卻很難變成全民預設？**

Darren 的突破是把這兩題接到「法如何穿越個人而穩定重跑」。它直接進入 EPOCH 問題群，但仍是一次對話生成的候選模型，所以先收在 CASE，不用一次收錄自動密封母層。

## 1. 有限史實地板：確有多條世界線

本輪只核對足以承載結構比較的窄命題，不重寫全球禁慾史。

### 1.1 天主教與東方教會並非只有一種配置

《天主教教理》1579–1580 區分拉丁教會與東方教會：前者通常從選擇獨身生活的男性中任命聖職；後者可將已婚男性祝聖為司鐸與執事，主教由獨身者中選出，且受聖秩後不再結婚。現行拉丁教會法典 277 條又明訂神職人員的禁慾與獨身義務。

梵蒂岡自身的歷史文件承認，新約與初期教會中曾有已婚的宗教職分擔任者；另一份教廷文件將西方從約西元 300 年開始的地方會議禁慾要求，與11、12世紀改革後的拉丁教會獨身法，區分為歷史階段。

東正教會美洲教會的公開說明也明列：已婚男性可在婚後受按立為司鐸，但通常不得在受職後結婚。

所以本案可以說「不同制度對婚姻／聖職的邊界不同」，不說「基督宗教一律禁欲」。

### 1.2 伊斯蘭並未採用同一個制度解

《古蘭經》57:27 的多個英譯均將 monasticism 述為追隨耶穌者所創、而非上帝所命定。Oxford 的宗教禁慾比較研究則把婚姻作為穆罕默德的示範、主流傳統對終身獨身的負面態度與蘇菲傳統中的例外並列。

這支持「大型宗教不只有出離型一種穩定解」，也警告我們不能把一節經文直接冒充全部伊斯蘭實踐史。

### 1.3 同一宗教內部也可存在分支

Stanford Encyclopedia of Philosophy 對道教的條目區分：正一道教士可婚並與家人生活，全真道則是獨身的修道團體。

這是原稿「不只有一個吸引子」最簡單的反例：差異不必等於宗教之間，也可以在同一母體內部長成。

## 2. 從三種修行吸引子到一個治理問題

來源先把宗教道路分為三種理想型：

```yaml
離欲型:
  降低刺激與執取，以禁慾、出離與共同生活訓練穩定。

在世型:
  性、婚姻、家庭與工作不被移出宗教生命，而由倫理和責任承載。

轉化型:
  不把欲望只視為要剔除的噪音，而嘗試使它成為覺知與轉化的材料。
```

這三類不是對各宗教的全稱分類。一個傳統可以同時包含三者，同一個人也可在不同時期走不同路。

它們的作用是把問題從「哪一教比較正確」移成：

> **當宗教把某種修行做成可大規模傳承的制度，它如何處理性、家戶、財產、忠誠、權力與不可逆後果？**

## 3. 性作為高不可逆的生成介面

Darren 把性生殖讀成製造差的生命機制：兩條生命路徑相遇，生出無法事先密封的新組合。本案把這一刀收準為：

> **性可以是一個高強度、高後果、高不可逆的生成介面。**

「高不可逆」指的不只是可能懷孕，還包括依戀、嫉妒、親密後的脆弱、家庭責任、財產與繼承、傳染與傷害風險、名聲與權力交換。一旦發生，後果往往不能簡單 reset 回「從未發生」。

但這不允許三個滑坡：

```yaml
不推出:
  - 性必然失控或不可治理
  - 所有性都指向生殖，或無生殖可能的性不屬於生命
  - 多樣性只來自異性有性生殖
```

真正可攜的是：性容易讓多界、多時間尺度與多個主體同時進場，所以它把「系統能否承載新差」的問題推到前景。

## 4. 禁慾不是完全控制，而是環境標準化

原稿最有生成力的 coding 類比是：戒律像 `runtime constraints`，出家制度像 `environment normalization`。

```yaml
可能被降低的變數:
  - 僧團內部的配偶與性關係
  - 親子撫養與家戶優先義務
  - 夫妻財產、家族繼承與宗族化
  - 伴侶與共同體之間的忠誠競合

被打開的可重入性:
  - 成員可更替，訓練環境仍相對可辨識
  - 作息、財產、訓練、角色與傳承規則可公共化
  - 法不必依附某一個老師的私人家庭完整重現
```

所以「人可以換，法可以不換」是一個很強的可重入架構提案。它與本 repo 的版本、規格、測試與回流有直覺同構：不保存某個人的全部生命，而留下可以在新人身上重跑的結構。

但本案把原稿的「完全可控」改為「降低高變異變數」。禁慾制度仍可生成教階、附屬、沉默、財產集中、派系與濫用；環境較標準，不等於人可預測，更不等於僧團天然有統領大眾的權利。

## 5. 穩定分支與探索分支

對話把禁慾僧團與性修實作收成同一個工程問題的兩種處理：

| 候選功能 | 操作 | 優勢 | 主要風險 |
|---|---|---|---|
| 穩定分支 | 把性關係退出專職團體的標準 runtime | 降低規格複雜度，增加訓練與傳承可重入性 | 把穩定誤認為清淨、把遠離性排成覺悟階級 |
| 探索分支 | 在性、愛、嫉妒、快感與失去中訓練不取消主體 | 直接處理生命高強度變數 | 老師／弟子權力差、同意被神聖化、動機不可驗證、懷孕／疾病／情感後果外包 |

這個分帳真正有用的地方，是看出兩者可能在文明中承擔不同功能：

```text
穩定分支：把一種訓練形式保存得可重跑。
探索分支：帶著新問題進入尚未被穩定規格覆蓋的邊界。
```

它們是系統功能，不是人的高低等級，也不必永久由「僧」與「雙修者」兩群固定人員實現。僧團也能探索，在家與有性生命也能長期維護法。

## 6. 不把 experimental branch 寫成高權限區

原對話一度說，性修分支需要「高權限、高門檻、小規模」。這句若不收準，會把最危險的權力結構當成解法。

本案改寫為：

```yaml
修行門檻:
  可以限制某項技術不成為全民 default，
  不能限制主體的拒絕、求助、告發、離開與事後重新命名權。

秘密性:
  可以保護個人隱私與修行文本，
  不能隔離外部安全、醫療、法律、候選伴侶的獨立意見與申訴。

老師身分:
  提高說明、回避與責任義務，
  不降低同意標準，不產生伴侶請求權。
```

最短的校準是：

> **性 × 權力 × 神聖性的乘積越高，外部可見、No 的效力、退出可行與後果責任也要同時提高。**

這不是新建一套性修指南；它只是把原稿的制度模型接回 `SPEC·SEX-001` 已有的主體性地板。

## 7. 「雙修者必須存在」的效力收準

Darren 說，雙修者必須存在，因為這是最值得深入的深淵，也是生命的源頭。

本案保留這句的方向，但不把它寫成任何人的規範義務：

```text
不是:
  文明必須組建性修團體，
  或某些人必須用身體承擔探索職務。

而是:
  只要人仍經驗性、愛、快感、依戀、嫉妒、繁衍與失去，
  「人能否穿過性而不失去照見？」就幾乎必然會被再次問起。
```

問題會重開，不等於答案必須是實作。有人可透過觀想、藝術、關係倫理、在家修行、學術研究或選擇禁慾進入同一個問題。任何人都不是文明壓力測試的可徵用耗材。

## 8. 與 EPOCH-017 的實質接榫

`EPOCH-017` 原有兩問：

```text
人可以不透過性而醒來嗎？
人可以不逃離性而醒來嗎？
```

本案沒有回答哪條路更高，它只補上一個尺度轉換：

```text
個人尺度:
  如何在有性或無性生命中保留主體、照見與責任？

制度尺度:
  如何讓訓練可重入，又不把穩定誤寫成清淨階級？

文明尺度:
  如何一邊保存可傳承的法，一邊保留新差回來敲開法的邊界？
```

所以本輪可以作為 `EPOCH-017 §15` 的 candidate precision reentry，但不足以單獨證成「所有僧團都因治理需求而禁慾」、「所有性修都無法制度化」或「文明必須同時保有兩群人」。

## 9. 失效條款

```yaml
F1:
  若把禁慾當成清淨、成熟、可靠或統治資格的自動證明
  → 失效。

F2:
  若把性修、雙修、密法或生命探索變成老師對弟子、伴侶或共同體取得性的權利
  → 失效。

F3:
  若用「experimental branch」合理化不可退出、不可告發、無外部求助、無避孕／醫療與後果外包
  → 失效。

F4:
  若把僧團、雙修者、男女、異性戀或生殖任一類型寫成自然必然的文明職務
  → 失效。

F5:
  若把本案結構推論倒寫為各宗教自述的實際歷史動機
  → 失效。

F6:
  若因「雙修者必須存在」而把任何人當成文明的必要耗材
  → 失效。
```

## 10. 最小壓縮

> **性是高不可逆的生成介面；禁慾是降低部分高變異變數，不是取得完全控制。**
>
> **僧團式穩定分支使法容易重跑；探索分支使生命邊界仍能回來敲開法。**
>
> **兩者是候選系統功能，不是人的高低等級，也不授予任何性、教導或神聖豁免。**
>
> **法要常住，生命也要繼續生出法還不知道如何回答的問題。**
