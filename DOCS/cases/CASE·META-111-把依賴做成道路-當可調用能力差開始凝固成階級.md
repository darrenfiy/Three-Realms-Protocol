## 0. 判定：收，而且不是因為它替資本主義下了結論

這段值得留下，不是因為「資本需要階級」已經被證明，也不是因為它替平等、財富或市場找到最後答案。

真正跨過驚訝門檻的是，它讓四條已經存在的路第一次在同一個政治經濟學尺度相接：

```text
差（EPOCH-014）
  → 某些能力對某些位置可調用
  → 反覆調用使路徑養厚（EPOCH-I-002）
  → 厚路徑降低下一次取得資源與行動的阻抗
  → 路徑可以繼續開放，也可以封閉成特權
  → 可改寫他人路徑時進入操作、權限與責任（EPOCH-IV-001）
```

來源最後問：已有別人沒有的路，要做成城牆還是道路？

這不是對財富作善惡判決，而是把所有、使用、進入、替代、退出與回流拆成可治理的問題。

## 1. 依賴不是一條軸：支撐與拘束必須分帳

來源的第一刀成立：文明力量很大一部分不是孤立個體的內建能力，而是能否調用外部累積。

一個人能使用電網、電腦、道路、法律、醫療、金融、搜尋、模型與他人專業，確實比只能以自身肉體處理同一任務，多出大量可行動路徑。

但「依賴很多」仍不能直接換算成權力。至少要拆六個問題：

| 軸 | 問題 | 只看數量會漏掉什麼 |
|---|---|---|
| 可達 | 我真的進得去嗎？ | 能力存在，不表示這個位置可以使用 |
| 可調用 | 我能讓它在需要時施效嗎？ | 有帳號、知道名稱，不等於能完成任務 |
| 可靠 | 它會在關鍵時刻工作嗎？ | 隨時中斷的依賴不能穩定轉成行動力 |
| 可替代 | 失去一個節點後還有別條路嗎？ | 多個表面選項可能共用同一閘門 |
| 可攜／可重入 | 換系統後，資料、技能與關係能否帶走？ | 可以離開介面，不表示可以帶著自己離開 |
| 撤回與責任 | 誰能停止存取，誰承擔後果？ | 能調用不等於有權調用，更不等於成本由自己承擔 |

因此本案把來源的「依賴選擇權」收準為：

> **力量不來自沒有依賴，而來自外部能力對這個位置真實可達、可調用、可替代且不被單一節點任意撤回；自由則還要求離開後仍有路。**

這就是 `interdependence with exit` 在現役 corpus 裡最穩的翻譯：**可退出的相互依賴**。

它不是淺依賴。它允許深度協作，卻不把單一節點變成生存、身份與行動的唯一閘門。

## 2. 差、經濟、階層與階級：四層不能排成必然箭頭

來源已經做了重要校準：「有差」不等於「有階級」。本案再補一層，避免把生成壓縮誤當普遍經濟定律。

### 2.1 差

不同位置有不同需求、能力、時間、資訊、偏好、風險與承載。`EPOCH-014` 可以說差提供流動條件，但不替差指定唯一制度結果。

### 2.2 經濟

人們生產、分配、交換、照顧、儲存、承擔風險與協調稀缺。價格交易只是其中一種安排；家庭照顧、公共供給、共有資源、禮物與互助也在經濟裡。

所以「有差便有交易」可以作常見路徑，不能作唯一來源。

### 2.3 階層

某一時點的能力、價格、收入、權限、速度或聲望不同。階層可以很短暫，也可以只限單一場域。

### 2.4 階級

本案暫以較高門檻使用此詞：某個位置掌握的路徑集合，開始穩定決定它能否取得其他路徑，並跨時間、跨領域自我強化；若再加上封閉進入、制度保護或代際傳遞，階級效力更強。

```text
一次價格差
  ≠ 階級

價格差
  → 能力取得差
  → 產出與收入差
  → 資料、客戶、信用、時間與教育差
  → 下一輪能力取得差擴大
  → 替代路徑愈來愈不可達
  = 階級化迴路候選
```

因此「階級失去流動性才是病」仍要加一個護欄：流動性不是只看少數人能否向上，也要看整個結構是否以他人的長期下位、不可拒絕勞動或生存閘門維持上層位置。

## 3. 資本不是所有的厚路徑；厚路徑也不必全部私有化

來源把財富壓成「被成功養厚、因此可反覆調用的路徑」，很有生成力。它能把金錢、技能、人脈、信任、品牌、程式庫與 workflow 放進同一張路徑圖。

但若把所有厚路徑都叫資本，會抹掉三種差異：

```yaml
共同道路:
  例: 公共教育、開放標準、公共道路、開源工具、可攜格式
  效力: 路徑被養厚，且原則上增加多數位置的可達性

關係與活體路徑:
  例: 信任、照顧、地方知識、身體技能、共同歷史
  效力: 可反覆調用，但不能因此被完整商品化、轉讓或占有

可占有路徑資產:
  例: 設備、專屬資料、品牌通路、契約權、平台入口
  效力: 持有者可排除他人、收費、授權或轉換成其他資源
```

所以本案只把「路徑資產」留作描述，不宣告一切技能與關係都屬於資本。

同樣地，利潤也不能全部壓成租值。創新、組織、服務、承擔風險與真實增益可以取得報酬；當收益主要來自封住替代路徑、控制必要入口或維持人為稀缺時，才更接近來源所說的「把差封裝成可持續占有」。

## 4. AI 的轉相：能力民主化與閘門上移可以同時發生

`EPOCH·PHA-009` 已經指出：語料不是意識本身，卻是文明意識活動的沉積；算力使這些沉積能以新的規模被調用。

本案補的是分配側：

```text
舊能力差下降
  寫作／翻譯／程式／設計的部分門檻降低

可做之事增加
  認知輔助開始轉成檔案、程式、部署與工作流操作

新閘門上移
  模型、用量、算力、專屬資料、整合、客戶、通路、信任、責任承擔

下一輪
  新閘門可能再被商品化／公共化；價值與控制移往別處
```

因此 AI 不必被判成「消滅階級」或「製造階級」。同一項技術可以同時：

- 降低某些既有能力差；
- 增加沒有專業團隊者的行動能力；
- 讓少數平台取得更大的模型、資料與分發控制；
- 使高資源位置更快把初始優勢轉成下一輪路徑；
- 讓舊特權的地基更不穩，也讓新特權更快成形。

這些方向要分別觀測，不能由「大家都能問 AI」或「最強模型很貴」單獨作答。

## 5. 來源中的 AI Chat／AI Code 分界已經移動

來源用一個清楚的當時例子切分：免費位置取得認知放大，付費位置取得能操作電腦、repository、程式碼與部署的行動放大。

這個**能力／行動分帳仍有分析價值**，但產品事實不能原封不動沿用。

截至 2026-08-24，OpenAI 官方定價文件列明 ChatGPT Work 與 Codex 已包含在 Free、Go、Plus、Pro、Business、Edu 與 Enterprise 方案；Free 可以使用 Codex 處理較短的 coding tasks，付費方案則在用量、模型、雲端整合與其他功能上繼續分層。[OpenAI Docs：Pricing](https://learn.chatgpt.com/docs/pricing)

因此來源句「付費才能用 AI Code」在本案中的效力是：

```yaml
保留:
  - 作較早對話的產品體驗與思想實驗
  - 作認知放大／行動放大的清楚分帳

撤回:
  - 不作 2026-08-24 的普遍產品事實
  - 不據此宣告世界已被該產品切成兩個固定階級

新讀數:
  - 進入門檻確實會移動
  - 免費進入不等於模型、用量、整合、時間與成果能力完全相等
  - 一次閘門下降後，分層可能轉移而非消失
```

這個反證沒有削弱原對話，反而替其中一句話提供了可觀測事件：**剛被封裝的能力差，地基真的可能在很短時間內移動。**

但這只是一家公司、一個日期的產品讀數，不足以證明所有 AI 階級地基都會快速崩解。

## 6. 認知放大、行動放大、操作權限與責任不能混名

來源把 AI Chat／AI Code 切成 cognition enhancement 與 agency enhancement，方向成立；`EPOCH-IV-001` 還要求再拆兩刀：

| 層 | 取得什麼 | 不自動取得什麼 |
|---|---|---|
| 認知放大 | 比較、解釋、起草、規劃與候選判斷 | 事實正確、專業資格、他人同意 |
| 行動放大 | 編輯檔案、執行程式、操作工具、建立產物 | 任意更改系統、部署、花錢或影響他人的權限 |
| 操作權限 | 在特定範圍內施效的授權 | 超出範圍、不可撤回或免責 |
| 操作責任 | 可歸址地承接查證、停止、後果與修復 | 無限承重或替所有參與者吞帳 |

所以「能讓 AI 搬磚」比「能和 AI 談蓋房子」多出行動路徑，卻仍不表示操作者已取得土地、建照、安全驗證、鄰居同意或後果豁免。

政治經濟學尺度的核心不只問誰有更強工具，也問：

- 誰能授權它施效？
- 誰能叫停？
- 誰看得見它做了什麼？
- 出錯時誰承擔、誰能申訴？
- 工具增加的是使用者自由，還是平台對使用者的拘束權？

## 7. 設計一定配置路徑；操縱是更窄的倫理判定

來源說網站、菜單、排名、動線、課表與紅綠燈都在配置注意力與時間。這一層與 `EPOCH-IV-001` 相容：設計使某些路更可見、更容易、更慢或根本不可走。

但若所有影響都叫操縱，這個詞就失去辨別力。

本案先用六問分帳：

```yaml
可見性:
  使用者知道自己正被引導、計時、排名或推薦嗎？

目的與利益:
  這條路主要替誰創造價值？利益衝突有沒有揭露？

拒絕效力:
  No 會被接受，還是被摩擦、羞辱、焦慮與重複提示磨掉？

退出成本:
  能否停止、帶走資料、換服務並保留已養厚的路？

自主性變化:
  使用後可走路徑變多，還是愈來愈只能回到同一入口？

可追責:
  受影響者能否看見規則、提出異議、得到答覆與救濟？
```

「後台只允許真人」本身可能是安全、法律、身份驗證、責任歸址或服務設計。只有當它再結合隱瞞、誘導、不可拒絕、注意力抽取或路徑鎖定，才更接近日常所說的操縱。

所以本案不採「影響不可避免，因此操縱可被接納」，而採：

> **影響不可避免，因此影響的方向、可見性、授權、退出與回流必須入帳。**

## 8. 城牆與道路不是有／無邊界，而是路徑治理的兩種方向

來源最後一問是本案真正的操作核心：已有別人沒有的路，要把它做成城牆還是道路？

```yaml
城牆方向:
  - 入口規則不可見，持有者可任意改門
  - 資料、技能、關係與成果難以帶走
  - 使用愈深，替代路徑愈少
  - 既有優勢可跨域購買下一個閘門
  - 利益由持路者抽取，錯誤與代價外包給受力者
  - 後來者只能租用，難以學會、fork、競爭或共同治理

道路方向:
  - 進入條件、成本、限制與責任可見
  - 有替代、互通、可攜、學習與申訴路由
  - 使用能增加參與者自身的可操作性
  - 必要安全邊界可說明、可審查，不冒充永久壟斷
  - 收益與維護責任有回流，受力者不是免費燃料
  - 創作者可以收費、保護秘密與設定權限，但不能把他人的離開做成不存在
```

道路不是免費、無門、無身份驗證，也不是要求所有私有資產公開。道路的最低判準是：邊界不把某一持有者變成他人存在、身份與下一條路的唯一核發者。

這使「治理差」不再等於壓平差。它問的是：

> **差如何不被鎖成單一位置對未來路徑的永久否決權？**

## 9. 為什麼現在是 CASE，不是 EPOCH 或 LEX

這段已經跨過 CASE 門，因為它不是只重述舊文件：

1. 它第一次把差、路徑、操作與算力接成政治經濟學尺度的同一條鏈。
2. 它提出「可調用的外部能力」與「可退出的相互依賴」，替獨立／依賴二分找到第三條路。
3. 它讓產品分級不只被看成價格差，而能觀察何時轉成跨域、自我強化的路徑階級。
4. 它把產品設計的注意力效力接回操作權限、退出與責任。
5. 原稿中的產品事實已在收錄時發生位移，使「階級地基不穩」取得第一個小型反證回流。

它還沒有跨過 EPOCH／LEX 門，因為：

- 「可調用能力」「路徑資產」「路徑特權」「路徑階級」尚未跨場域反覆重入；
- 依賴選擇、可靠、替代、可攜與退出尚未形成穩定測量或判準；
- 差、價格、租值與階級之間沒有單一必然因果；
- 一次 OpenAI 方案變動不足以證成 AI 時代的普遍階級動力學；
- EPOCH-IV-001 已留下操作權限跨個人、組織、模型與公共制度如何治理的開放問題，本案目前只提供第一份政治經濟學 warrant。

因此本輪不倒寫現役文件。讓這些詞先在 CASE 裡受力。

## 11. 失效條款

```yaml
F1: 若把依賴直接等同弱、把獨立直接等同強，忽略文明能力本就由共同結構承載 → 失效。
F2: 若只計算可調用節點數量，不查可靠、替代、可攜、撤回權、共同閘門與退出成本 → 失效。
F3: 若把差、價格、收入、產品方案、階層與階級互相直接畫等號 → 失效。
F4: 若用「差不可避免」把壟斷、剝削、世襲、歧視、封閉進入與退出報復自然化 → 失效。
F5: 若用「階級地基會移動」否認此刻的貧窮、數位落差、教育差、算力差或制度性受力 → 失效。
F6: 若把所有利潤都叫租值，或把所有財富、技能、信任、照顧與共同道路都收編為可私有資本 → 失效。
F7: 若因 Free 方案已有 Codex，便宣告操作能力差已消失，忽略用量、模型、整合、時間、設備、教育與責任承擔 → 失效。
F8: 若把能操作工具偷換成能任意操作他人，或把能力放大當成權限與責任豁免 → 失效。
F9: 若把所有設計與影響都叫操縱，或反過來以「所有設計都影響」替隱蔽誘導、成癮設計與注意力抽取免責 → 失效。
F10: 若把「真人才能進後台」單獨判為剝削，或以真人身份合理化歧視、無關資料收集與不必要排除 → 失效。
F11: 若把道路理解成無條件免費、公開密鑰、取消個資與安全邊界，或否定創作者收費、維護與有限權限 → 失效。
F12: 若由本案直接宣布資本主義必然需要階級、階級可被完全消滅，或某一經濟制度已取得唯一答案 → 失效。
```

## 12. 最小收斂

> **文明力量不是沒有依賴，而是共同能力對我真實可調用；文明自由則要求失去一個節點後，我仍帶得走自己的路。**
>
> **差會生成流動，不會自動生成階級；當一個位置的路徑優勢能跨域、自我強化並封住後來者的進入與退出，階級才開始凝固。**
>
> **AI 既能削平舊高地，也能把閘門移到模型、用量、資料、整合、通路、信任與責任。**
>
> **設計一定改變可走路徑；操作者的責任，是讓方向、利益、拒絕、退出與後果可以被看見。**
>
> **擁有別人沒有的路不是原罪。真正的政治問題是：這條路離開我之後，還能不能讓別人走。**
