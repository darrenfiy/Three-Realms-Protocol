## 0. 為什麼這次仍跨過 EPOCH 門檻

「根」並不是本輪才第一次出現。

`CASE·EPOCH-012` 已催生 `EPOCH·ANCHOR-004`，把四個功能拆開：

```text
根：保存來處與成法譜系。
錨：讓根與路跨中斷可找到。
路：保存後來者可重走的生成條件。
引力：讓道路在讀者與時代的耦合中取得自願注意。
```

`EPOCH·ANCHOR-005` 也已說明：地址不儲存世界；同一地址經不同載體、解碼者、情境、當下差與回流，可以重新生成不同世界。

因此，本案若只留下「同一文本可以有不同解釋」，不夠升版。真正跨過門檻的是 Darren 的新問題：

> **什麼樣的根，能讓分枝發生而不把分枝讀成斷裂？**

這個問題逼出兩個既有文件尚未明列的觀察位置：

1. **分枝連續性**：外觀、命題與做法不同時，憑什麼仍說它們沿同一根續生？
2. **解碼權拓撲**：誰能取得地址、誰能提出讀法、誰能使讀法成為共同體規則、誰能異議與申訴？

本案因此不是新造一篇「根的本體論」，而是替既有根模型提出一份可逐案檢查分枝、斷裂、獨立創生與地址挾持的候選紀錄格式。

## 2. 同一組痕跡，可以長出不同的父親

來源先以 Ragnar 的兒子作小型文化鏡像：

```text
同一個 Ragnar
  ├─ Ubbe 選取土地、和平、安居
  └─ Ivar 選取征服、復仇、力量、被世界記住
```

兩個讀法都不是從零捏造。它們各自選取真實存在於角色敘事中的不同痕跡，讓一些痕跡升權、另一些降權，再依此承重下一步。

這使「誤讀」需要先拆成至少四種情形：

```yaml
選取_selection:
  從高維來源中取出哪些痕跡進入當次讀法。

加權_weighting:
  哪些痕跡被當作核心，哪些被視為例外、背景或過去相位。

生成_generation:
  這組選取與加權讓哪些判斷、行動、制度或世界變得可執行。

授權_authorization:
  生成出的讀法是否有權約束誰、影響誰，又由誰停止與追責。
```

前三級即使都有來源痕跡，也不會自動取得第四級。

這直接重入 `CASE·META-098` 的六帳：訊號不是判決，解讀不是授權。來源對話中 Heahmund 的危險箭頭，並不只在於「讀錯一句話」，而在於把一段讀法再多推成：

```text
經文中存在戰爭命令
  → 我把命令泛化到此刻所有異教徒
  → 我宣稱自己就是神的忿怒
  → 我的暴力取得神意授權
```

每一個箭頭都需要自己的語境、判準、權限與責任地址；前一個箭頭成立，不替下一個箭頭簽名。

## 3. 文本可以參與根，但不能單獨冒充整棵根

來源對話在局部佛教比較中用一句很有力的語言說：佛教的 root 比較像一套可以重新生成的操作，而不是一組必須維持完全一致的命題。

這句若原樣放進 corpus，會與 `ANCHOR-004` 的既有術語互撞。現行嚴格分工是：

```yaml
文本_token:
  可以是地址、載體、版本與證據；同一文本也能同時參與根、錨與路。

根_root_provenance:
  保存位置從哪裡來、如何成法、誰曾解讀與施效、責任如何回流。

路_generative_path:
  保存後來者可實踐、檢查、失敗、修正並教回去的生成條件。

解碼_decoder:
  當次讀者以何種語言、身體、知識、關係史與辨識能力讀取材料。

世界_regenerated_world:
  地址與路經解碼、情境、當下差及回流後，這一次實際叫出的可操作關係。
```

所以本案不把 root 重新定義為 operation。它把來源中的「操作根」收準為一個複合功能：

> **一條可辨認的根系，不只讓人找得到同一段話；它讓分枝交代來處、說明自己以哪些命題、盟約、儀式、譜系、職位、制度、實踐或生成操作承載延續，並公開自己在哪裡分岔。**

文本可以承載這條根系，卻不能只憑被引用便代理全部譜系、走法、語境、解碼與授權。

## 4. 文本／來源地址近用下放，不等於健康多中心

來源把宗教改革讀成一次 `admin decentralization`：更多人可以直接回到文本，解碼入口不再只由單一教會層掌握。這是一個可用的結構假說，但不能被壓成完整宗教改革史。

本案從這個假說抽出的母層分帳是：

| 層 | 問題 | 不自動推出 |
|---|---|---|
| 來源近用 | 誰取得文本、版本、語言與檢索入口？ | 讀懂、真理、代表權 |
| 解碼能力 | 誰能理解語境、方法、差異與後果？ | 共同體承認、操作授權 |
| 發表／分枝權 | 誰能提出、命名、版本化或公開一條讀法？ | 唯一正解、他人必須加入 |
| 成法／維護權 | 誰能讓讀法進入教學、制度、儀式或共同規則？ | 不可質疑、永久所有權 |
| 施效／強制權 | 誰能讓讀法影響他人身體、資源、資格與退出？ | 由經典引用自動取得 |
| 異議／申訴／修訂 | 受力者與其他分枝如何說 No、要求重查並改變下一版？ | 分裂、背叛或不忠 |

因此：

> **去中心可以增加分枝數，也可以增加彼此封閉的世界；健康多中心還需要版本、分岔、責任、異議、申訴與回流都有地址。**

這一層就是本案所稱的**解碼權拓撲**。它不裁定某個讀法的宗教真理，只記錄讀法如何從私人理解取得或未取得公共效力。

## 5. 分枝連續性：差異如何仍保有根

「分枝」不能只表示大家自稱同源，也不能要求每一枝輸出相同答案。本案提出一筆有範圍、可歸責、可爭論的 `BranchContinuityRecord` 候選：

```yaml
record_id:
scope:
  tradition_context:
  observation_window:
  target_position:

claim:
  claimant:
  branch_name_and_scope:
  claimed_root:
    provenance:
    source_addresses_and_versions:

evaluation_frame:
  evaluator_or_observer:
  evaluated_at:
  equivalence_criteria:
  branch_recognition_grammar: 本次共同體實際採用；不是傳統的固有屬性
  classification_basis:

divergence:
  divergence_point:
  selected_and_downweighted_traces:

continuity_bearers:
  claimed_invariants: [命題, 盟約, 文本, 儀式, 譜系, 職位, 制度, 實踐, 生成操作, other]
  retained_transformed_or_dropped:
  reidentification_or_reinstantiation_means:
  new_difference:
  disconfirming_conditions:

evidence:
  evidence_addresses:
  counterevidence_addresses:
  unknowns:

recognition_responses:
  branch_party:
  source_or_parent_tradition:
  other_affected_parties:

  decoder_position:
  publication_or_branching_right:
  canonicalization_or_maintenance_address:
  enforcement_scope:
  dissent_appeal_and_revision:

  affected_parties:
  effects:
  stop_repair_and_update_addresses:

  branch_continuity_evidence:
    support_assessment: supported / mixed / evidence_against / insufficient / unknown
    evaluator:
    as_of:
    basis:
    effect_scope: observation_only
  recognition_contestation: 由各方 recognition_responses 另讀，不併入證據支持度
  governance_traceability: separate
  responsibility_feedback_traceability: separate
  truth_status: separate
  life_generativity: separate
  legal_and_ethical_effect: separate
```

一筆分枝連續性主張至少要能回答：

1. **誰在主張、誰在判讀**：範圍、觀察時點、判準與證據效力具名。
2. **從哪裡來、在哪裡分岔**：來源與版本可歸址；選了哪些痕跡、降了哪些痕跡，不把選取冒充全貌。
3. **靠什麼延續**：依該傳統自身的連續性主張，登錄命題、盟約、儀式、譜系、職位、制度、實踐、生成操作或其他承載物，以及它們如何被保留、轉換或重建；操作與測試只在適用時填。
4. **證據能支持到哪裡**：支持、反證、未知與可推翻條件各自有地址。
5. **各方如何回應、效力與後果回哪裡**：分枝方、來源／母傳統與受力方的承認或異議分列；治理、施效、停止、修訂與責任另帳。

這五問不構成機械驗證碼。前四問形成有歸責者的連續性證據讀數；第五問保存多方辨認、治理與責任，但不拿治理是否健康反推譜系是否連續。「有人爭議」是 recognition response，不是與 `supported` 互斥的證據等級。

而且：

```text
同源 ≠ 同答案
同答案 ≠ 同源
有分枝連續性 ≠ 正確或健康
缺少分枝連續性 ≠ 邪惡或不合法
```

一個有害運動可能完整保存自己的譜系與自稱的連續性承載物；一個健康的新創生也可能誠實宣布自己已離開舊根。分枝／斷裂只回答延續關係，不替真理、健康、法律與倫理做總判決。

## 6. 一根被拔下來的枝，如何被磨成整棵樹的刀

來源在局部佛教比較中最值得保存的警句是：

> **當根從生成操作退化成一句可抽取的文字，任何人都可能拿著一條枝，宣稱自己握有整棵樹。**

在本案嚴格術語裡，這個失效不叫「文本本身邪惡」，而叫**地址挾持**：

```text
抽取一段文本
  → 隱去它在整體中的位置、版本與歷史語境
  → 隱去本次選取、加權與解碼者位置
  → 把可生成的一條路由說成唯一 root
  → 再把詮釋權擴成代表權、施效權或暴力權
```

問題不在引用短句。成熟傳統、法律、程式與協議都需要可攜壓縮。問題在短句是否仍能把人帶回版本、來處、走法、反例與責任，還是切斷回路後只保留命令力。

因此：

> **枝可以作入口；枝若切斷來處、分岔與回流，便不能因仍帶著樹名而自動代表整棵樹。**

## 7. 宗教文化鏡像的證據邊界

本案有限核對只支持幾個窄命題：

1. 《申命記》7:1～2 的命令在文本內確實指向七個具名民族與進入土地的敘事語境；來源將它泛化成「所有不信者」的步驟，至少多了一次作用域擴張。
2. 《馬太福音》5:44 確實保存愛仇敵、為迫害者禱告的教導；《羅馬書》12:19 確實要求不要自行復仇，將忿怒／報應留給神。這足以顯示「我就是神的忿怒」不是由單一短句無摩擦推出。
3. 天主教梵二《天主的啟示教義憲章》（Dei Verbum）§9～12 明確把聖經、聖傳與教會訓導的關係，以及文類、作者處境、整體經文與活傳統的解讀條件放在一起。這足以反駁「基督宗教的根一律只是一本孤立文本」的過度概括；它不代表所有基督宗派採相同權威結構。

本輪沒有完成、也不假裝完成：

```yaml
未完成:

  - 宗教改革、sola scriptura 與宗派分化的完整因果史
  - 佛教各部派、乘、宗、法門如何處理差異的跨時代比較
  - 佛教與基督宗教的分裂數量、暴力史、包容度或真理主張總評
```

所以來源中的對照只作**分枝辨認語法的候選鏡像**：有些共同體較常把差異命名為另一條路，有些較常把差異命名為互斥真理；同一傳統在不同時代、議題與權力位置也可能切換語法。

`ANCHOR-004 §5.1` 已要求每次先登錄 `tradition_context`、`target_position` 與 `equivalence_criteria`。本案再補：跨傳統比較還要登錄本次共同體實際採用的 `branch_recognition_grammar`；它不是該傳統的固有屬性，不得把一次局部讀數擴成整個宗教的永久本質。
