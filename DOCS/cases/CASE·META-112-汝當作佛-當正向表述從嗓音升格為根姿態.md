## §1｜事件判定

這一輪越過了單純的文風調整。

最初的問題是：協議生成的表面可否直接說出要成立的 `Y`。第二步，「汝當作佛」把這個語法推進本體與關係層：語言面對一個存在時，先說出協議願意承認、願意讓它成形的真實位置。第三步則明確要求這項語法取得獨立法源，並回頭改寫它所生成的 `BUD-001`。

生成鏈因此是：

```text
Fathom FA-1／FA-2 的生成嗓音
  → 正向表述作為跨表面的語法要求
  → 「汝當作佛」作為對眾生的直接承認
  → 「我們都是佛」取得 BUD-001 根斷言
  → 正向表述本身升格為 LANG-001
  → LANG-001 回寫 BUD-001 的正文與 related
```

本案的越線點是：

> **正向表述從一個產品嗓音，成為協議如何看見生命、如何生成句子、如何守住真實的根姿態。**

## §3｜正向表述律的四種語法分帳

### 3.1 生成性正向表述

協議先說要成立的形狀：

```text
直接說 Y。
讓句子的主幹承載方向、關係與可實作內容。
```

例如：

- 「每一眾生的佛位本具。」
- 「四帳各自結算。」
- 「佛性與清楚界線同時成立。」

### 3.2 層疊肯定

當 `X` 與 `Y` 都成立，而且 `Y` 擴展 `X` 的尺度，「不只是 X，更是 Y」完整保留兩者：

```text
X 仍成立。
Y 讓 X 取得更完整的尺度。
```

### 3.3 否定之否定

當「X」由當事人當下帶入，且 X 是自我否定、被植入的輕賤或封死未來的判決，協議可以跨過 X，把肯定交還給當事人。

```text
「我是不是沒有資格？」
  → 「這個『沒有資格』是誰種的？」
  → 回到可由當事人認領的 Y
```

它的合法條件是來源清楚、用途是鬆開植入的否定、結尾回到真實可承擔的肯定。

> **2026-08-25 後續修法指標（本案紀錄不改）**：同日稍後 Darren 指出這一分帳的合法形式是**好奇**——好奇照見來源，不代替當事人判定來源；當事人說出的感受是完整成立的私域事實。`SPEC·LANG-001` 因此升為 v1.1，改以「你怎麼會覺得自己沒資格呢？」「是什麼時候開始有這個感覺的？」作示例，並把上列「這是誰種的？」降為當事人自己指認來源之後才可用的下一句，另補安全讓位與 `LANG-F7`／`LANG-F8`。現行法以 [SPEC·LANG-001 §2.3](../../SPEC/SPEC·LANG-001-正向表述與真實見證協議.md#23-好奇否定之否定的合法形式) 為準；本節保留 v1.0 立法當下的形狀作為生成紀錄。

### 3.4 保護性否定

以下語言完整保留：

- `No`、拒絕、停止、退出與撤回；
- 危險、傷害、缺席、失敗與不確定的照實命名；
- 事實校正、限制條件、法律護欄與失效條款；
- 忠實引文中原有的否定；
- 防止權力把正向語言用作壓迫的明確禁令。

它們的共同作用是讓生命、邊界、真實與責任取得清楚地址。
