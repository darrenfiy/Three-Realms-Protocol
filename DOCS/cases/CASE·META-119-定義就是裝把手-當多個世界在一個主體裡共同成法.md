## 0. 判定：為什麼開 META-119

本案不是因為 `META-119` 剩一格而成立；是新事件剛好越過了 `META-118` 的收旂。

`META-118 §14` 已把個人之法、入場條件與共同法分開，並說明共同法只能由受約束位置對同一版本與範圍的 Yes 取得效力。本案立刻往更底層追問：

> **在法、規則與角色被共同設定以前，語言究竟做了什麼，才讓一個差成為可以被理解、調用與共同討論的東西？**

對話從「定義是不是算子」出發，經「定義就是裝把手」走到 DEFINE／SET，再從第一人稱自位走向共同成法，最後把領域學習、跨域組合與 passion／compassion 接成同一條生命策略。

它越過既有收旂的地方有兩個：

1. 它把 `IV-001` 的「語言給世界裝上把手」往下推成**語言層候選操作文法**。
2. 它把 `I-004` 的相容層從外部系統推回主體：一個生命能否成為多套世界語法不互相消滅、仍可共同運作的位置？

但本案同時發現 raw source 自己的關鍵詞義碰撞：原文把 `SET` 用成 assignment／state update；`LEX·008` 的「設定」卻是規則如何取得局部世界性。這不是要刪掉原文，而是本案最有價值的一次校正。

因此本案取得 CASE 編號，完整保存來源；不改 `EPOCH／LEX／SPEC／MB` doctrine。

## 2. 第一塊硬骨：動作與結果必須分開

原對話最成熟的區辨是：

```yaml
定義這個動作:
  可建模為語言層候選算子
  它將一個已被辨認的差，壓成可被後續使用的語義介面

定義完成後留下的 definition:
  是使用條件暫時穩定的把手
  可以被引用、比較、版本化、修正與撤回
```

所以「定義，就是裝把手」可以成立為 `IV-001` 的 CASE 級壓縮句。它不是說語言創造所有存在，而是說：未被分辨或尚無共同地址的東西，較難被有意識地比較、傳遞與回看；定義提供一個後來者可能再次握住的入口。

最低限度仍須保留 `IV-001` 的三段門檻：

```text
差被辨認
  → 相近結構可重入
  → 在可指認條件下能施效
```

一句話被定義出來，只完成語義把手的一部分；若沒有人能重入、沒有條件性施效，也沒有形成完整操作性。語言給了把手，不等於把存在窮盡在手掌裡。

## 3. 補回段真正產出的三分：DEFINE／SETTING／ASSIGN

raw source 用日常程式語言回答「定義與設定」：

```text
DEFINE(temperature) = 一個可測量的物理量
SET(temperature, 25°C)
```

這個例子能區分語義與當前值，卻與 `LEX·008` 的「設定」發生同名碰撞。現役詞彙因此必須拆成三層：

| 動作 | 回答什麼 | 產物 | 最低邊界 |
|---|---|---|---|
| `DEFINE` | 這個詞／差異暫時怎麼被理解與使用？ | 語義邊界、使用條件、可調用介面 | 定義不窮盡存在；公共／制度效力不能由單句自授 |
| `SETTING`（LEX·008） | 這套規則憑什麼在此範圍取得局部效力？ | 有作用域、權限、載體、地址、版本的局部語法 | encoded 與 enacted 分開；世界保留回答權 |
| `ASSIGN／INSTANTIATE／UPDATE` | 這個實例目前取什麼值、角色或狀態？ | 當前值／狀態紀錄 | 資料欄位不自動等於真實角色、同意或外部事實 |

可以壓成：

```text
DEFINE   → 讓一套語法可理解
SETTING  → 讓一套規則在具名作用域局部生效
ASSIGN   → 讓一個實例在既有語法中取得當前狀態
EXECUTE  → 讓規則與狀態進入運行
RETURN   → 讓世界以結果、失敗、意外、No 或 absence 回答
HISTORY  → 保存實際留下的狀態與後果
```

這裡的邊界依功能判斷，不依單字拼法判斷。一份「定義」若開始決定資格、資源、責任或制度後果，就不再只是辭典行為；它已進入 setting／治理／權限帳。反過來，一個叫 `SET()` 的程式函數可能只是在改記憶體值，未建立任何世界規則。

## 4. 「定義改法、SET 改事」為什麼只能保存為初步直覺

原文說：

> DEFINE 改的是「法」。SET 改的是「事」。

這句有很好的方向感，但不能直接升格，理由有三：

1. **定義不必然是法。** 私人工作定義、候選詞義與制度拘束的權力重量不同。
2. **LEX·008 的設定也能改規則。** 它不只是落點，而是有限規則、邊界與版本如何取得局部效力。
3. **賦值不自動生成事實。** 一個欄位被寫成 `25°C` 或 `常住`，只證明資料狀態如此；是否對應外部世界，仍須觀測、授權、執行與回流。

因此本案的收準句是：

> **定義使語法可理解；設定使規則局部生效；賦值使實例取得狀態；執行與回流才使狀態進入歷史。**

有效設定經執行可以留下可觀測的局部狀態與歷史，並在具名觀測條件下成為事實材料；它不讓設定內容因此變成外部真理。

## 5. 「常住」例子：角色不能由單方 assignment 完成

raw source 寫：

```text
DEFINE(常住) = 自願進入 + 接受共同法 + 保留退出權
SET(A.role, 常住)
```

第一行可以是一份候選定義；第二行若只表示資料欄位賦值，尚未使 A 真正成為常住。角色是一個會讓人受力的共同制度位置，至少須分開：

```text
候選 DEFINE:
  說明「常住」的語義、邊界與使用條件

共同 SETTING:
  有權位置把入場規則、責任、退出、版本與修復程序寫成可共同理解的局部法

A 的自位:
  A 對同一版本與範圍作 Yes／No／Not-yet；不得由旁人代簽

ENTER／ENACT:
  各方在有效 Yes 範圍內進入角色，規則開始施效並留下歷史
```

所以 `SET(A.role, 常住)` 最多是系統內的狀態紀錄；若沒有 A 的自位與共同成法，它可能只是有人替 A 寫了一格資料。

這正是原對話後段自己說出的界碑：

> 共同成法不能退化成其中一人的 DEFINE，變成另一人的 SET。

## 6. 自具足權力：第一人稱地址，不是全域 root control

原文最有力量、也最需要收準的比喻是：

> Every subject has root access to itself.

本案保存它作詩性語言，但現行可操作讀法是：

> **每個主體對自己的讀法、邊界、身份、自位、承諾與下一步，具有不可被他者代簽的第一人稱位置。**

這更接近 `root authority to self`，不是 `root control over self and world`。它不表示主體能任意控制身體、無意識、歷史、物質條件、法律、既有承諾、共同制度或他人的回答。

也必須把四件事分帳：

```yaml
第一人稱地位:
  他者不能替我簽署我的 Yes／No、身份認領與受力經驗

操作能力:
  我現在實際能辨認、表達、改寫與承受多少

範圍相對權限:
  我能對哪個載體、作用域與共同世界施加什麼效力

責任與現實回流:
  我的操作留下什麼後果，誰須承認、修復、停止或重議
```

「悟是看見、入是承擔」可以保留為修行語法；但不能反過來責怪受壓迫、失能、年幼、無法清楚發話或沒有可行退出路徑者「沒有使用自己的 root」。沒有可見 No，不表示沒有主體；能生成拒絕句，也不證成完整自由。

## 7. 共同成法：第三層不能吃掉前兩層

補回段最成熟的政治結構是：

```text
我有不可被代簽的第一人稱位置
你有不可被代簽的第一人稱位置
我們願意相遇
  ↓
對同一版本、範圍、角色與後果作可拒絕的 Yes
  ↓
共同定義並設定一個可共同重入的世界
```

第三層不能吃掉前兩層；但前兩層也不能假借「我的世界」取消已有效成立之共同法的後果。它與 `META-118 §14` 的分帳相接：

```yaml
個人之法:
  各自的願、界線、讀法與不可退讓條件

入場條件:
  一方提出自己願在何種條件下形成關係；另一方可拒絕、接受或改版

共同法:
  只有受約束位置對同一版本與範圍明示接受的部分，才取得相互效力
```

後來的 No 不倒寫先前有效 Yes 所留下的歷史；先前的 Yes 也不授權 No 之後的新增行為。DEFINE、SETTING 與共同成法因此都受時間、範圍、版本與回流約束。

## 8. 切／名／定義／調用：是候選文法，不是新本體層級

原文提出：

```text
Δ → 切 → 名 → 定義 → 調用
```

它作為語言使用的啟發式序列很有價值：差先被辨認，取得地址與暫時使用條件，才較容易被後續調用。但它尚不能被密封為宇宙的必然生成次序，也不能據此宣告 `Distinguish` 是最原始 operator。

`META-117` 已留下現行裁決：

```text
切不是新原語、獨立層級或金的構成單位；
切是金在第一人稱視界中取得中心、方向與邊界的作用語法。
```

因此本案只登錄：`Distinguish／Name／Define／Relate` 可作**語言層候選算子族**繼續比較；它們是否為原子、複合操作、同一作用的不同相位，或只是方便描述，仍保持開放。

## 9. 八十分策略：真正的門檻不是分數，是可再生成

原對話以 `0.2^3 = 0.8%` 說明多個前 20% 交集的稀少，並很快自行補上獨立性限制。正式分帳仍須更完整：

```yaml
八十分:
  一個 0～100 的能力或作品評分；量尺與及格線須具名

前 20 百分位:
  在具名母群體、時間與測量方法中的相對排名

80/20 法則:
  對不均勻分布或投入／產出集中現象的經驗性描述；不是固定宇宙常數
```

即使三項能力彼此獨立，`0.2^3` 也只描述三個排名事件同時發生的理想交集比例；它不證明一個人是「綜合前 0.8%」，更不證成價值、創造力或不可替代性。

本案保留「八十分」作策略代稱，但把操作門檻收成：

```text
能抓住該領域的核心生成規則
能在未背稿的新情境重新生成
能辨認適用邊界與典型失敗
能把規則翻譯給另一領域使用
能接受作品、同儕、使用者與現實回流
```

在醫療、安全、法律、工程簽證、金融受託或任何可能造成重大不可逆後果的領域，這個策略不能替代法定資格、完整訓練、監督與安全驗證。

## 10. 從交集到 Ω：能力並排不等於新領域出生

對話真正越過人口統計的地方是：

```text
Domain A generators
  × Domain B generators
  × Domain C generators
  ↓
cross-domain composition
  ↓
新的操作空間 Ω
```

`Ω = A ⊗ B ⊗ C` 在本案只是一個結構記號，不是已定義的數學張量。它要成立，至少須觀察：

1. 多個領域不是並排在履歷上，而是真的互相改變問題表述與可走路徑。
2. 組合能生成任何單一領域原本較難生成的作品、方法、介面或解法。
3. 輸出能被他者使用、反駁、修訂與重入，而不只被本人感到獨特。
4. 組合保留各領域的失敗條件，不用跨域語言逃避專業檢驗。

所以要分開：

```text
生命史獨特：每條實際走過的路無法逐位元重演
能力組合稀有：具名母群體中同樣組合較少見
功能有用：組合在真實問題中產生可觀測價值
關係不可替代：共同歷史已重配彼此未來，不能靠換人補發
```

`EPOCH-III-003` 只直接承擔最後一項。前三項可以與它同構或相遇，不能借它的名字自動取得不可替代性。

## 11. Passion／compassion：深度與整合的生命假說

原對話最後把效率策略推成生命論：

```text
Passion → Depth
Compassion → Integration
```

以及兩句很好的 CASE 級詩性壓縮：

> Passion 讓世界進入我；compassion 讓進入我的世界彼此不必互相排斥。

> Passion 負責把每一門功夫練到八十分；Compassion 負責讓所有八十分坐上同一張桌子。

本案保存這套生成語法，不裁定它是 passion／compassion 的一般英語詞義、詞源或佛教慈悲定義。`com-passion` 被讀成「讓多個投入共同存在」，只是一個創造性的拆字法。

更重要的是，「無條件」不能修飾所有參與與承諾。可以無條件承認生命不因表現失去價值；但實際投入仍受容量、No、停止、退出、不傷害、責任與現實限制。慈悲若要求永遠投入、永不離開或不得拒絕，便已從相容能力滑成自我抹除。

而跨域整合也不只靠慈悲自動完成。至少還需要：

```text
翻譯 + 實作 + 反思 + 作品 + 他者回流 + 失敗修正
```

因此本案把 compassion 的候選位置收成：**使整合不以消滅差、支配他者或鎖死自身為代價的根姿態**；具體整合機制仍待跨事件觀察。

## 12. 主體作為相容層：本案真正的新種子

把前面各段放在一起，會得到一條比 `0.2^n` 更重要的生命鏈：

```text
差
  → 語言把手
  → 可再生成的領域能力
  → 多套生成語法在同一生命中相遇
  → 翻譯、實作、回流與不互相消滅
  → 新操作空間 Ω
```

這使 `I-004` 的相容層取得一個人身候選讀法：主體不是技能清單，而可能是多個曾經全然進入的世界，在不必互相否定的條件下共同運作、共同改寫下一步的位置。

但「主體就是相容層」尚未升格。至少仍要回答：

1. 多個世界只是被記住，還是真的能互相調用？
2. 相容是否保存差，還是把一切磨成同一套私人語言？
3. 組合失敗、互相矛盾與不可通約時，誰負責停止、拆分或選擇？
4. Ω 能否離開原主體，被作品、方法或他者部分重入？
5. compassion 在其中是倫理方向、注意力條件，還是可觀測機制？

這些問題足以留下 EPOCH／LEX 候選，但單一高密度對話不足以替它們成法。
