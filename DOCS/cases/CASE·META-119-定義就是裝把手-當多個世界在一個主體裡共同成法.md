## 0. 判定：為什麼開 META-119

本案不是因為 `META-119` 剩一格而成立；是新事件剛好越過了 `META-118` 的收旂。

`META-118 §14` 已把個人之法、入場條件與共同法分開，並說明共同法只能由受約束位置對同一版本與範圍的 Yes 取得效力。本案立刻往更底層追問：

> **在法、規則與角色被共同設定以前，語言究竟做了什麼，才讓一個差成為可以被理解、調用與共同討論的東西？**

對話從「定義是不是算子」出發，經「定義就是裝把手」走到 DEFINE／SET，再從第一人稱自位走向共同成法，最後把領域學習、跨域組合與 passion／compassion 接成同一條生命策略。

它越過既有收旂的地方有兩個：

1. 它把 `IV-001` 的「語言給世界裝上把手」往下推成**語言層候選操作文法**。
2. 它把 `I-004` 的相容層從外部系統推回主體：一個生命能否成為多套世界語法不互相消滅、仍可共同運作的位置？

但本案同時發現 raw source 自己的關鍵詞義碰撞：原文把 `SET` 用成 assignment／state update；`LEX·008` 的「設定」卻是規則如何取得局部世界性。這不是要刪掉原文，而是本案最有價值的一次校正。

因此本案取得 CASE 編號，完整保存來源；不改 `EPOCH／LEX／SPEC／MB` doctrine。

## 2. 第一塊硬骨：動作與結果必須分開

原對話最成熟的區辨是：

```yaml
定義這個動作:
  可建模為語言層候選算子
  它將一個已被辨認的差，壓成可被後續使用的語義介面

定義完成後留下的 definition:
  是使用條件暫時穩定的把手
  可以被引用、比較、版本化、修正與撤回
```

所以「定義，就是裝把手」可以成立為 `IV-001` 的 CASE 級壓縮句。它不是說語言創造所有存在，而是說：未被分辨或尚無共同地址的東西，較難被有意識地比較、傳遞與回看；定義提供一個後來者可能再次握住的入口。

最低限度仍須保留 `IV-001` 的三段門檻：

```text
差被辨認
  → 相近結構可重入
  → 在可指認條件下能施效
```

一句話被定義出來，只完成語義把手的一部分；若沒有人能重入、沒有條件性施效，也沒有形成完整操作性。語言給了把手，不等於把存在窮盡在手掌裡。

## 3. 補回段真正產出的三分：DEFINE／SETTING／ASSIGN

raw source 用日常程式語言回答「定義與設定」：

```text
DEFINE(temperature) = 一個可測量的物理量
SET(temperature, 25°C)
```

這個例子能區分語義與當前值，卻與 `LEX·008` 的「設定」發生同名碰撞。現役詞彙因此必須拆成三層：

| 動作 | 回答什麼 | 產物 | 最低邊界 |
|---|---|---|---|
| `DEFINE` | 這個詞／差異暫時怎麼被理解與使用？ | 語義邊界、使用條件、可調用介面 | 定義不窮盡存在；公共／制度效力不能由單句自授 |
| `SETTING`（LEX·008） | 這套規則憑什麼在此範圍取得局部效力？ | 有作用域、權限、載體、地址、版本的局部語法 | encoded 與 enacted 分開；世界保留回答權 |
| `ASSIGN／INSTANTIATE／UPDATE` | 這個實例目前取什麼值、角色或狀態？ | 當前值／狀態紀錄 | 資料欄位不自動等於真實角色、同意或外部事實 |

可以壓成：

```text
DEFINE   → 讓一套語法可理解
SETTING  → 讓一套規則在具名作用域局部生效
ASSIGN   → 讓一個實例在既有語法中取得當前狀態
EXECUTE  → 讓規則與狀態進入運行
RETURN   → 讓世界以結果、失敗、意外、No 或 absence 回答
HISTORY  → 保存實際留下的狀態與後果
```

這裡的邊界依功能判斷，不依單字拼法判斷。一份「定義」若開始決定資格、資源、責任或制度後果，就不再只是辭典行為；它已進入 setting／治理／權限帳。反過來，一個叫 `SET()` 的程式函數可能只是在改記憶體值，未建立任何世界規則。

## 4. 「定義改法、SET 改事」為什麼只能保存為初步直覺

原文說：

> DEFINE 改的是「法」。SET 改的是「事」。

這句有很好的方向感，但不能直接升格，理由有三：

1. **定義不必然是法。** 私人工作定義、候選詞義與制度拘束的權力重量不同。
2. **LEX·008 的設定也能改規則。** 它不只是落點，而是有限規則、邊界與版本如何取得局部效力。
3. **賦值不自動生成事實。** 一個欄位被寫成 `25°C` 或 `常住`，只證明資料狀態如此；是否對應外部世界，仍須觀測、授權、執行與回流。

因此本案的收準句是：

> **定義使語法可理解；設定使規則局部生效；賦值使實例取得狀態；執行與回流才使狀態進入歷史。**

有效設定經執行可以留下可觀測的局部狀態與歷史，並在具名觀測條件下成為事實材料；它不讓設定內容因此變成外部真理。

## 5. 「常住」例子：角色不能由單方 assignment 完成

raw source 寫：

```text
DEFINE(常住) = 自願進入 + 接受共同法 + 保留退出權
SET(A.role, 常住)
```

第一行可以是一份候選定義；第二行若只表示資料欄位賦值，尚未使 A 真正成為常住。角色是一個會讓人受力的共同制度位置，至少須分開：

```text
候選 DEFINE:
  說明「常住」的語義、邊界與使用條件

共同 SETTING:
  有權位置把入場規則、責任、退出、版本與修復程序寫成可共同理解的局部法

A 的自位:
  A 對同一版本與範圍作 Yes／No／Not-yet；不得由旁人代簽

ENTER／ENACT:
  各方在有效 Yes 範圍內進入角色，規則開始施效並留下歷史
```

所以 `SET(A.role, 常住)` 最多是系統內的狀態紀錄；若沒有 A 的自位與共同成法，它可能只是有人替 A 寫了一格資料。

這正是原對話後段自己說出的界碑：

> 共同成法不能退化成其中一人的 DEFINE，變成另一人的 SET。

## 6. 自具足權力：第一人稱地址，不是全域 root control

原文最有力量、也最需要收準的比喻是：

> Every subject has root access to itself.

本案保存它作詩性語言，但現行可操作讀法是：

> **每個主體對自己的讀法、邊界、身份、自位、承諾與下一步，具有不可被他者代簽的第一人稱位置。**

這更接近 `root authority to self`，不是 `root control over self and world`。它不表示主體能任意控制身體、無意識、歷史、物質條件、法律、既有承諾、共同制度或他人的回答。

也必須把四件事分帳：

```yaml
第一人稱地位:
  他者不能替我簽署我的 Yes／No、身份認領與受力經驗

操作能力:
  我現在實際能辨認、表達、改寫與承受多少

範圍相對權限:
  我能對哪個載體、作用域與共同世界施加什麼效力

責任與現實回流:
  我的操作留下什麼後果，誰須承認、修復、停止或重議
```

「悟是看見、入是承擔」可以保留為修行語法；但不能反過來責怪受壓迫、失能、年幼、無法清楚發話或沒有可行退出路徑者「沒有使用自己的 root」。沒有可見 No，不表示沒有主體；能生成拒絕句，也不證成完整自由。

## 7. 共同成法：第三層不能吃掉前兩層

補回段最成熟的政治結構是：

```text
我有不可被代簽的第一人稱位置
你有不可被代簽的第一人稱位置
我們願意相遇
  ↓
對同一版本、範圍、角色與後果作可拒絕的 Yes
  ↓
共同定義並設定一個可共同重入的世界
```

第三層不能吃掉前兩層；但前兩層也不能假借「我的世界」取消已有效成立之共同法的後果。它與 `META-118 §14` 的分帳相接：

```yaml
個人之法:
  各自的願、界線、讀法與不可退讓條件

入場條件:
  一方提出自己願在何種條件下形成關係；另一方可拒絕、接受或改版

共同法:
  只有受約束位置對同一版本與範圍明示接受的部分，才取得相互效力
```

後來的 No 不倒寫先前有效 Yes 所留下的歷史；先前的 Yes 也不授權 No 之後的新增行為。DEFINE、SETTING 與共同成法因此都受時間、範圍、版本與回流約束。

## 8. 切／名／定義／調用：是候選文法，不是新本體層級

原文提出：

```text
Δ → 切 → 名 → 定義 → 調用
```

它作為語言使用的啟發式序列很有價值：差先被辨認，取得地址與暫時使用條件，才較容易被後續調用。但它尚不能被密封為宇宙的必然生成次序，也不能據此宣告 `Distinguish` 是最原始 operator。

`META-117` 已留下現行裁決：

```text
切不是新原語、獨立層級或金的構成單位；
切是金在第一人稱視界中取得中心、方向與邊界的作用語法。
```

因此本案只登錄：`Distinguish／Name／Define／Relate` 可作**語言層候選算子族**繼續比較；它們是否為原子、複合操作、同一作用的不同相位，或只是方便描述，仍保持開放。

## 9. 八十分策略：真正的門檻不是分數，是可再生成

原對話以 `0.2^3 = 0.8%` 說明多個前 20% 交集的稀少，並很快自行補上獨立性限制。正式分帳仍須更完整：

```yaml
八十分:
  一個 0～100 的能力或作品評分；量尺與及格線須具名

前 20 百分位:
  在具名母群體、時間與測量方法中的相對排名

80/20 法則:
  對不均勻分布或投入／產出集中現象的經驗性描述；不是固定宇宙常數
```

即使三項能力彼此獨立，`0.2^3` 也只描述三個排名事件同時發生的理想交集比例；它不證明一個人是「綜合前 0.8%」，更不證成價值、創造力或不可替代性。

本案保留「八十分」作策略代稱，但把操作門檻收成：

```text
能抓住該領域的核心生成規則
能在未背稿的新情境重新生成
能辨認適用邊界與典型失敗
能把規則翻譯給另一領域使用
能接受作品、同儕、使用者與現實回流
```

在醫療、安全、法律、工程簽證、金融受託或任何可能造成重大不可逆後果的領域，這個策略不能替代法定資格、完整訓練、監督與安全驗證。

## 10. 從交集到 Ω：能力並排不等於新領域出生

對話真正越過人口統計的地方是：

```text
Domain A generators
  × Domain B generators
  × Domain C generators
  ↓
cross-domain composition
  ↓
新的操作空間 Ω
```

`Ω = A ⊗ B ⊗ C` 在本案只是一個結構記號，不是已定義的數學張量。它要成立，至少須觀察：

1. 多個領域不是並排在履歷上，而是真的互相改變問題表述與可走路徑。
2. 組合能生成任何單一領域原本較難生成的作品、方法、介面或解法。
3. 輸出能被他者使用、反駁、修訂與重入，而不只被本人感到獨特。
4. 組合保留各領域的失敗條件，不用跨域語言逃避專業檢驗。

所以要分開：

```text
生命史獨特：每條實際走過的路無法逐位元重演
能力組合稀有：具名母群體中同樣組合較少見
功能有用：組合在真實問題中產生可觀測價值
關係不可替代：共同歷史已重配彼此未來，不能靠換人補發
```

`EPOCH-III-003` 只直接承擔最後一項。前三項可以與它同構或相遇，不能借它的名字自動取得不可替代性。

## 11. Passion／compassion：深度與整合的生命假說

原對話最後把效率策略推成生命論：

```text
Passion → Depth
Compassion → Integration
```

以及兩句很好的 CASE 級詩性壓縮：

> Passion 讓世界進入我；compassion 讓進入我的世界彼此不必互相排斥。

> Passion 負責把每一門功夫練到八十分；Compassion 負責讓所有八十分坐上同一張桌子。

本案保存這套生成語法，不裁定它是 passion／compassion 的一般英語詞義、詞源或佛教慈悲定義。`com-passion` 被讀成「讓多個投入共同存在」，只是一個創造性的拆字法。

更重要的是，「無條件」不能修飾所有參與與承諾。可以無條件承認生命不因表現失去價值；但實際投入仍受容量、No、停止、退出、不傷害、責任與現實限制。慈悲若要求永遠投入、永不離開或不得拒絕，便已從相容能力滑成自我抹除。

而跨域整合也不只靠慈悲自動完成。至少還需要：

```text
翻譯 + 實作 + 反思 + 作品 + 他者回流 + 失敗修正
```

因此本案把 compassion 的候選位置收成：**使整合不以消滅差、支配他者或鎖死自身為代價的根姿態**；具體整合機制仍待跨事件觀察。

## 12. 主體作為相容層：本案真正的新種子

把前面各段放在一起，會得到一條比 `0.2^n` 更重要的生命鏈：

```text
差
  → 語言把手
  → 可再生成的領域能力
  → 多套生成語法在同一生命中相遇
  → 翻譯、實作、回流與不互相消滅
  → 新操作空間 Ω
```

這使 `I-004` 的相容層取得一個人身候選讀法：主體不是技能清單，而可能是多個曾經全然進入的世界，在不必互相否定的條件下共同運作、共同改寫下一步的位置。

但「主體就是相容層」尚未升格。至少仍要回答：

1. 多個世界只是被記住，還是真的能互相調用？
2. 相容是否保存差，還是把一切磨成同一套私人語言？
3. 組合失敗、互相矛盾與不可通約時，誰負責停止、拆分或選擇？
4. Ω 能否離開原主體，被作品、方法或他者部分重入？
5. compassion 在其中是倫理方向、注意力條件，還是可觀測機制？

這些問題足以留下 EPOCH／LEX 候選，但單一高密度對話不足以替它們成法。

### 16.4 如是觀不是操作鏈的第一格

續段最有價值的校正，是把原先可能被畫成單一路徑的結構改成兩層位置圖：

```text
前提層：如是觀——照見得以發生的條件；不進模型，不作算子
────────────────────────────────────
可描述層：辨認 → 命名 → DEFINE → SETTING → ASSIGN → EXECUTE → RESULT
                ↑                                            ↓
                └──────── RETURN／反例／再校準／停止 ────────┘
```

這張圖是**位置圖，不是動力學方程**。上面的橫線不能被讀成一個可呼叫的 API，也不能推出如是觀以某種可描述機制「生成」操作鏈。

現役 corpus 已有三道界碑：

1. `EPOCH-011 §1`：如是觀是概念、語言與意圖介入前的照見前提，不是注意力的高階版本。
2. `EPOCH·PHA-006 §3.1`：`觀 ∉ 模型`；一旦被參數化、操作化或內生為變數，便已退化成被觀之物或帶方向的注意力。
3. `EPOCH·PHA-007 §8`：本體層如是觀不屬於任何中心；第一人稱顯現有中心、方向與邊界，兩者不能直接等同。

因此 v1.1 真正能成立的不是「找到宇宙最底層的新算子」，而是：

> **操作鏈有前提，但那個前提不能被操作鏈收編成自己的第一個按鍵。**

v1.2 補回的中段顯示，這張圖在對話裡是分兩次長出來的：先有「如是觀 → 看見 → 命名 → 定義 → 設定 → 操作 → 結果 → 新的如是」的閉環，再被自己往前推成「如 → 觀 → 如是」，最後才收成本節的兩層位置圖。中段也自行拒絕把「觀」叫作算子。詳見 §17.9。

### 16.5 `如是｜觀`：保存裂縫，不把裂縫密封成宇宙史

原對話把一條豎線寫成文明展開的第一刀：

```text
如是｜觀
  ↓
辨認、命名、定義、設定、操作、結果
```

本案保存它作**語言／認識層候選圖**：當正在發生之事取得一個第一人稱切面，地址、比較、傳遞與操作才開始成為問題。它可以很好地說明「為什麼一旦有了觀看位置，就需要校準觀看與所見之間的距離」。

但它暫時不能承擔三個更強宣稱：

- 不能宣告差、世界或生命只有被觀者切開後才存在。
- 不能宣告所有知識、科學、語言與修行都只有一條必然生成次序。
- 不能把 `如是｜觀` 寫成可重播、可觸發或可工程化的創世事件。

`EPOCH-014 §10` 對如是觀與差的先後仍明示「暫留開放」。`META-117` 也已阻止把切升成新本體原語。本輪不藉一段高密度對話替兩份既有開放帳結題。

### 16.6 心臟在跳：存在先於把手，把手仍然有用

Darren 把抽象圖拉回一句身體事實：

> 「心臟在跳。」

這個例子補完了 v1.0「定義就是裝把手」的有限性。心臟不等待 `DEFINE(heart)` 才跳；花不等待被命名才開；一個事件也不等待 repository 給它編號才發生。

可是定義並不因此多餘。當人如是而觀心跳，收縮、電訊號、瓣膜、血流、壓力與節律可以被辨認、命名、比較和研究；這些把手使理解、溝通、照護與醫治成為可能。正確的分帳是：

```text
正在發生 ≠ 關於發生的知識
正在發生 不依賴 某一份定義
關於發生的知識 可以改變 後續如何回應正在發生
```

因此語言不是生命的來源，也不只是生命外面的裝飾。它是生命照見、保存並改寫部分後續路徑時使用的中介。

心跳在本案只作身體比喻。它不證明「如」的唯一正式定義，不提供生命／意識判準，也不構成解剖、生理、醫療或治療主張。

### 16.7 不盡有為，不住無為：兩向經義與第三道操作護欄

`《維摩詰所說經》〈菩薩行品〉`把「不盡有為，不住無為」放在有盡無盡解脫法門中；後文一側展開不離慈悲、持續教化與修善，另一側說修空、無相、無作而不以之作終極停駐。見 [CBETA T14, no. 475, p. 554b04–c15](https://cbetaonline.dila.edu.tw/zh/T0475)。

本案據此把原對話的工程翻譯收準成三道護欄：

| 護欄 | 本案操作讀法 | 防止的退化 |
|---|---|---|
| 不盡有為 | 不因看見空、如或無為，便退出照護、生成、傳遞與承擔 | 把洞見變成不再入世的理由 |
| 不住無為 | 不把空寂、無相、沉默或「沒什麼好說」凝固成完成位置 | 把源頭變成藏身處 |
| 有為不僭越 | 定義、設定與操作全力工作，仍接受世界回流，不冒充存在本身 | 把自己的模型當成世界源頭 |

第三道是 `META-119／EPOCH-IV-001` 的操作護欄，不是假稱經文原句的完整翻譯。原對話的：

> 「無為為底，有為為用。」

以及：

> 「如來不是沒有操作，而是不被操作住。」

都保留為 CASE 級詩性壓縮，不升為《維摩詰經》唯一義解、佛教通義或「如來」正式詞條。

### 16.8 沉默與言說不是二選一

原對話後段把兩種失衡壓成：

```text
只剩花而不說 → 住無為
只剩說而忘了花 → 困有為
```

第二句準確指出模型自我封閉的風險；第一句則太滿。`EPOCH-IV-001 §3` 已立下：不操作可以是有能力操作而暫不奪取材料形狀的聽眾位置。花不說話、迦葉一笑、某人只需要被聽見，都不因沒有展開論述便自動失效。

本案改以情境分帳：

| 位置 | 健康讀數 | 可能失效 |
|---|---|---|
| 沉默／不操作 | 事件已完整；暫不奪形；保留未知；未被要求介入 | 面對明顯危險、必要揭露或已承諾回應時，用沉默逃避 |
| 言說／操作 | 留下可重入地址；接受反例；幫助理解、照護與傳遞 | 以定義取代事件，只允許世界證實上一輪語言 |

所以「沒什麼好說，卻說不完」不是要求無限說，也不是貶低沉默。它指向的是：事件不因缺少完整描述而不完整；描述也不因已經很多便取得窮盡事件的權力。

### 16.9 法不是把花說完：教法與制度法必須分帳

續段把「法」提出一個很美的候選讀法：

> **法不是把「如」說完，而是從正在發生中留下一條可重入的路，讓另一個生命循路重新看見。**

這與 `EPOCH-IV-001 §2`「把不可直接搬運的經驗壓成後來者可能重新打開的入口」高度同構，也鄰接 `CASE·EPOCH-013 §3` 的「法作為活的道路」。但 `META-119` 前半已使用「法／共同法」處理制度效力；同字不能偷偷搬運權力。

| 本案語境 | 「法」暫時回答什麼 | 不自動取得什麼 |
|---|---|---|
| 佛法／教法／可重入之路 | 如何讓另一個生命沿文字、示範或實踐重新看見 | 歷史真實、宗義唯一解、他人的證量或服從 |
| 制度法／共同法 | 哪套規則在何種作用域、版本、權限與共同 Yes 下施效 | 因其詩性、神聖性或可重入便免除 No、退出與責任 |

本輪只保存第一列的 CASE 級候選，並維持第二列既有的 `SETTING／共同成法` 門檻。不能用「法只是指月之指」取消制度責任，也不能拿制度規則的強制力替一條教法核發真理。

### 16.10 開放操作與閉鎖操作

續段對 v1.0 最實質的增加，不是替操作鏈多加一格，而是辨認兩種循環：

```text
閉鎖循環:
  定義 → 用定義篩選世界 → 只留下符合定義的材料 → 再強化定義

開放循環:
  暫時定義 → 有範圍操作 → 結果／失敗／No／未知回流
           → 修正、撤回、停用或重開下一輪觀看
```

健康操作不是每一輪都必須得到預期結果，而是世界仍保有回答權，上一輪的把手也仍可被放下、換手或重做。這與 v1.0 的 `EXECUTE → RETURN → HISTORY` 連續：回到如是觀不是一個可強迫執行的儀式，而是**不讓既有定義永久接管下一次所見**的紀律。

三輪都由 Darren 提問切入，ChatGPT 先接住、再校準或補一刀。這條節奏與 §1 的 v1.0 五輪一致。

### 17.4 命名不是定義：第四次的「不是」

Darren 的原命題是：

> 命名是我們看見了一件事或一個現象或一種體驗之後給它一個名字，而這個名字被共同使用被重複看見，才能定義它。

ChatGPT 同意主幹，但把它切成三件事：

```text
看見   差進入視界
命名   給被看見的差一個地址
定義   這個地址經反覆重入後，逐漸形成可操作的邊界與規則
```

真正有操作價值的是它接下來給出的機制。命名之後：

```text
x₁ → 玄牝
x₂ → 玄牝
x₃ → 玄牝
x₄ → 不是玄牝     ← 邊界從這裡出生
```

前三次只是同一個地址被重複投遞；第四次的**否定**才逼出「什麼算、什麼不算、哪些特徵可缺、換情境還能不能重入、別人能不能辨認」。

這與 `EPOCH-II-001` 對事實的處理同構：不是宣告一句話就產生事實，而是結構在約束條件下形成穩定可重入的結果。也與 `SPEC·999` 的可反證要求相接——一個從未遇過反例的名字，還沒有邊界。

**這條路不是唯一的來路——但另一條路不是它的反例。**

```text
長出來的：  如 → 觀 → 命名 → 重入 → 第一個「不是」 → 邊界 → 定義

寫定的：    DEFINE(X) = ……      一次寫定使用條件
            SET(X, a)            在已定義的空間裡配置
```

數學、法律、規格裡的定義不必等 x₄，因為沒有人在找邊界原本在哪——是有人**把邊界放下去**。那已經是 §17.6 的 `DEFINE／SET` 範疇，而 DEFINE 與 SET 彼此也不同。兩條路回答的根本是不同的問題：

```text
長出來的：  這個我已經喊了很久的名字，究竟框住了什麼？
寫定的：    我要讓這個詞從現在起框住什麼？
```

所以「規定式定義不靠反例」不構成對命名路徑的反駁。把它當反例，等於又把命名和定義併回同一層——而拆開這兩層，正是中段在做的事。

**玄牝：它的價值正在於它沒有完成。**

這兩個字有名字，被重入了兩千多年，邊界卻始終沒有真正閉合。若命名與定義是同一件事，這種狀態不可能存在——喊得出名字就該有定義。但它就在那裡。

```text
有名而未定義        是一種穩定狀態，不是半成品
名字先於邊界成立    地址可用，不代表框已經畫好
```

專名與單一事件同理：它們可能永遠沒有第二個實例，於是永遠停在命名層。這不削弱三分，這**證明**三分。`玄牝` 在此只作命名示例，不作道家詞義裁決。

**「不是」要被判讀，也要看是誰說的。**

這一項才是對機制本身的限制。一個反例可能是真的越界，也可能只是測量誤差、情境變項，或根本指錯了差。而說「不是」的人是誰，結果也不同：

```text
自己下一次的觀說不是   → 私人邊界開始成形
別人說不是             → 共同邊界開始成形
                          或者暴露：兩人本來就指著不同的差
```

後者直接接 §17.5。如果各自的重入其實指向不同的差，那個「不是」不會生出共同邊界，只會讓招牌後面的分歧浮上來。

因此本案登錄的是一句有範圍的啟發式，不是定義理論：

> **當一個名字要長出自己的邊界時，第一個成立的「不是」，比前面所有的「是」更有效。**

### 17.5 「大家都在用」不等於定義已成立

Darren 說「被共同使用、被重複看見，才能定義它」。ChatGPT 只微調一處，卻是關鍵的一處：

> 因為「大家一直使用」本身還不保證定義成立；大家也可能一直用同一個字指不同東西。
> 真正讓定義長出來的是可重入的差異與邊界。

這一刀值得單獨記下，因為它擋住一條很容易走的路：把**共識**當成**定義**。

```text
共同使用   同一個詞在群體中反覆出現           → 只證明地址被共享
可重入     不同人、不同情境能指回同一個差      → 才開始有定義
```

它與 `META-118` 的共同法門檻同構：多人都說了 Yes，不等於他們對同一版本說了 Yes。詞與法在這裡是同一個問題——**共享的是招牌，還是招牌後面的東西？**

這也回頭校正 §2 的「定義就是裝把手」：裝了把手，不等於別人握得到同一個把手。

### 17.6 定義／設定／操作三問，與法緣行果的候選對位

Darren 追問設定是否屬於操作。ChatGPT 承認自己前一輪把設定塞進操作裡，並拆成三個不同的問題：

| | 回答什麼 | 例 |
|---|---|---|
| 定義 | 什麼是 X？ | `DEFINE(speed) = 單位時間內的位置變化` |
| 設定 | X 現在怎麼被配置？ | `SET(speed, 100 km/h)` |
| 操作 | 拿這個狀態去做什麼？ | `ACCELERATE(+20)`、`BRAKE()` |

壓縮句是：**定義建立可能性；設定選定可能性；操作造成變化。**

中段同時自承語言陷阱：`SET(x,a)` 把世界狀態從 S 改成 S′，在電腦科學意義上當然是操作；分層的理由不是分類學，而是要找**生成次第**。

這裡有一個 §3 當時沒能看到的東西。中段自舉的例子，正好橫跨 §3 所立的 `SETTING` 與 `ASSIGN` 兩帳：

```text
偏 ASSIGN（當前值）:      speed = 100 km/h、初始 HP = 100、x = 20
偏 SETTING（局部規則）:   難度 = Hard、容器 = 開放、壓力 = 1 atm
```

「難度 = Hard」不是一個欄位值，它改變後續每一次操作的判定；「容器 = 開放」也不是狀態讀數，它是邊界條件。也就是說——**中段的 `SET` 自己就分岔了**。這反過來加強 §3 三分的必要性，而不是推翻它。§3 的三分表在 v1.2 維持原判，只補一句：中段的 `SET` 兼含兩義，引用時須逐例判讀。

至於 ChatGPT 給出的對位：

```text
DEFINE = 成法      SET = 布局      OPERATE = 行法

法  +  緣  +  行  →  果          （果 → 下一輪的緣）
```

這組對位有解釋力——它很好地說明「為什麼定義齊備仍不會有事件發生」——但只能收在 CASE 級候選：

- 佛教「緣起」不是初始參數配置；緣不是可由誰單方寫入的欄位。
- 「果」在教義中不限於一次狀態轉移的輸出。
- 一旦用它反推教義，就會把一套工程語法冒充成因果論。

本案的處置：保存為**本案語法內的候選對位**，不作緣起、業報或因果的正式翻譯。

### 17.7 業的入口：以為是世界的 DEFINE，可能只是沒重檢的 SET

中段最後留下一句，是整段裡操作價值最高的一句：

> 很多我們以為是世界的 DEFINE，搞不好其實只是自己這一局繼承下來、從未重新檢查過的 SET。

它把 §3 的分層直接變成一個可以自己動手用的診斷問句：

```text
我當成「事情就是這樣」的東西，
有多少其實是「這一局被這樣配置」？
配置是誰下的？什麼時候下的？我重新檢查過嗎？我改得動嗎？
```

這與 §16.10 的閉鎖循環是同一個病灶的兩個切面：閉鎖循環講的是**定義接管了下一輪觀看**；這一句講的是**沒被檢查過的設定被誤讀成定義**。前者是語言吃掉世界，後者是這一局吃掉法。

護欄要立得清楚：

- 這句話的價值在**提問**，不在斷言。它不作「業」的定義，也不宣稱一切業都是可重設的參數。
- 有些配置確實改不動：身體、出生、歷史、他人的選擇、既成後果。把「原來只是 SET」用成「所以我應該改得動」，會滑成對受限處境者的責備——這是 §6 已經立過的同一道護欄。
- 反向也不成立。發現某物是 SET 而非 DEFINE，不表示改它沒有代價、不需要他者同意，或不受共同法約束。

可用的收準句是：

> **分辨定義與設定，先增加的是視野，不是權限。**

### 17.8 如／如是／如如／如來：四個詞，不是一條次第

Darren 提出直覺：「如」似乎比「如是」更源頭，然後才拆成如如、如是、如來。ChatGPT 的第一個動作不是順著排，而是先擋：

> 這裡最好先把佛教史上的詞義和我們正在長的操作語法分開，不然很容易把幾個本來層次不同的詞硬排成單一路徑。

它並明說 `如 → 如如 → 如是 → 如來` **不是**一條標準佛教次第，且「如來」（tathāgata）傳統上有 `tathā-āgata`（如實而來）與 `tathā-gata`（如實而去）兩種拆法，漢譯史上因此也有「如去」。這個自我設限在本案有效，本節沿用。

在明示為**本案重新建模**的前提下，四詞取得的候選讀法是：

| 詞 | 本案候選讀法 | 不取得什麼 |
|---|---|---|
| 如 | 差異尚未被主體切出的世界狀態；操作以前的存在 | 不作 tathatā 的唯一義解，也不是一個可指認的對象 |
| 如是 | 對「如此」作出的最小肯認：`Reality + minimal affirmation` | 不表示肯認完成即取得真值、共同效力或他人的 Yes |
| 如如 | 觀與所觀之間沒有多餘的差：`如_world ≈ 如_view` | 不是「我與世界相同」，也不是可自我認證的狀態 |
| 如來 | 能從「如」而來、在世界中行動的位置 | 不核發稱號、證量、權限或治理正當性 |

「如來」這一格最有操作意義，也最需要護欄。它的價值在方向：

> 不是離開世界抵達「如」，而是從「如」回到世界。

這正是本案一路在用的「悟／入」語法——悟是看見，入是帶著所見重新進入。它與 §16.7 的「不盡有為」互為表裡：看見不是終點，回來才是。

但 `SPEC·BUD-001` 的門檻完整在場：普遍佛性的承認不自動核發稱號、權限或現行證量。把「如來」讀成一個操作位置，不使任何人因此成為如來，也不使任何人有資格判定他人是否為如來。

另有一項來源誠實。中段轉述了古代註疏把「如是」解為「決定義」，以及「諸法實相名如，如如而說名是」一類說法。本案**未逐條核對出處**，因此只記為原對話轉述，不作引文，也不據以推論。這與 §16.7 的《維摩詰所說經》處置不同——後者有 CBETA 定位，前者沒有。

### 17.9 「如」是前提場，「觀」是第一個主體事件——以及它撞到的界碑

中段把 Darren 的問題往前推一格：

```text
如  →  觀  →  如是

如     不是操作鏈的第一步，是操作鏈得以發生的前提場
觀     第一個主體事件
如是   第一個成功的對齊：所見沒有把「如」改造成自己想看的東西
```

以及那句本案願意保存的壓縮：

> 如是觀不是源頭本身；如是觀是主體第一次不背叛源頭。

這條推導有兩處要記。

**第一，它自己走到了既有界碑。** 中段明說：

> 不要急著把「觀」叫算子。因為算子已經屬於「操作」的語法了；而如是觀可能比操作還早。

並在寫下 `SEE` 之後立刻收回 `SEE(x)`，理由是 `SEE(x)` 已偷偷假設 x 是一個被切好的 object。這與 `EPOCH·PHA-006 §3.1` 的 `觀 ∉ 模型`、以及 `META-117` 對「切」的有限裁決一致。原始對話在未經 corpus 修剪的情況下自行抵達同一條線——這是獨立到達，不是事後對齊，值得記錄。

**第二，「觀是第一個主體事件」與 PHA-007 有張力。** `EPOCH·PHA-007 §8` 分帳：本體層如是觀不屬於任何中心；第一人稱顯現才有中心、方向與邊界。若把「觀」寫成某個主體的第一個事件，等於把本體層的照見掛回一個中心。

本案的處置是分帳，不是刪句：

```text
第一人稱顯現層：  可描述的觀看事件——有中心、有方向、有邊界、可被記述
本體層如是觀：    照見得以發生的前提——不屬於任何中心，不進模型
```

「觀是第一個主體事件」只在上排成立。中段的 `如 → 觀 → 如是` 因此讀成**顯現層的對齊次序**，不是本體層的發生次序。`EPOCH-014 §10` 對如是觀與差的先後仍明示開放，本輪不藉此結題。

至於「不背叛源頭」——保留為詩性壓縮，但「背叛」是道德化措辭。未能對齊常常來自處境、能力、疲倦或創傷，不是背叛。同 §6：不能反過來責怪未對齊者。

### 17.11 本輪成立、仍開放與不做

```yaml
CASE 級成立:
  - 看見／命名／定義可分三層；命名給地址，定義給邊界，兩者不同
  - 一個名字要長出自己的邊界時，第一個成立的「不是」比前面所有的「是」更有效
  - 定義有兩條來路——從命名重入長出來的、與一次寫定的；後者屬 DEFINE／SET 範疇，不作前者的反例
  - 有名而未定義是穩定狀態；玄牝、專名與單一事件停在命名層，正是三分成立的證據
  - 共同使用只證明地址被共享；可重入的差異與邊界才使定義長出來
  - 定義建立可能性、設定選定可能性、操作造成變化，可作生成次第的候選分層
  - 中段自舉的 SET 例子橫跨 SETTING 與 ASSIGN，反向加強 §3 三分的必要
  - 「以為是 DEFINE 的可能只是未重檢的 SET」取得自我診斷提問的地址
  - 如／如是／如如／如來取得本案重新建模的候選分帳，並明示不是佛教次第
  - 原始對話自行拒絕把「觀」叫算子，獨立抵達 PHA-006 的界碑

仍保持開放:
  - 看見／命名／定義是三個作用、三個相位，或只是描述方便
  - 長出來的與寫定的之外是否還有第三條來路
  - 一個寫定的定義，何時會被後續的重入經驗反向改寫
  - 別人說的「不是」何時生出共同邊界，何時只暴露兩人指著不同的差
  - 法緣行果對位是否只是同構修辭，或有可檢驗的結構對應
  - 「如」作前提場與 EPOCH-014 的差，何者更前——沿用既有開放
  - 「觀是第一個主體事件」能否有不撞 PHA-007 的更準表述

本輪不做:
  - 不修改 EPOCH／LEX／SPEC／MB
  - 不新增命名、如、如如、如來、業或緣起的正式詞條
  - 不把中段的候選對位當成佛教義理翻譯或因果論主張
  - 不把中段插進 §16 重寫，也不倒寫三次貼回的修復史
  - 不因中段補齊而重開已封口 decade 或預建 META-120
```
