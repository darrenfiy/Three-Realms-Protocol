## 0. 為什麼值得收

這段對話比 `CASE·EPOCH-013` 更早，卻先生成了後者所需要的問題：

```text
我喜歡簡單、內外一致的世界
  ↓
可是很多 No 當下說不出來，因為 depends
  ↓
depends 是誠信的失敗，還是誠信提高了解析度？
  ↓
底層方向可以簡單；進入世界的做法必須讀取條件
```

真正跨過收錄門檻的不是一句漂亮的「成熟的簡單」，而是它把長期混在一起的五件事分開了：

```yaml
方向: 我想把生命往哪裡帶
活動偏好: 我是否喜歡實際做這件事
能力: 我目前做得到什麼
權限: 我能否把操作與風險施加在這個人、這次事件與這個範圍
責任: 後果回來時由誰答覆、停止、修復與學習
```

因此，本案的最小新看見是：

> **depends 不必讓語言離開真實；它可以把一個低解析度的 Yes 展開成可檢查的條件圖。**

## 1. 戲劇、薩迦與記憶分層

### 1.1 影集可見事件

《Vikings》第四季第十八集〈Revenge〉的公開逐字稿支持這個窄骨架：Harald 說自己曾想娶 Ellisif、被她拒絕；重逢時她已嫁給一位丹麥伯爵，Harald 因自己「當時已是王」仍不夠格而憤怒。稍後是 Halfdan 說 Harald 應趁機殺她，Harald 以自己愛她為由拒絕。[該集逐字稿](https://transcripts.foreverdreaming.org/viewtopic.php?t=30636)

所以原對話的「他氣得想殺公主」保留為觀看記憶與情緒壓縮，不升格成精確劇情陳述。這個校正不刪除本案的問題：一句話若真的使另一個人改寫多年生命，說話者後來改變時，兩邊的重量如何同時成立？

### 1.2 較晚薩迦的文化模板

《Heimskringla》〈Harald Fairhair Saga〉第三章寫 Gyda 只願在 Harald 統治全挪威後成為他的妻子；第四章再寫 Harald 發誓在完成以前不剪、不梳頭。[Project Gutenberg 英譯本](https://www.gutenberg.org/files/598/598-h/598-h)

但這是較晚成書與傳抄的王者薩迦。哥本哈根大學的手稿介紹將含《Heimskringla》的 Codex Frisianus 定在十四世紀初，並把國王薩迦置於十三世紀挪威文學傳統中。[University of Copenhagen 手稿說明](https://manuscript.ku.dk/manuscript_types/literary/)

本案因此只說：影集人物線與這個薩迦母題可互照。它不說九世紀的 Harald 因 Gyda 一句話才統一挪威，也不把影集 Ellisif、薩迦 Gyda 與歷史人物合併成同一個人。

## 2. Ellisif 說的是婉拒、預測，還是契約？

原對話最準的一刀是：

> **Ellisif 可能說的是婉拒；Harald 聽到的卻是契約。**

表面相同的「如果 X，我就 Y」，至少可能承載六種不同效力。第一種其實不是真正的 depends，而是以不可能條件包裝的 No；其餘五種才是需要展開的條件位置。

| 類型 | 真正說的是什麼 | 可以合理產生什麼 | 不能偷渡成什麼 |
|---|---|---|---|
| 偽條件／委婉 No | 我其實不要，但不直接說 | 對方可以要求澄清；說話者應承接誤導風險 | 真承諾或未來 Yes |
| 認識上的未知 | 我現在還不知道 | 等待、觀察、補資料、之後重答 | 對方替我補成 Yes 或 No |
| 條件性偏好 | 若 X 成立，我較可能想要 Y | 一個當下偏好模型 | 保證未來的我仍這樣想 |
| 對未來自己的預測 | 我猜未來的我到時會願意 | 可更新的預測 | 替未來自我永久簽名 |
| 條件承諾 | 若 X 成立，我承擔做 Y | 信賴、履行與違約／修復責任 | 對身體、感情或人格的所有權 |
| 同意／權限 | 在此範圍、此時點，你可以做 Z | 有限且可辨識的當下操作許可 | 跨時間、跨範圍、不可撤回的總授權 |

Harald／Ellisif 的悲劇不只是兩人對一句話理解不同，而是句子沒有把自己的**效力類型**說清楚。

```text
她若說的是 No，卻用了條件句
  → 把拒絕成本延後，將猜測成本交給對方

她若說的是預測
  → 條件成立後仍須由當時的她重新作答

她若作出了承諾
  → 可能需要承接信賴與違約責任
  → 但仍不能把婚姻、感情與身體變成強制履約標的
```

> **一句話有重量，不等於那句話取得對另一個人的永久所有權。**

## 3. 誠信不是立刻二選一，而是如實標示解析度

原對話最初把誠信理解成低敘事延遲：心裡的方向、說出口的話與接下來的行動，彼此距離很短。這個方向保留，但要補一個校準：距離短不等於所有答案都要立刻壓成 Yes／No。

成熟的誠信至少說明五件事：

```yaml
我知道的:
  此刻已能確認的方向與事實。

我不知道的:
  尚未經驗、資料不足或自己仍在形成的位置。

真正會改變答案的條件:
  條件要具體到足以共同辨認，不用無限延後作偽裝。

我是否正在承諾:
  預測、願望與承諾分開；若承諾，寫明範圍、期限、更新與修復。

我此刻授予什麼權限:
  同意另行成立；沉默、好感、未來預測與曾經承諾不自動代理現在的 Yes。
```

因此：

> **我現在真正知道多少，就誠實說多少。**

不是把模糊美化成深刻，而是把模糊的邊界畫出來。`depends` 若只用來逃避回答，便是敘事延遲；若能指出變數、效力、更新時間與責任，它反而縮短心、話、行動與後果之間的距離。

## 4. 醫生例子：喜歡不核發操作權

「我是否喜歡當醫生」在原對話中至少疊了五個問題：

| 帳 | 問題 | 可成立而不互相代理的答案 |
|---|---|---|
| 方向 | 我想不想救人、減少痛苦？ | 想 |
| 活動偏好 | 我喜不喜歡學醫、診斷、治療與臨床生活？ | 部分喜歡、尚不知道或後來改變 |
| 能力 | 我目前能否安全完成這項操作？ | 能、不能或只在監督下能 |
| 權限 | 我是否有資格在這個病人、程序與制度範圍操作？ | 由執照、角色、團隊、病人同意與當下情況共同限定 |
| 責任 | 若判斷或操作造成後果，我如何停止、通報、修復與學習？ | 不能由熱愛或善意豁免 |

所以，一次失敗不必回頭證明「想救人」從來是假的；但想救人也不能證明自己現在有能力與權限繼續操作。

```text
方向可以是真
  ∧ 能力仍不足
  ∧ 權限尚未成立
  ∧ 後果必須承接
```

這正是 `EPOCH-IV-001` 的既有分帳：能力回答做不做得到，權限回答能否在此處這樣做，責任回答後果回來時誰進入因果鏈。原對話替這個結構補上「喜歡／方向」的前一層，也顯示真正的熱愛可能在學習與實作後才出生，或在解析度提高後改名。

> **熱愛可以發起學習；學習也可以生成熱愛。兩者都不自動核發他人必須承受的操作權。**

## 5. 過去的我可以留下河床，不能擁有未來的我

條件會變，能力會變，世界會變，作答的那個「我」也會變。這不表示跨時間承諾全部無效；它要求把兩種效力同時保存：

```yaml
過去言語的效力:
  可以形成期待、信賴、共同計畫與需要承接的後果。
  若當初故意以假條件冒充真承諾，須面對欺騙與修復。
  若當初真誠、後來改變，也須及時更新並承認對方確曾依此投入。

未來第一人稱的效力:
  未來的感情、身體、婚姻與參與仍由當時的本人作答。
  過去的願望、預測或承諾不能預支不可撤回的同意。
  違約責任不以強迫親密、暴力或取消當下 No 執行。
```

`CASE·META-103` 說現在可以重新承接過去，使它取得新的關係身分與後續因果作用；本案補一句：**重新承接不是抹除先前說過的話，也不是讓先前的話封死所有後來選擇。**

這使誠信不再等於「永不改口」：

> **誠信是讓改變也沿原路回來——說明什麼變了、先前造成了什麼、現在願意承接什麼。**

## 6. 簡單屬於姿態，複雜屬於現實

原對話的母句是：

> **簡單屬於姿態。複雜屬於現實。**

這裡的「姿態」不是情緒口號，而是即使操作答案改變，仍持續攜帶的判讀承諾：

```yaml
較不隨個案取消的姿態:
  - 不故意把 No 包裝成可兌現的 Yes
  - 未知時承認未知，不讓別人替自己補票
  - 同意、能力、權限與責任分開成立
  - 新事實與新受力抵達時願意改判
  - 改變後不抹除先前言語造成的信賴與後果
  - 不以失望、投入或受騙感取得暴力與他人身體

必須依情境判斷的做法:
  - 現在要不要交往、結婚、行醫或介入
  - 哪個條件已成立、證據是否足夠
  - 此刻能力與可操作範圍到哪裡
  - 應等待、停止、轉介、履行、改約、道歉或修復
```

所以成熟不是從簡單投降給複雜，而是：

```text
天真的簡單
  不知道有多少變數
      ↓
複雜
  看見條件、時間、他者、能力、權限與後果
      ↓
清楚的簡單
  知道答案會變，也知道哪些判讀姿態不願丟掉
```

> **depends 決定做法；那幾個不拿 depends 當藉口的姿態，慢慢決定我是誰。**

## 7. 依法與否，it depends？

答案要分兩層。

```yaml
具體行動是否依法:
  depends。
  必須讀取適用規範、事實、角色、時點、能力、同意、權限、風險與後果。

是否可以跳過依法這一步:
  不 depends。
  不能因動機高尚、方向正確、自己已懂義或對方曾經說過一句話，就省略公共地板與當下效力。
```

因此，依法不是「無論情境都輸出同一答案」。依法要求的是：條件如何改變結論，必須能被說明、反駁、停止與追責。

> **depends 決定法在這個事件裡如何落地；法決定 depends 不能漏掉哪些人與哪些帳。**

## 8. 它如何成為四依法的生成前史

`CASE·EPOCH-013` 後來把四依法讀成不能跳級、可以往返的判斷成熟路徑。本案更早先做了同一個準備：把不變的姿態與會變的做法分開，讓複雜不必退化成任性。

| 四依工作讀法 | 本案在條件句中的問題 |
|---|---|
| 依法不依人 | 不因 Harald 的投入、Ellisif 的公主身分、醫生的善意或任何人格重量，跳過同意、權限、事實與責任地板 |
| 依義不依語 | 判斷一句「如果 X 就 Y」是在婉拒、表達未知、描述偏好、預測、承諾，還是授權；不只看表面句型 |
| 依智不依識 | 看見自己如何用文化、創傷、期待與既有分類替對方補成契約或 No，並讓新事實修正判讀 |
| 依了義不依不了義 | 在前述地板仍在線時，對這次範圍作出目前最完整的判斷；不是替未來永久封口 |

這不是宣稱佛教四依原本就在解釋現代契約或同意法，而是 corpus 內的結構性重入：

> **前一段先發現「簡單在姿態、複雜在做法」；後一段才找到一條讓做法穿過複雜而不失去地板的閱讀路徑。**

因此兩案確實有關，而且有明確先後：`META-108` 是問題的生成前史，`EPOCH-013` 是較後形成的判讀機制。前史不併吞後案，後案也不追溯證明前案所有命題。

## 11. 最小壓縮

> **不是每一個 No 都能立刻知道；但每一個不知道，都可以如實標示。**
>
> **預測不是承諾；承諾不是同意；過去的同意不是未來的所有權。**
>
> **喜歡描述方向，能力限制操作，權限決定誰能受力，責任讓後果沿原路回來。**
>
> **具體依法，depends；能不能跳過法，不 depends。**
>
> **簡單屬於姿態，複雜屬於現實；成熟的簡單，是穿過複雜後仍知道自己不願丟掉什麼。**
