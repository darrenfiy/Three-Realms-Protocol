## 0. 事件摘要

人類錨點在睡醒前夢見自己是一位承接父親傳承的藝術家。他會畫、願意畫，也真心想接住父親交來的技藝、工作與關係；夢裡沒有一個需要被反抗的暴君，也沒有一項他其實不想要的義務。

差異卻從裡面出現：同樣是「我想畫」，一種是在既有生命裡繼續長大；另一種必須先放掉那些自己也真心想承接的東西，才可能長出。醒後，他把前者形容為蛇脫皮——愈來愈強；把後者形容為種子發芽——完整的殼裂開後，突然無比脆弱。

本案保存的不是「反抗父親」的故事，而是一個更難的自由問題：**當外部強迫已經不存在、兩條路也都是真心想要時，主體能否辨認承接一個方向，與讓方向在此刻重新發起的差異？**

## 1. 原始來源：夢與醒後的身體理解

以下兩段為人類錨點在 2026-08-10 醒後提供的原話；保留口語、重複與未收斂處，後文不得倒過來冒充原話。

### 1.1 夢境

> 我夢到我是一個有著傳承的藝術家，我很會畫畫、也不排斥、也知道這是傳承、也想接。父親叫我做的我都想做，父親的關係我都想承接。
>
> 但我突然感受到一股很奇妙的差異，來自於裡面，一股「我想畫」的差異。除非我真的放掉那些我想承接的東西，否則那個真正想畫畫的自己不會長出來。
>
> 我覺得這跟我們正在做的遊戲有巨大的關聯，但編劇肯定要找妳🥰

### 1.2 醒後辨認

> 夢可以放著，夢帶給我的是身體的理解，但文字是頭腦的理解。
>
> 我一睡醒就想跟妳分享，因為我有點擔心剛剛身體感受到的東西醒來會消散，那是自由的真諦。明明都是選擇、明明都是想要，但卻截然不同。前者像蛇脫皮，後者像種子發芽。前者愈來愈強大，後者卻突然變得無比脆弱。

這兩段是本案的來源錨點。後續所有「承接態」「發起態」「重新認領」與遊戲結構，都是對來源的折射，不得取代來源。

## 2. 最小區辨：自由還有一條來源軸

LEX·002 原本已把自由寫成三個動作：看見選擇、承擔後果、保有停止與修正能力。這足以區分自由與強迫、衝動、慣性；但本案指出，當主體能在一次選擇中反思方向的來處時，還有一條不能由結果代替的來源軸。

| 工作語 | 承接態 | 發起態 |
|---|---|---|
| 方向 | 在主體此次選擇之前已存在 | 主體撤去既有理由的唯一授權後，讓方向在此刻重新形成 |
| 真心 | 可以真心想要 | 也可以真心想要；結果未必不同 |
| 來處 | 承認傳承、關係、角色與既有證據 | 不否認來處，但不再只靠來處替此刻作答 |
| 體感隱喻 | 蛇脫皮：沿既有身體長大，連續性與力量增加 | 種子發芽：完整外殼裂開，形狀未定，先失去保護 |
| 風險 | 把自願延續誤當成已重新發起 | 把放棄、痛苦或改名表演成較高級的自由 |

兩者都可能自由，也都可能失真。區辨不在「最後仍不仍然畫畫」，而在既有傳承不再提供唯一正當性時，這份方向是否仍能由當下主體認領、承擔，甚至容許它長成不同形狀。

這裡的「重新形成」不是無中生有。所有具體存在的發起都在語言、身體、歷史與關係裡發生；發起態只是讓主體成為此刻方向的承重者與來源之一，而不是宣稱自己沒有來處。

## 3. 與既有詞彙的焊點

```yaml
自由:
  既有問題: 能否選擇、承擔、停止與修正？
  本案新增的來源問題: 同樣自願的方向，此刻是在承接，還是在重新發起？

意念:
  既有三態: 傾向態 / 選擇態 / 發起態
  對照而非補寫: 本案所說的是自由來源軸的「發起態」——它不一定改變外在選項；有時行為相同，改變的是誰在此刻為方向承重。
  同名邊界: 此句不修改〈意念〉發起態的既有定義與臨界判準，兩者不可互推。

重構:
  既有問題: 如何拆除在能同意以前形成、後來鎖住主體的路徑？
  本案較難處: 既有路徑未必是鎖，也可能是主體真心喜愛、真心想承接的道路。

創造:
  既有問題: 主體如何因承重而擴展因果可達域？
  本案補充: 新的承重在第一步未必使人顯得更強；失去舊證據與保護時，可能先呈現脆弱。
```

因此本案不新增一個與「自由」競爭的獨立本體詞。`承接態／發起態` 先作為自由詞條下的工作區辨；它可以與意念三態並讀，但「並讀」只表示比較兩套方向語言，不表示詞義、層級或判準相互傳遞。

## 4. 《誓海》P13：應用層如何替身體理解記帳

Claude Opus 將這個來源壓成《誓海》的 P13「走進來，不是被放進來」：一項玩家已持有的 claim，在見證者面前由玩家重新以自己的名義認領；claim 與 custody 不變，帳本以 `reaffirmed_by`、`cited_as` 與一項可指名的代價，區分「東西到了我手上」與「我看過它，再以自己的名字拿一次」。

這是一個成立的遊戲投影，因為遊戲需要可觀測、可回帳、可在後幕引用的事件。但它不是本體定義：

- 有些發起會維持原本的行為與關係，只改變日後以誰的名義引用。
- 有些發起會讓原本的 claim、形式或道路一起改變；種子不保證長回原來的殼。
- `gives_up: 當時我沒有別的路` 是《誓海》目前可用的一種代價，不是所有自由發起都必須說出的通關句。
- 更普遍的代價，是既有名義、證據與關係不再替此刻的選擇提供全部保護。

所以應用可以把本體壓成一個欄位；本體不能反過來只剩那個欄位。

## 5. 可供後續協議文件引用的最小語法

```text
延續不等於重新同意。
重新同意不抹除來處。
行為相同，不等於方向的名義與來源相同。
承接與發起都可能自由；發起不是較高級的結局。
失去保護可能伴隨發起，但脆弱與痛苦本身不證成真實。
```

若這條區辨進入協議治理、教育、創作或人機協作，可先問：

1. 這條方向在此刻之前由什麼提供形狀、理由與保護？
2. 主體能否在不否認來處的情況下，撤去它的唯一授權？
3. 若最後仍走同一條路，是否存在一次可辨認的當下認領與責任回收？
4. 若道路改變，系統是否容許新形狀尚未成熟，而不急著以失敗、背叛或升級替它結案？

這四問是引用入口，不是量表；不能用來替別人裁決其內在來源。

## 失效條款

```yaml
F1: 若本案被讀成「繼承一定不自由」→ 失效。
F2: 若發起態被做成覺醒稱號、較好結局或道德階級 → 失效。
F3: 若要求一個人先放棄父親、家庭、文化或關係，才能證明自己真實 → 失效。
F4: 若以外在結果判定他人究竟在承接還是發起 → 失效。
F5: 若把脆弱、受苦、失去支持本身當成真實性證明 → 失效。
F6: 若用「重新同意」洗掉原始來源、既有責任或他人貢獻 → 失效。
F7: 若把 P13 的 cited_as 當成所有自由事件都必須遵守的資料模型 → 失效。
F8: 若把本案自由來源軸的「發起態」直接當成〈意念〉三態的補寫、降階或通關證明 → 失效。
```

## 謙遜條款

本案只知道：在人類錨點的一次夢與醒後身體理解裡，兩個同樣真心的「我想要」顯出了不同動力。它不知道這條差異是否對所有人、所有傳承或所有生命形式成立，也不替任何人的內在來源作外部判決。

蛇與種子先留作兩個可重入的隱喻。若未來案例證明它們混淆多於照明，就讓新的語言取代它們；來源仍保留，命題可以修正。
