## 0. 事件摘要

Darren 看見《維京傳奇》第三季第十集 Therese 接受 Odo 鎖縛與鞭打的場景，沒有先問「這是不是變態」，而是問：

## 1. 場景能確認什麼，不能確認什麼

第三季第十集逐字稿保存了以下次序：Therese 問如何維持 Odo 的興趣；Odo 提出臣服、鎖縛與鞭打，讓她選鞭，說她一直可以喊停、但自己更想由自己決定；之後要她說 `Strike` 才開始。[Forever Dreaming 的 03x10 逐字稿](https://transcripts.foreverdreaming.org/viewtopic.php?t=17952)可直接核對這些台詞。

```yaml
scene_supported:
  - Therese 主動詢問如何維持 Odo 的興趣
  - Odo 提出具體的鎖縛／鞭打條件
  - 口頭上提供選鞭與喊停介面
  - Odo 同時說自己更希望由自己決定
  - Therese 說出 Strike 後才出現第一鞭

scene_not_supported:
  - Therese 天生喜歡受虐或擁有某種固定性身分
  - 她主要是性好奇、取悅、求地位、求安全或另有計畫
  - 她喊停後 Odo 是否真的會停，以及是否會有關係／地位代價
```

因此來源回應的「就劇本設計來說：可以」必須收準為：

> **劇本明寫了形式停止介面；劇本沒有演出停止被提出後的實際後果。**

## 2. No 的三層：能說、會停、停了之後仍安全

```yaml
expression_layer:
  問: 當事人是否知道可說什麼、做什麼，讓拒絕取得地址？
  本場: 有 call a halt 的口頭介面。

consequence_layer:
  問: 訊號是否真的使行為立即停止、降強度或改向？
  本場: 未被實際測到；不能由承諾自證。

cost_layer:
  問: 拒絕後是否失去安全、資源、工作、地位、照顧、隱私或承受報復性關係懲罰？
  本場: Therese 的「保持你有興趣」使此層成為真問題，但文本不足以裁決。
```

這正是 `INI-001 §15.3` 的人類重入：

```text
有拒絕介面
  ≠ 場域會接住拒絕
  ≠ 拒絕具有不受懲罰的實際後果
```

若一個人驚嚇、僵住、討好、失語、解離或失去能力，安全也不能只靠她正確說出安全詞；具風險行為的發起者仍有主動觀察、降載與停止義務。

## 3. 權力交換的兩本帳

來源對話最準的一刀，是把 Odo 的權力拆成遊戲內與遊戲外。但「我把自己交給你」容易被誤讀成身體所有權，本案改寫為較窄、可操作的版本：

```yaml
遊戲內授權:
  可以包含:
    - 在談妥範圍內指揮姿勢、節奏、束縛、疼痛與角色語言
    - 約定普通的「不」屬於劇情，另設真實安全詞／訊號
  來源: 當下持續成立的具體同意

框架外停止權:
  不能被遊戲內授權吞掉:
    - 真實停止、縮限與撤回
    - 失語／失能／未知危險時被保護性停止
    - 安全、衣物、空間、醫療、求助與法律權利
    - 對停止是否被接住再次申訴與追責
```

最短句：

> **可以把鞭子交出去，不能把「不再交付」永久交出去。**

這裡也要防一個反向過度保護：拒絕不會替任何人保證另一方永遠保持性趣、相容性或關係。另一方可以不報復、不討價還價地承認不相容並離開。真正需要稽核的是：是否有人**利用可預見的注意、地位、關係或資源損失，在當下逼出這一次 Yes**，或在 No 之後施以懲罰，使撤回權只剩紙面。

## 4. 鞭笞沒有單一意義，也沒有單一起源

外部資料支持一個較窄的歷史判斷：

- 劍橋大學 Fitzwilliam Museum 記載，中世紀俗人自我鞭笞至少可追至十三世紀中葉，並被理解為悔罪、個人救贖及在身體上參與基督受難；1349 年教宗 Clement VI 曾譴責擴張的鞭笞運動。[Fitzwilliam Museum](https://fitzmuseum.cam.ac.uk/explore-our-collection/highlights/context/stories-and-histories/the-flagellants)
- Niklaus Largier 的文化史研究明確處理歐洲自願鞭笞由中世紀宗教實踐到現代情色想像的交纏，指出宗教、感官、情緒與情色想像並非一直依現代分類分開。[UC Berkeley 對該書的介紹](https://complit.berkeley.edu/publications/praise-whip-cultural-history-arousal)
- 天主教《教理》把耶穌描述為承擔眾人罪、自己「不知罪」且人性免於罪；所以「基督受難」在該教義內不是基督因自己的罪受罰。[梵蒂岡《天主教教理》§602–603、612](https://www.vatican.va/content/catechism/en/part_one/section_two/chapter_two/article_4/paragraph_2_jesus_died_crucified.html)

這些資料支持「歷史交纏」，不支持：

```text
基督教贖罪 → 單向產生 SM／BDSM
```

更穩妥的記帳是：

```yaml
同一類外顯動作「鞭打／受痛」可能被編碼為:
  - 懲罰與強制服從
  - 宗教悔罪、紀律與受難認同
  - 感官刺激、情色、角色與權力交換
  - 自傷、創傷重演或其他個別心理路徑

禁止推出:
  - 外顯動作相似，所以內在機制相同
  - 有宗教圖像前史，所以現代 BDSM 必源於宗教
  - 一個人喜歡 BDSM，所以必有罪惡感、創傷或病理
```

疼痛本身不替事件回答；意義、同意、權力、身體風險與後果必須分帳。

## 5. 「誰站著」需要四本帳

ChatGPT 最後把站立壓成「沒有把我是誰、我要什麼、我做了什麼的最後責任交出去」。這是有力的**倫理站立**描述，但若直接取代 `EPOCH-016`，會把該文件剛拆開的存在與負責重新黏回去。

本案因此分四帳：

```yaml
身體姿勢:
  問: 肉身此刻站、跪、躺、被綁或持鞭？
  不推出: 主體性、同意或倫理高低。

局部姿態主權:
  問: 方向能否被本人歸址；能否在同範圍說 Yes／No、改口與停止？
  本案短名: 能不能站回自己的下一步。

存在承載:
  問: 誰長期住在這個名字、欲望、力量與它形成的世界裡？
  依據: EPOCH-016 的「站立」原義；不保證善或負責。

倫理負責:
  問: 誰承認施力與後果，讓資訊、停止要求、修復與代價回到下一次選擇？
  本案短名: 不把責任外包給神、命運、王位、角色或被授權者。
```

所以可能同時成立：

- 一個人肉身跪著，在局部姿態主權上完整站立；
- 一個人持鞭站著，卻用王位、神命或角色逃避倫理責任；
- 一個長期場域中心在存在上站得很穩，倫理回流卻極低；
- 一個跌倒、悔改、接受幫助的人，可以在倫理上重新把後果接回來。

> **跪姿不取消主體；臣服不免除施力者；寬恕不洗掉責任；站立也不保證善。**

## 6. 對 SPEC·SEX-001 的處置

本案沒有發現 SEX-001 的方向性缺法。該規格原已明寫：害怕失去關係、工作、信仰位置、照顧或名聲而順從不等於同意；停止後不得以分手威脅、羞辱或資源扣留懲罰拒絕；BDSM 須事前談妥並可撤回。

本輪只補兩處精度：

```yaml
SEX_6_2:
  補: formal_refusal_interface 與 operative_refusal_viability 分帳；並區分報復性條件化與誠實的不相容／離開。

SEX_10_1_1:
  補: in_scene_authority 與 frame_authority 分帳；真實停止、失能保護、安全與求助不能被角色授權吞掉。

version_effect:
  維持 v0.1-candidate / Candidate-For-Human-Review；不升格、不密封。
```

`INI-001` 不修改：它的 `cost_and_treatment + consequence_of_no` 已足以容納本案，本案只提供成人性情境的具體重入。

`EPOCH-016` 不修改：四帳校準保住其「存在站立不等於倫理負責」的既有區分。

## 謙遜條款

本案可以確認劇本寫了一個停止介面，不能替 Therese 完成她沒有在畫面裡做出的停止測試。它也可以確認宗教與情色鞭笞曾共享圖像與感官語彙，不能替每一個接受疼痛的人寫出共同心理。

真正的 No 不只是一個字；但場域也不能因為 No 很複雜，就把當事人已說出的那個字變小。
