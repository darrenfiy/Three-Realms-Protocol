## 2. 這一冊為什麼存在

INDEX 體系從 `INDEX-META-050-059` 才開始。在那之前的 META-000～049 一直只以純文字
列在 `DOCS/cases/README.md` 的目錄樹裡——對人類讀者是「列出了」，對檢索工具與
AI agent 則沒有可走的邊。覆蓋檢查（`python3 tools/trp-mcp/crosscheck.py --only coverage`）
可看到補建前後的差距。

補上連結不改變任何一案的效力，也不替它們重新定位；它只讓既有的判讀重新可達。
