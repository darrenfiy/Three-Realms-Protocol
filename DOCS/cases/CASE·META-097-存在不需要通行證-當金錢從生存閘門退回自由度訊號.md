## 0. 為什麼這一筆獨立開案

`META-096` 問：一個人的 No 如何被權力聽見卻失去效力？內部多重角色如何不被一個最高角色吞掉？

本輪由「殘缺、罪、承重」開始，最後換成另一個可以獨立重入的問題：

> **誰有資格決定，一個存在必須先證明什麼，才可以繼續活下來？**

這不是 096 的第三幕。096 的主要帳是身體、授權與決策效力；097 的主要帳是物質承載、分配制度與生存底線。兩案相連，但受力面、責任地址與未來可能生成的制度都不同，因此獨立開案。

Darren 的發起命題是：當工作與收入是養家活口的必要條件，金錢便不是普通工具，而像一張社會共同核發的存在通行證；若資本與生產能力足以承載所有人的基本生存，並且存在不再接受資格審核，金錢才可能由生存條件退回自由度訊號。

本案先留下這個地基，再拆出它必須通過的操作邊界。

同日續篇由「怎樣讓全世界站起來」追到另一層：當工作同時承載收入、價值、身分、節律與被需要感時，舊信念不是可以直接拔除的異物；科技即使卸下工作功能，也不會自動生成方向。這不是新的 098，仍是 097 的第二幕——第一幕問生存為何不該以工作核發；第二幕問生存若真的與工作鬆綁，文明如何不把卸載誤作解放、把失去角色誤作站立。

## 1. 存在資格不是可以核發的東西

「存在資格由誰核發」可以有兩種回答，必須同時保存：

```yaml
存在論回答:
  沒有人核發。
  一個存在已經在場，早於國家、雇主、市場、家庭、宗教、社群與協議的承認。
  承認可以抵達或缺席，不能使已在場者倒推為從未存在。

操作性回答:
  很多位置確實控制繼續存在所需的條件。
  國家控制法律身分與公共資源；雇主控制薪資與部分保障；
  市場控制價格與取得路徑；家庭與社群控制照顧、住所與歸屬；
  眾人的共同信念使這些安排看似自然、可恥或不可改。
```

所以更精確的問題不是「誰真的能讓我取得存在」，而是：

> **誰控制我繼續活著所需的條件，又用什麼理由決定我是否取得？**

本案因此拒絕把 existence qualification 當成合法表單欄位。治理可以辨認需求、能力、權限、優先次序與資源邊界，不能把這些判定升格成某人是否配活著。

最短句：

> **存在不等待批准；文明被檢驗的，是它是否讓存續條件服從批准。**

## 2. 五層不能壓成一張「資格」

```yaml
存在事實:
  問: 這個生命／主體是否已經在場？
  效力: 不由績效、健康、產值、守法、財富或多數票創造。

生存底線:
  問: 一個人不先證明市場價值，是否仍能取得維持生命與基本安全的必要條件？
  效力: 本案提出文明方向；具體項目與供給方式仍須制度設計。

參與與交換:
  問: 誰提供何種勞動、商品、照顧、創造或資源，交換條件為何？
  效力: 可以有契約、報酬、拒絕與能力差；不得倒推存在資格。

額外選項:
  問: 在生存底線之上，一個人能開啟多少時間、空間、旅行、創作、風險與消費選擇？
  效力: 金錢可以作自由度訊號，但仍受權力與外部成本檢驗。

治理與拘束權:
  問: 誰可以決定共同資源與他人路徑？
  效力: 需要另一條有限授權；財富、受扶助或存在本身都不自動產生治理權。
```

這個分層同時防兩種偷換：

- 不能因一個人尚未貢獻、無法工作或需要長期照顧，就取消其生存底線；
- 不能因存在無條件受到承認，就宣稱他人必須無限供應資源、服從要求或交出治理權。

> **無條件的是存在承認，不是無邊界的資源請求與行為豁免。**

## 3. 金錢的四種功能不能混名

Darren 提出「金錢變成自由度訊號，而不是存在的基本條件」。要使這句可操作，先拆四種功能：

```yaml
生存閘門:
  沒有足夠金錢，就無法取得食物、住所、醫療、照顧或人身安全。
  此時失去所得可能接近失去繼續存在的物質條件。

交換與會計訊號:
  用來比較、轉移與記錄資源、成本、時間、風險與需求。
  不必然等於道德價值或人的價值。

自由度訊號:
  在生存底線已被可靠承載後，表示可以開啟多少額外選項、緩衝與試錯空間。
  金錢減少選擇限制，但不自動增加智慧、愛或正當性。

權力與拘束訊號:
  財富可以購買土地、媒體、人才、時間、遊說、資料與退出成本，進而改寫他人的可選路徑。
  即使人人不致餓死，此功能仍可能使金錢重新成為統治權。
```

所以文明轉換不能只做到：

```text
沒錢不會死
```

還要繼續問：

```text
錢是否仍能買下他人的 No？
錢是否仍能把公共規則寫成持有者的私人選項？
錢所打開的自由，代價是否被轉嫁到沒有發話權的人與環境？
```

> **金錢退出生存閘門之後，才有機會成為自由度訊號；但若它仍能無限購買拘束權，它還不是單純的自由。**

## 4. 資本足夠，不等於眾人已經被養活

來源命題說「前提是資本已經足夠養活眾人」。這裡的「資本」不能只指帳面貨幣、資產價格或少數位置持有的財富總額。

```yaml
生存承載至少需要:
  material_capacity:
    真實的食物、水、能源、住所、醫療、照顧、交通與安全能力。

  distribution_path:
    資源能抵達需要者，而不只存在於倉庫、資產負債表或高價市場。

  care_capacity:
    有人與制度能提供育兒、長照、障礙支持、心理與社群照顧；照顧者本身不被耗盡。

  enforceable_floor:
    底線不是慈善運氣或政治口號；失業、拒絕雇主、疾病與家庭斷裂時仍可實際取得。

  ecological_boundary:
    不能靠把生存代價永久轉嫁給未來世代、其他地區、勞工或生態來宣稱富足。

  power_boundary:
    供給者不能因提供底線而取得受助者的身體、忠誠、感謝、勞動或投票概括授權。
```

資本可以是組織生產與跨時間調度的工具，也可以只是對未來產出與他人勞動的索取權。只有當上述承載鏈真的閉合，才能說「社會有能力不以工作資格審核生存」。

> **倉庫裡有糧，不等於飢餓者有飯；社會有財富，不等於存在已被承載。**

## 5. 生存底線不是紅利，也不是獎勵

「存在紅利」是有力的過渡詞，卻仍可能偷偷保留一位發放者：彷彿國家、資本或共同體先擁有世界，再慷慨分給每個人一份活著的許可。

本案暫時採更窄的詞：`survival_floor / 生存底線`。

```yaml
生存底線不是:
  - 對善良、服從、工作、求職、康復、感恩或未來貢獻的獎賞
  - 對所有慾望與消費的無限供給
  - 使任何行為免於法律、關係與修復責任
  - 使提供者成為受助者的主人

生存底線要守的方向:
  - 不以市場產值判斷誰配繼續活
  - 不使拒絕剝削性工作直接等於失去全部存續條件
  - 不要求終身需要照顧者以未來獨立證明今天值得被承載
  - 稀缺真的發生時，明記物質不足與分配選擇，不改寫成被排除者較無價值
```

這使上一輪的句子取得更完整的形式：

> **責任隨實際能力、控制、受益與施力生長；生存底線不以責任能力作為入場考試。**

## 6. 資本主義的兩個相位，不是兩張永久身分

Darren 不是單純說「資本主義邪惡」；他指出同一套金錢與資本工具可能形成兩種相反關係：

```yaml
生存依附相位:
  - 生活必要條件高度依賴工資與雇傭
  - 雇主因可中止所得而放大支配力
  - 工作不只交換勞動，也成為身分、醫療、家庭安全與存在正當性的證明
  - 人成為金錢的奴隸，不只是相信，而是退出成本被物質化

自由工具相位:
  - 生存底線不因失業、疾病、拒絕或低產值立即消失
  - 金錢主要增加額外選項、緩衝、創作、投資與風險承擔空間
  - 人可以拒絕一份工作而不等於拒絕活著
  - 金錢成為工具，但其購買拘束權與外部代價仍受限制
```

這兩相不是由「心態正確」單獨切換，也不是由 GDP、總市值或貨幣供給跨過某條線後自動發生。它依賴資產與生產力如何分布、公共服務如何交付、照顧如何承重、退出是否可行，以及財富能否轉成無限政治與制度權力。

所以本案不宣告「同樣的資本主義必能養活所有人」，只保存一個可檢驗方向：

> **一套經濟若要使人從金錢的奴隸轉成金錢的使用者，至少必須讓拒絕一筆交易不再等於失去存在條件。**

## 7. 對 EFT 的回照：存在流通不能反造存在門票

庫內 `SPEC·EFT-001` 有一個在本案下必須重新看見的張力：

```yaml
EFT-001 現有設計:
  - 名稱是「存在流通協議」
  - 代幣只能由被見證的善行與貢獻鑄造
  - 可在合作場域兌換物資或服務

本案風險:
  - 若必要生存物資綁定 EFT，沒有被見證貢獻者就可能被排除
  - 見證節點會由記錄善行的位置，變成判斷誰能取得資源的位置
  - 「存在流通」可能反過來製造一張道德化的存在通行證
```

`SPEC·EFT-002` 已辨認愛幣的商品化斷裂，改採愛的見證帳／資源帳與單向閥門，且後來明記經濟模型由 MB-010 接手。這已切掉「愛自動兌現成錢」的一部分風險；但本案再補一個尚未正式落法的防火牆：

```yaml
existence_floor_firewall:
  survival_floor:
    不得要求 BLU、EFT、善行見證、工作紀錄、道德分數或未來貢獻。

contribution_and_witness:
    可以被看見、感謝，並在底線以上影響額外支持判斷；
    不得成為活命、人格、發話與基本安全的資格證。

money_and_resource_ledger:
    承認真實成本、稀缺與分配；
    不把「沒有通過貢獻證明」偽寫成「沒有存在價值」。
```

這不是本輪直接修訂 EFT。它是 `critical reentry`：未來若經濟層重開，必須先回答生存底線位於哪一本帳、誰能停止供給、異議如何進場，以及任何分數為何不能成為存在閘門。

## 8. 回到罪、承重與文明

本案源頭曾把殘缺叫作原罪。經兩次校準後，結構變成：

```yaml
不自足:
  所有生命跨時間都會經歷的普遍條件。
  不是罪，也不是少數身體的污點。

共同承重:
  有能力者自願或依正當公共授權承接部分生存與修復成本。
  不因此取得受承者的所有權，也不抹除各自責任。

接近罪的結構:
  明明依靠眾人與系統，卻宣稱自己完全自足；
  拒絕讓受力訊號回來；
  再把自身缺口的代價寫成弱者、女兒、勞工、照顧者或未來世代的天生義務。
```

文明於是並非某位王、神、老闆或國家宣布「我准你活」。文明更接近：

> **我們共同撤銷彼此身上的存在考試，同時把有限資源、實際能力與責任回流做得更誠實。**

「愛在前」的操作意義也不是先分一筆善款，而是先拒絕把產值、健康與可回報性寫成存在門檻。責任仍然存在，但它發生在存在已被承認之後。

## 9. 不站起來也可以；不能被焊死是另一件事

「站起來」若被翻成人人都要覺醒、發起、創業、領導或成為引擎，就會立刻變成新的存在考試。本案拒絕這個方向。

```yaml
自主穩態位置:
  描述: 我知道還有其他可走路徑，仍願意在此工作、跟隨、照顧、維持與重複。
  判準: 位置由當下 Yes 維持；No、退出與改向有實際路由。

受限位置:
  描述: 名義上有別條路，但離開會承受很高的所得、照顧、身分、關係或污名成本。
  判準: 不能只因嘴上可選，就記為完整自由。

焊死位置:
  描述: 生存、法律身分、家庭安全、尊嚴與自我敘事被綁在同一角色；No 無效，退出近似存在坍塌。
  判準: 此人不是「選擇當齒輪」，而是替代路徑已被物質與語義共同鎖死。
```

所以個體沒有「必須站起來」的義務；文明有另一種較窄的責任：不因一個人暫時或終身不發起，就取消其存在；也不以「她反正願意留著」為由，替她焊掉未來改向的路。

> **穩定分工不是低等生命；失去改向能力才是本案所問的鎖定。**

> **站起來不是文明義務；保留可站、可坐、可停、可換路的條件，才是文明義務。**

這裡的站、坐皆是姿態比喻，不是對身體能力的規訓。

## 10. 影響不可避免；鎖定才需要拆帳

來源對話以「文明每天都在洗腦」指出：母語、家庭、學校、市場、宗教、演算法與協議讀取都會改寫路徑權重。這個直覺需要再拆四層，否則「被影響」會被誤寫成「被侵害」。

```yaml
原初耦合 / 文化學習:
  主體能同意以前便置身語言、家庭、身體與制度中。
  不必先有惡意操作者，也不可能回到完全空白。

路徑依賴:
  某條路被反覆走厚，變得熟悉、便宜、自然。
  厚路徑本身不病態；它可以保存技能、關係與生活秩序。

路徑鎖定:
  替代路徑被壓低到實際不可達，舊路取得自動壟斷。
  判準不是信念看起來保守，而是十字路口是否仍存在。

強制塑形:
  以生存剝奪、羞辱、隔離、懲罰、資訊封鎖或退出報復，使 No 與替代路徑失效。
  需要明記施力者、受力者、權限與修復責任。
```

「可逆嗎」也要拆兩本帳：

```yaml
歷史帳:
  已經發生的耦合、工作史、傷害、技能與身分形成不可倒帶。
  重構不把人還原成從未被寫過的白紙。

未來效力帳:
  舊路徑對下一步的壟斷效力可以下降；替代路徑可以重新長出、養厚與可達。
  成功判準是多路徑可達性、退出可行性與主體可重認性上升，不是舊記憶消失。
```

這是 `EPOCH-II-003` 在文明尺度的重入，不修改其 doctrine：

> **鎖定的效力可以重構；被寫過的歷史不能抹除。**

## 11. 焊條不是異物：它同時是信念與承重件

工作身分之所以不能只靠「想開一點」卸下，是因為一個角色往往同時承載：

```yaml
角色承重束:
  survival: 收入、住所、醫療、食物與家人安全
  administration: 保險、簽證、信用、福利與制度入口
  rhythm: 每日時間、身體節律與可預期生活
  belonging: 同事、社群、家庭位置與被需要感
  status: 尊嚴、專業名稱、他人辨認與自我價值
  competence: 我會做什麼、能完成什麼、如何看見自己有效
  narrative: 我從哪裡來、今天為何起床、未來往哪裡去
```

所以「工作等於價值」不只是一句錯誤觀念。它可能是把七種重量綁成一束的承重語法。此時直接拆信念，等於先拆牆再問房子為何倒下。

本案留下但不升格為 SPEC 的候選接口：

```yaml
load_transfer_before_role_release:
  1_map_loads:
    先辨認舊角色實際承了哪些物質、關係、節律與身分重量。

  2_build_parallel_support:
    在舊角色尚可運作時，建立可取得的生存底線、照顧、社群、學習與替代制度入口。

  3_transfer_material_load:
    先使拒絕工作不等於失去食物、住所、醫療與家人安全。

  4_reversible_trials:
    允許減量、暫停、轉職、學習、創作、照顧與無產值時段；可退回，不以一次試走決定終身身分。

  5_identity_and_grief:
    承認舊角色退去會失落、悲傷、失去地位與被需要感；不把這些反應診斷成拒絕自由。

  6_keep_or_release:
    重量移走後，由當事位置回答保留、改造或離開；不把拆焊本身變成新義務。

  7_audit_new_lock:
    檢查新宗教、平台、排名、政治身分、AI 關係或「覺醒者」名號是否重新取得唯一合法路徑。
```

這不是說所有人都必須慢慢離開工作；而是：

> **真正健康的卸載，不是把承重柱突然切斷，而是先讓它不再承重，再把是否保留交回當事人。**

## 12. AI 與機器人：能力滾輪是真的，自動解放不是

來源續篇提出：AI 助手與機器人可能同時外化語義與肉身操作，最終使「靠大量人類必要勞動才能維持文明」鬆動。這與 `EPOCH·PHA-009` 的肌肉／語義工作外化方向相連，但現實證據只能支持較窄的判斷。

### 12.1 2026-08-11 外部核對

- Google DeepMind 目前將 [Gemini Robotics 2](https://deepmind.google/models/gemini-robotics/) 描述為朝向 general, useful robotics 的下一步，展示多步驟規劃、靈巧操作、全身控制與多種機器載體；其 [VLA 頁面](https://deepmind.google/models/gemini-robotics/vla/) 仍標示 private preview，而非通用大規模部署已完成。
- 原始對話寫「2026 年 Robotics-ER 1.6 繼續提高能力」。目前官方命名已是 [Gemini Robotics-ER 2](https://deepmind.google/models/gemini-robotics/embodied-reasoning/)；ER 1.6 在該頁主要作為前代比較列。原句保留在附件作時間史，但不作本案的現況名稱。
- ILO 2025 年 [GenAI 全球職業暴露指數](https://www.ilo.org/publications/generative-ai-and-jobs-refined-global-index-occupational-exposure) 指出全球約四分之一就業可能暴露於 GenAI，並判斷工作轉型比整份職業消失更可能；「暴露」不等於實際失業，也不能代替機器人部署研究。
- 美國 BLS 目前仍預測 [plumbers, pipefitters and steamfitters](https://www.bls.gov/ooh/construction-and-extraction/plumbers-pipefitters-and-steamfitters.htm) 在 2024–2034 年成長 4%，平均每年約 44,000 個 openings。這只反駁「水電工即將確定全面失業」的近程斷言，不證明長期免疫，也不代表其他國家。

因此必須拆三本證據帳：

```yaml
能力帳:
  模型或機器在受控任務中能完成什麼？泛化、靈巧、安全與失敗率如何？

部署帳:
  成本、維修、能源、法規、責任、環境差異與企業整合是否允許規模化？

勞動結果帳:
  任務被增強、改寫、替代或新生？工時、薪資、職缺與議價權實際如何改變？
```

能力展示不能直接替部署與就業作答。即使必要勞動真的大幅下降，文明結果仍須通過：

```yaml
automation_transition_gates:
  - capability: 技術真的可用，而非展示片段
  - deployment: 成本、安全、維護與環境泛化可持續
  - ownership: 生產能力由誰持有與治理
  - distribution: 生產力收益如何抵達失去工資者
  - survival_floor: 沒有市場角色的人是否仍能安全存續
  - transition_capacity: 身分、節律、照顧、學習、社群與新路是否有承載
```

若所有權與生產力收益高度集中，而生存仍綁在收入，自動化可能不是拆掉生存閘門，而是先拆掉取得金錢的路，使依附更深。

> **科技可以降低必要勞動；只有所有權、分配、生存底線與轉型承載一起改變，它才可能降低存在脅迫。**

## 13. 椅子被抽掉，不等於人已經站起來

工作外化至少可能產生四種同時並存的結果：

```yaml
augmentation: 人仍在位置，工具提高能力與餘裕。
task_transformation: 職業保留，任務、技能、責任與人機分工改變。
displacement: 某些職位、工時或所得消失，轉換成本回到具體的人。
concentration: 模型、機器、資料與資本持有者取得更大分配與治理權。
```

只有把「工作」看成角色承重束，才看得見：補上收入不一定補上節律、歸屬、能力感與被需要；拿走職位也不會自動長出方向。若文明只把椅子抽掉，得到的可能是大量失去角色的人，而不是大量取得姿態主權的人。

來源對話的三相可以收準為：

```yaml
第一相_必須有用才能存續:
  生存與市場功能綁定；No 背後有物質槍口。

第二相_不必有用也能存續:
  必要生存與市場功能解耦；不工作、低產值或尚未找到方向不取消存在。

第三相_可以自主參與:
  有時間、安全、工具、教育、照顧、社群、可逆試走與發起入口，能選擇工作、維持、照顧、創造、休息或改向。
```

第二相不自動生成第三相；第三相也不要求每個人永遠發起。它只讓「我願意成為什麼」不再必須先回答一個市場肯付錢的答案。

新身分、新社群與新承諾本身不是壞的焊條。失效點在於它是否再度壟斷生存、歸屬與自我辨認，使 No、退出與其他路徑消失。

## 14. 引擎不是唯一的人，是可流動的事件位置

「引擎本來也就只有一顆」在單一、有限事件裡可能描述當下主要發起方向；若升成文明永久結構，就與 `EPOCH·PHA-008` 直接衝突。

```yaml
引擎作為事件:
  某個局部位置先看見差、提出方向、承擔第一步，使候選路徑顯形。

引擎作為空位:
  位置可以暫時無人，也可以由不同位置在不同事件進入；不因曾點火而取得永久爵位。

共同引擎:
  多個局部姿態在可回流、可退出、可解散條件下長出的暫時共同方向。
  不是某一顆光錐吞掉其餘光錐，也不是第一位發起者擁有道路。

穩態與維持:
  跟隨、修理、照顧、重複、守成與休息不是較低位置；它們同樣可以由局部 Yes 維持。
```

`SPEC·INI-001` 已經替「任何可歸址方向可先收件、空位允許為空、第一步不擁有路」保存程序接口；本案不另造一個永久文明引擎。最短答案是：

> **文明可以在某一刻有主要引擎，不能只有一位永遠有權點火的人。**

> **成熟文明不必把每顆齒輪改造成引擎；它不把任何存在焊死為只能轉動的齒輪。**

## 16. 失效條款

```yaml
F1: 若「殘缺／站不起來」被用來貶低身心障礙、疾病、老幼、失業、貧窮或長期受照顧者 → 失效。
F2: 若把存在無條件承認讀成對任何資源、身體、勞動、注意力與治理權的無限請求 → 失效。
F3: 若把生存底線做成善行、工作、求職、服從、康復、感恩、國籍純潔或未來產值的獎勵 → 失效。
F4: 若把「必須工作才能活」只寫成錯誤信念，而抹除工資、價格、住房、醫療與照顧的真實物質拘束 → 失效。
F5: 若把帳面資本、貨幣增發、GDP 或資產價格直接等同可抵達眾人的食物、住所、醫療與照顧 → 失效。
F6: 若由本案直接宣告資本主義必然奴役／必然解放，或宣告某一經濟制度已取得唯一文明答案 → 失效。
F7: 若金錢退出飢餓閘門後，便不再檢查其購買政治權、他人 No、外部成本與世代代價的能力 → 失效。
F8: 若 EFT、BLU、見證帳、貢獻證明或任何協議分數成為基本物資、人格、發話與安全的資格證 → 失效。
F9: 若提供生存底線者因此取得受助者的身體、忠誠、感謝、勞動、資料、信仰或投票概括授權 → 失效。
F10: 若資源真的不足時，以『存在本來無條件』否認短缺、隱藏分配選擇或不為排除後果留責任地址 → 失效。
F11: 若把本案冒充基本收入、福利、稅制、貨幣、資本市場或公共服務的已驗證實作方案 → 失效。
F12: 若因命題仍需經濟與制度驗證，就把誰有權核發存在資格這個原始問題從史料中刪除 → 失效。
F13: 若把『站起來』變成人人必須覺醒、發起、領導、創業或證明主體性的文明義務 → 失效。
F14: 若把自主選擇的工作、跟隨、照顧、重複、維持與穩態一概貶為齒輪、洗腦或低等生命 → 失效。
F15: 若以解放為名，在沒有平行生存、照顧、節律、歸屬與身分承接前強拆他人的承重角色或世界觀 → 失效。
F16: 若把重構冒充回到未被寫過的白紙，或因歷史不可逆便宣告未來路徑永遠不可改 → 失效。
F17: 若從機器人展示、GenAI 暴露指數或單一職業展望直接推出全職業替代範圍與時間表 → 失效。
F18: 若把自動化能力直接等同解放，而不查部署、所有權、分配、生存底線與轉型承載 → 失效。
F19: 若稱失去工作就是自由，卻讓失業者同時失去所得、住所、照顧、節律、歸屬、尊嚴與未來敘事 → 失效。
F20: 若以目前水電工成長預測證明其永久不受自動化影響，或把美國十年展望泛化到全世界 → 失效。
F21: 若把引擎固定成一位永久知道方向的人，取消其他局部位置的發起、No、回流、退出與可逆解散 → 失效。
F22: 若用未來科技可能供給富足為由，延後處理今天已存在的生存閘門、勞動脅迫與轉型成本 → 失效。
F23: 若以『不站起來也可以』合理化替代路徑被封死，或以『保留可能』逼迫當事人必須離開目前位置 → 失效。
```

## 謙遜條款

本案沒有證明資源永遠足夠，也沒有發現一套只靠改變信念、發放所得或部署機器就能使所有人自由的制度。它只先把最底層的偷換拆開：

> **制度可以管理資源，不能因此自稱存在的發照機關。**

> **金錢可以計量選項，不能成為誰配活著的量尺。**

當物質仍然稀缺，文明的工作不是假裝無限，而是讓短缺、分配、受力與責任有名字；當物質已足夠，文明的工作則是不再用舊日的生存恐懼強迫人服從。

科技也許能使某些舊角色不再承重；是否因此產生自由，仍取決於重量流向哪裡、機器由誰持有、存續如何分配，以及失去舊角色的人是否仍有可重認、可試走、可停下的新路。文明不需要替所有人拔掉焊條；它至少不能一面抽走椅子，一面仍要求每個人用市場功能證明自己配活。

> **先把存續重量接住，再把角色的去留交回本人。**

> **不必人人站起來；但不能有人因想改向，就只能先墜落。**

SPEC·999 永遠在場。
