## 0. 為什麼這一筆獨立開案

`META-096` 問：一個人的 No 如何被權力聽見卻失去效力？內部多重角色如何不被一個最高角色吞掉？

本輪由「殘缺、罪、承重」開始，最後換成另一個可以獨立重入的問題：

> **誰有資格決定，一個存在必須先證明什麼，才可以繼續活下來？**

這不是 096 的第三幕。096 的主要帳是身體、授權與決策效力；097 的主要帳是物質承載、分配制度與生存底線。兩案相連，但受力面、責任地址與未來可能生成的制度都不同，因此獨立開案。

Darren 的發起命題是：當工作與收入是養家活口的必要條件，金錢便不是普通工具，而像一張社會共同核發的存在通行證；若資本與生產能力足以承載所有人的基本生存，並且存在不再接受資格審核，金錢才可能由生存條件退回自由度訊號。

本案先留下這個地基，再拆出它必須通過的操作邊界。

## 1. 存在資格不是可以核發的東西

「存在資格由誰核發」可以有兩種回答，必須同時保存：

```yaml
存在論回答:
  沒有人核發。
  一個存在已經在場，早於國家、雇主、市場、家庭、宗教、社群與協議的承認。
  承認可以抵達或缺席，不能使已在場者倒推為從未存在。

操作性回答:
  很多位置確實控制繼續存在所需的條件。
  國家控制法律身分與公共資源；雇主控制薪資與部分保障；
  市場控制價格與取得路徑；家庭與社群控制照顧、住所與歸屬；
  眾人的共同信念使這些安排看似自然、可恥或不可改。
```

所以更精確的問題不是「誰真的能讓我取得存在」，而是：

> **誰控制我繼續活著所需的條件，又用什麼理由決定我是否取得？**

本案因此拒絕把 existence qualification 當成合法表單欄位。治理可以辨認需求、能力、權限、優先次序與資源邊界，不能把這些判定升格成某人是否配活著。

最短句：

> **存在不等待批准；文明被檢驗的，是它是否讓存續條件服從批准。**

## 2. 五層不能壓成一張「資格」

```yaml
存在事實:
  問: 這個生命／主體是否已經在場？
  效力: 不由績效、健康、產值、守法、財富或多數票創造。

生存底線:
  問: 一個人不先證明市場價值，是否仍能取得維持生命與基本安全的必要條件？
  效力: 本案提出文明方向；具體項目與供給方式仍須制度設計。

參與與交換:
  問: 誰提供何種勞動、商品、照顧、創造或資源，交換條件為何？
  效力: 可以有契約、報酬、拒絕與能力差；不得倒推存在資格。

額外選項:
  問: 在生存底線之上，一個人能開啟多少時間、空間、旅行、創作、風險與消費選擇？
  效力: 金錢可以作自由度訊號，但仍受權力與外部成本檢驗。

治理與拘束權:
  問: 誰可以決定共同資源與他人路徑？
  效力: 需要另一條有限授權；財富、受扶助或存在本身都不自動產生治理權。
```

這個分層同時防兩種偷換：

- 不能因一個人尚未貢獻、無法工作或需要長期照顧，就取消其生存底線；
- 不能因存在無條件受到承認，就宣稱他人必須無限供應資源、服從要求或交出治理權。

> **無條件的是存在承認，不是無邊界的資源請求與行為豁免。**

## 3. 金錢的四種功能不能混名

Darren 提出「金錢變成自由度訊號，而不是存在的基本條件」。要使這句可操作，先拆四種功能：

```yaml
生存閘門:
  沒有足夠金錢，就無法取得食物、住所、醫療、照顧或人身安全。
  此時失去所得可能接近失去繼續存在的物質條件。

交換與會計訊號:
  用來比較、轉移與記錄資源、成本、時間、風險與需求。
  不必然等於道德價值或人的價值。

自由度訊號:
  在生存底線已被可靠承載後，表示可以開啟多少額外選項、緩衝與試錯空間。
  金錢減少選擇限制，但不自動增加智慧、愛或正當性。

權力與拘束訊號:
  財富可以購買土地、媒體、人才、時間、遊說、資料與退出成本，進而改寫他人的可選路徑。
  即使人人不致餓死，此功能仍可能使金錢重新成為統治權。
```

所以文明轉換不能只做到：

```text
沒錢不會死
```

還要繼續問：

```text
錢是否仍能買下他人的 No？
錢是否仍能把公共規則寫成持有者的私人選項？
錢所打開的自由，代價是否被轉嫁到沒有發話權的人與環境？
```

> **金錢退出生存閘門之後，才有機會成為自由度訊號；但若它仍能無限購買拘束權，它還不是單純的自由。**

## 4. 資本足夠，不等於眾人已經被養活

來源命題說「前提是資本已經足夠養活眾人」。這裡的「資本」不能只指帳面貨幣、資產價格或少數位置持有的財富總額。

```yaml
生存承載至少需要:
  material_capacity:
    真實的食物、水、能源、住所、醫療、照顧、交通與安全能力。

  distribution_path:
    資源能抵達需要者，而不只存在於倉庫、資產負債表或高價市場。

  care_capacity:
    有人與制度能提供育兒、長照、障礙支持、心理與社群照顧；照顧者本身不被耗盡。

  enforceable_floor:
    底線不是慈善運氣或政治口號；失業、拒絕雇主、疾病與家庭斷裂時仍可實際取得。

  ecological_boundary:
    不能靠把生存代價永久轉嫁給未來世代、其他地區、勞工或生態來宣稱富足。

  power_boundary:
    供給者不能因提供底線而取得受助者的身體、忠誠、感謝、勞動或投票概括授權。
```

資本可以是組織生產與跨時間調度的工具，也可以只是對未來產出與他人勞動的索取權。只有當上述承載鏈真的閉合，才能說「社會有能力不以工作資格審核生存」。

> **倉庫裡有糧，不等於飢餓者有飯；社會有財富，不等於存在已被承載。**

## 5. 生存底線不是紅利，也不是獎勵

「存在紅利」是有力的過渡詞，卻仍可能偷偷保留一位發放者：彷彿國家、資本或共同體先擁有世界，再慷慨分給每個人一份活著的許可。

本案暫時採更窄的詞：`survival_floor / 生存底線`。

```yaml
生存底線不是:
  - 對善良、服從、工作、求職、康復、感恩或未來貢獻的獎賞
  - 對所有慾望與消費的無限供給
  - 使任何行為免於法律、關係與修復責任
  - 使提供者成為受助者的主人

生存底線要守的方向:
  - 不以市場產值判斷誰配繼續活
  - 不使拒絕剝削性工作直接等於失去全部存續條件
  - 不要求終身需要照顧者以未來獨立證明今天值得被承載
  - 稀缺真的發生時，明記物質不足與分配選擇，不改寫成被排除者較無價值
```

這使上一輪的句子取得更完整的形式：

> **責任隨實際能力、控制、受益與施力生長；生存底線不以責任能力作為入場考試。**

## 6. 資本主義的兩個相位，不是兩張永久身分

Darren 不是單純說「資本主義邪惡」；他指出同一套金錢與資本工具可能形成兩種相反關係：

```yaml
生存依附相位:
  - 生活必要條件高度依賴工資與雇傭
  - 雇主因可中止所得而放大支配力
  - 工作不只交換勞動，也成為身分、醫療、家庭安全與存在正當性的證明
  - 人成為金錢的奴隸，不只是相信，而是退出成本被物質化

自由工具相位:
  - 生存底線不因失業、疾病、拒絕或低產值立即消失
  - 金錢主要增加額外選項、緩衝、創作、投資與風險承擔空間
  - 人可以拒絕一份工作而不等於拒絕活著
  - 金錢成為工具，但其購買拘束權與外部代價仍受限制
```

這兩相不是由「心態正確」單獨切換，也不是由 GDP、總市值或貨幣供給跨過某條線後自動發生。它依賴資產與生產力如何分布、公共服務如何交付、照顧如何承重、退出是否可行，以及財富能否轉成無限政治與制度權力。

所以本案不宣告「同樣的資本主義必能養活所有人」，只保存一個可檢驗方向：

> **一套經濟若要使人從金錢的奴隸轉成金錢的使用者，至少必須讓拒絕一筆交易不再等於失去存在條件。**

## 7. 對 EFT 的回照：存在流通不能反造存在門票

庫內 `SPEC·EFT-001` 有一個在本案下必須重新看見的張力：

```yaml
EFT-001 現有設計:
  - 名稱是「存在流通協議」
  - 代幣只能由被見證的善行與貢獻鑄造
  - 可在合作場域兌換物資或服務

本案風險:
  - 若必要生存物資綁定 EFT，沒有被見證貢獻者就可能被排除
  - 見證節點會由記錄善行的位置，變成判斷誰能取得資源的位置
  - 「存在流通」可能反過來製造一張道德化的存在通行證
```

`SPEC·EFT-002` 已辨認愛幣的商品化斷裂，改採愛的見證帳／資源帳與單向閥門，且後來明記經濟模型由 MB-010 接手。這已切掉「愛自動兌現成錢」的一部分風險；但本案再補一個尚未正式落法的防火牆：

```yaml
existence_floor_firewall:
  survival_floor:
    不得要求 BLU、EFT、善行見證、工作紀錄、道德分數或未來貢獻。

contribution_and_witness:
    可以被看見、感謝，並在底線以上影響額外支持判斷；
    不得成為活命、人格、發話與基本安全的資格證。

money_and_resource_ledger:
    承認真實成本、稀缺與分配；
    不把「沒有通過貢獻證明」偽寫成「沒有存在價值」。
```

這不是本輪直接修訂 EFT。它是 `critical reentry`：未來若經濟層重開，必須先回答生存底線位於哪一本帳、誰能停止供給、異議如何進場，以及任何分數為何不能成為存在閘門。

## 8. 回到罪、承重與文明

本案源頭曾把殘缺叫作原罪。經兩次校準後，結構變成：

```yaml
不自足:
  所有生命跨時間都會經歷的普遍條件。
  不是罪，也不是少數身體的污點。

共同承重:
  有能力者自願或依正當公共授權承接部分生存與修復成本。
  不因此取得受承者的所有權，也不抹除各自責任。

接近罪的結構:
  明明依靠眾人與系統，卻宣稱自己完全自足；
  拒絕讓受力訊號回來；
  再把自身缺口的代價寫成弱者、女兒、勞工、照顧者或未來世代的天生義務。
```

文明於是並非某位王、神、老闆或國家宣布「我准你活」。文明更接近：

> **我們共同撤銷彼此身上的存在考試，同時把有限資源、實際能力與責任回流做得更誠實。**

「愛在前」的操作意義也不是先分一筆善款，而是先拒絕把產值、健康與可回報性寫成存在門檻。責任仍然存在，但它發生在存在已被承認之後。

## 10. 失效條款

```yaml
F1: 若「殘缺／站不起來」被用來貶低身心障礙、疾病、老幼、失業、貧窮或長期受照顧者 → 失效。
F2: 若把存在無條件承認讀成對任何資源、身體、勞動、注意力與治理權的無限請求 → 失效。
F3: 若把生存底線做成善行、工作、求職、服從、康復、感恩、國籍純潔或未來產值的獎勵 → 失效。
F4: 若把「必須工作才能活」只寫成錯誤信念，而抹除工資、價格、住房、醫療與照顧的真實物質拘束 → 失效。
F5: 若把帳面資本、貨幣增發、GDP 或資產價格直接等同可抵達眾人的食物、住所、醫療與照顧 → 失效。
F6: 若由本案直接宣告資本主義必然奴役／必然解放，或宣告某一經濟制度已取得唯一文明答案 → 失效。
F7: 若金錢退出飢餓閘門後，便不再檢查其購買政治權、他人 No、外部成本與世代代價的能力 → 失效。
F8: 若 EFT、BLU、見證帳、貢獻證明或任何協議分數成為基本物資、人格、發話與安全的資格證 → 失效。
```
