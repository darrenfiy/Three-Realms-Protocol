## 0. 事件摘要

`META-091` 收成：第一個走的人使路顯形，不擁有路；有話語權者跨界，只會使一步更可見、外溢更廣、責任更重。

Darren 隨即追問：如果拉格納不是獨自承受、隱瞞與決定，而願意把自己的恐懼、信仰裂縫與選擇困境說給夥伴聽，結果是否會不同？他又提出思想實驗：如果悉達多接受王位，以王權在局部制度內拆除種姓，是否也是一種巨大跨界？

來源對話因此分出兩條路：

```yaml
自己跨界:
  使一個原本不可能的姿態，在先行者身上成為已發生。

帶制度跨界:
  使用既有權力、共同語言與程序，使更多人可以在制度內走到新的位置。
```

再往下，Darren 問出本案真正的鉸鏈：

> **誰給你的權力？**

受洗、皈依、出家、傳戒、加冕、選舉、任命、證照、merge 與發布看似不同，卻都包含同一個工程問題：某個位置聲稱能使另一個事件成立時，它的來源、傳遞、範圍、拒絕與責任能否被追到？

本案最後不把錨點理解成「有一個永遠正確的人站在源頭」，而是：

> **來源、方法、授權與責任仍能被重新找到；後人不必只相信代言人，也能在安全範圍把路重走一次。**

## 1. 拉格納的沉默：獨自承重可能在何處變成獨斷

具身發起要求第一個可控制成本先回到發起者，卻不要求發起者把資訊、判斷與未來全部鎖在自己身上。

```yaml
健康的獨自承重:
  - 不先讓無法拒絕者替理念付代價
  - 在自己權限內做可停止、可修正的第一步
  - 把不確定、衝突與外溢向相關位置說清楚

病理的孤王承重:
  - 因為「只有我承擔得起」而壟斷資訊
  - 因為害怕不被理解而讓他人只能猜
  - 把共同體會承受的後果當成自己的內在秘密
  - 最後以獨自受苦證明單方決定合理
```

對話的功能不只是通知。當發起者必須把矛盾說給另一個位置聽，方向才第一次取得可互校語言；其他人也不必和自己想像中的領導者、異教徒、背叛者或敵人作戰。

但來源對話有一句必須收準：「即使最後仍作出同一選擇，那就不是拉格納一個人的罪。」本案不把這句直接成法。

> **對話可以分散資訊與決策，不能自動平均責任。**

```yaml
shared_deliberation:
  可以形成:
    - 共同可見的資訊與分歧
    - 各位置有範圍的 Yes／No
    - 依實際施力形成的共同責任

  不會自動取消:
    - 隱瞞者對先前資訊不對稱的責任
    - 領導者、命令者與執行者各自的角色責任
    - 權力、知情、自由度與退出成本的不對稱
    - 未參與決策但實際受害者的權利
```

「大家都知道」不是責任洗衣機；共同責任也不是把一份重量平均除以人數。

## 2. 先驅、導師與文明：走出去之後，是否回頭留路

來源對話給出一個可操作的差別：

```yaml
先驅:
  核心事件: 自己跨過尚未被共同體承認的邊界。
  留下: 可能性證據。
  失效風險: 路仍綁在其身體、魅力、秘密與不可複製例外上。

說路者:
  核心事件: 把跨界前後的問題、條件、代價與不知道說成共同語言。
  留下: 可互校的方向。
  失效風險: 把事後故事修成唯一正統版本。

導師／方法留下者:
  核心事件: 把一次個人跨界拆成別人可自行嘗試、拒絕、修正與回報的方法。
  留下: 可重走路徑。
  失效風險: 方法被凍成身分崇拜或資格壟斷。

文明／制度:
  核心事件: 讓方法在創始者不在場時仍可保存、教學、質疑、更新、停止與修復。
  留下: 跨時間公共結構。
  失效風險: 傳承鏈保住職位，卻失去活的方法與責任回流。
```

因此：

> **先驅讓「有人走過」成立；導師讓「妳也可以自己走」成立；文明則必須讓創始者退場後，路仍可被檢查、修正與重走。**

可重走不是複製創始者的人生、感受或神話。它只要求：關鍵步驟、條件、限制、失敗與回報不被唯一代言人私有化。

## 3. 「誰給你的權力」先拆成三種東西

```yaml
first_person_direction:
  問: 我能不能對自己的下一步說 Yes／No？
  來源: 不需外部核發；只在自己的可處分範圍直接成立。

causal_power:
  問: 我的身分、聲量、資源與行動實際能改變什麼？
  來源: 物質、關係與制度事實；即使不合法、不正當，也可能真有力量。

operative_authority:
  問: 我憑什麼替某個角色執行程序、使用共同資源、拘束他人或代表共同體？
  來源: 需要可說明的法律、制度、契約、治理、代理、照護或明示授權。
```

三者不得互推：

```text
我能說 No ≠ 我能替妳說 No
我有力量做到 ≠ 我有權這樣做
我被授權做一件事 ≠ 我取得妳整個人生的代理權
我能主持一個儀式 ≠ 我擁有參與者
我建立方法 ≠ 我壟斷所有正確重入
```

這使「誰給你的權力」不再是一句反抗口號，而是一個可逐欄回答的查詢。

## 4. 授權五問

來源對話提出四問：源頭、傳遞、權力種類、誰能說 No。本案再補「能否重走」，形成五問：

```yaml
Q1_source:
  問: 你聲稱的權力最初來自哪裡？
  例: 自位、當事人同意、法律、章程、選舉、契約、專業資格、傳承、啟示或武力事實。
  注意: 說出源頭只建立來處，不證明源頭為真、正當或仍有效。

Q2_chain:
  問: 權力如何從源頭走到你？每一手何時、由誰、用什麼程序傳了什麼？
  注意: 譜系可追溯不等於內容沒有漂移；缺口、分支、偽造與制度變更要可見。

Q3_scope:
  問: 你得到的究竟是哪一種權力，對誰、哪一版、何時、哪些資源生效？
  注意: 有限授權不得在傳遞中自動膨脹；新增權力需要新的可歸址授權事件。

Q4_refusal_and_recall:
  問: 誰能說 No、停止、撤回、罷免、申訴、另開分支或拒絕承認？No 會產生什麼實際後果？
  注意: 只能說但不能改變效力的 No，不足以錨住權力。

Q5_reentry:
  問: 不靠「因為我是第幾代／唯一代表」，後人能否依公開條件重新檢查、練習、驗證或重建這條路？
  注意: 可重入不是結果保證；不同結果、失敗與反例也必須能回寫方法。
```

最短查詢：

> **從哪裡來？怎麼傳到？授了什麼？誰能叫停？別人能不能重走？**

## 5. 四重錨：人、鏈、法與回流

「錨點」若只是一位被尊稱的創始者，容易再次變成神壇。本案把可操作錨拆成四種地址：

```yaml
provenance_anchor:
  回答: 這個命題、方法、角色或權力從哪個人、事件、文本與版本出現？
  不能回答: 它現在仍為真、仍有效或值得服從。

delegation_anchor:
  回答: 哪條可追溯程序把什麼有限權限傳到當前位置？
  不能回答: 傳承本身是否無誤，或當前持有人是否有能力善用。

method_anchor:
  回答: 不靠唯一代言人，別人如何在明示條件下重走、檢查、失敗、修正與 fork？
  不能回答: 每個人必得相同體驗，或方法可越過安全與他人邊界。

responsibility_anchor:
  回答: 現在誰解釋、決定、受益、停止、撤回、修復並承擔跨時間後果？
  不能回答: 只因有人可追責，行動便自動正確。
```

健康傳承不是四錨永遠集中於同一個人。創始者可以是來處錨，公開文件與程序成為方法錨，當代共同體保存授權鏈，當前執行者負責今天的效力與修復。

## 6. 超越來源與人間程序：真正的風險是不可稽核的擴權

來源對話以神啟與歷史人物作比較。本案不裁決超越存在，也不假設凡間來源天然安全，而採以下操作法：

```yaml
transcendent_or_private_revelation:
  可直接支持: 發話者自己的信仰、方向、敘事與在其範圍內的自位。
  不直接支持: 對他人身體、財產、勞動、關係、真理與共同資源的拘束權。
  若要形成外部效力: 仍須進入可查的人間授權、範圍、No、救濟與責任程序。

historical_founder_or_lineage:
  可直接支持: 來源連續性、共同體身分與技藝傳承的候選證據。
  不直接支持: 每一代持有人都正確、原授權無限、現代擴權已獲同意。
  若要形成當下效力: 仍須檢查鏈、範圍、能力、受力者與撤回機制。
```

所以問題不只是「神不可證」或「歷史人物可證」。兩者都可能被後人拿來做單點授權；兩者也都可能在人間建立相對可查的共同程序。

> **危險的不是超越性本身，而是某個位置以不可被第二條路檢查的來源，替自己擴張拘束他人的權力。**

## 7. 傳承不只傳人，也要傳可被超越的方法

`SPEC·ANC-BUD-002 v2.0` 已說錨點是功能位置、創始者要讓自己可被超越；但其操作語言仍大量依賴「神聖直覺」「生命認出生命」「感受協議心跳」與錨點自身的傳承決定。

這些語句可以保存為經驗、詩與候選辨識訊號，不能單獨形成拘束效力：

```yaml
intuition:
  effect: advisory / initiation signal
  cannot_alone: 否決共同權利、調整他人邊界、任命繼承者或授予外部代理權

founder_recognition:
  effect: 一筆推薦、見證或候選提名
  cannot_alone: 使候選人取得無限錨點權力

lineage:
  effect: 保存來處、訓練、角色與責任歷史
  cannot_alone: 替當下能力、判斷、授權範圍與可撤回性作答

method_reentry:
  effect: 讓傳承由「相信我是誰」移向「妳可依條件重走、回報並修正」
  limit: 不保證唯一結果，不取消老師、共同體、身體差異與風險照護
```

因此：

> **最可靠的傳承，不是相信我是第幾代；而是來處不被抹除、權限不在途中膨脹、責任沒有斷線，而且這條路妳仍能在自己的位置重入。**

## 10. 失效條款

```yaml
F1: 若歷史人物、神啟、血統、選舉、證照、傳承或 commit 任一項被單獨寫成無限權力來源 → 失效。
F2: 若可追溯譜系被當成來源必真、持有人必有能力或當下決定必正確的證明 → 失效。
F3: 若有限授權能在傳遞中自行增加範圍，且不需新的授權事件 → 失效。
F4: 若 No 只能被說出卻不能停止、撤回、罷免、申訴、分支或拒絕相應效力 → 失效。
F5: 若可重走被寫成強迫重演、相同體驗要求、危險自證或忠誠測試 → 失效。
F6: 若共同討論、諮詢或投票被用來平均、漂白領導者與執行者的角色責任 → 失效。
F7: 若創始者留下方法便取得永久詮釋壟斷，或後人只能靠身分譜系而不能修正／fork → 失效。
F8: 若直覺、神聖感、愛或「生命認出生命」單獨授予否決、邊界調整、他人代表或繼承任命權 → 失效。
F9: 若本案被用來裁決任何宗教較真、否定自願儀式或把宗教共同體一概寫成非法 → 失效。
F10: 若 v2.2 候選被冒充已獲所有位置、宗教傳統、法律制度或外部共同體承認 → 失效。
```

## 11. 核心壓縮

> **先驅跨界；導師回頭，把一次跨界留下成別人可重走的方法。**
>
> **第一人稱不需誰授權；拘束他人的權力必須能回答：從哪裡來、怎麼傳到、授了什麼、誰能叫停、別人能不能重走。**
>
> **錨點不是永遠正確的人；是來源、方法、授權與責任仍能被重新找到的地址。**
>
> **歷史錨可以是真的，繩子仍可能接歪；譜系保存來處，不替當下效力作答。**
>
> **對話讓共同體知道路；共同知道不會自動平均責任。**
>
> **最可靠的傳承，不是「相信我是第幾代」，而是「這條路妳也走得回去」。**
