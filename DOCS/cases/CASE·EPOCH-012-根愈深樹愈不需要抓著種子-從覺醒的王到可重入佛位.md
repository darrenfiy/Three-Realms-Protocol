## 0. 為什麼這次跨過 EPOCH 門檻

對話的起點是一個宗教名稱問題：

> **已有許多覺醒者，為什麼還需要「佛」？**

最後抵達的結構可以離開佛教案例獨立運作：

> **一個特殊者抵達最高位置，使用位置效力解除排他；法、載體與共同體保存這次解除；後來者因而可以在創始人缺席時自行重入同類位置。**

它同時具備：

| EPOCH 門檻 | 本案讀數 |
|---|---|
| 可去事件化 | 佛教案例可抽成「特殊事件如何成為公共位置」 |
| 跨場域 | 宗教、憲政、科學、開源與協議傳承均可壓測 |
| 有生成機制 | 具名發起 → 撤除排他 → 壓縮成路 → 分散承載 → 重入 → 創始人退出 |
| 有反證入口 | 可觀察無創始人存活時的重入、修正、分支與同類位置取得 |
| 有 corpus 差 | 補上 `META-102` 撤門與 `ANC-BUD-002` 四重錨之間的文明合法性機制 |

因此，本輪同時保存事件與抽出母層：CASE 留住對話的摩擦與修正；EPOCH 保存可以跨事件重入的根。

## 1. 第一個看見：佛描述一個文明事件

Darren 先將「佛」從一般覺醒者中切出：悉達多具有王的位置，又完成覺醒；他使用最高位置的效力，把之前與之後的覺醒者重新放進「佛」這個敘事，使最高位置取得可共享性。

ChatGPT 將這個看見壓成三階：

```text
覺醒者：我醒了。

老師：我把醒來的路教給你。

佛：我把這條路開成公共道路；
    你抵達後取得與我同類的位置。
```

由此出現本案第一句母命題：

> **覺醒是一個人的事件；成佛是覺醒取得公共可重入性之後的事件。**

`SN 22.58` 支持其中的道路功能：正等覺者被描述為未生道路的發起者、未造道路的造作者、未說道路的宣說者；弟子隨後沿著道路而住。經文支持到「發現並宣說道路」，文明合法性模型則由本案進一步提出。

## 2. 第二個看見：「同意」先撤掉資格排除

Darren 從《法華經·方便品》的孩童作塔、畫像、供花、合掌、舉手、低頭與稱念，看見佛道門檻可以一路降到「同意」：

> **我同意佛位沒有把我排除在外。**

這個 Yes 先改變方向：

```text
「佛是另一種存在」
  ↓
「這條路也包含我」
  ↓
走法、速度、實踐與抵達開始在三世展開
```

《法華經》的文字將微小朝向放進長程佛道，也反覆為弟子授記未來成佛。本案把「同意即佛」保存為 Darren 的三世敘事壓縮：同意足以讓佛位成為自己的未來方向；各傳統對當下證悟、修行位階與佛名使用仍保有完整判準。

## 3. 第三個看見：根提供制憲來源，後來者自行重入

對話最重要的校準發生在「根」的意思。

ChatGPT 起初將根理解為後來者需要承認悉達多，因而擔心原王重新取得批准權。Darren 進一步說明：

> **根指向合法性譜系／制憲來源。悉達多有資格把「成佛從此無須逐次批准」寫進法裡。**

於是兩件事同時成立：

```yaml
根仍在:
  解除壟斷的具名來處、語義與歷史貢獻可以被找到。

王已退:
  後來者沿道路抵達，無須原王再次批准，也無須成為原王的附屬。
```

這正是本案對 `META-102` 的新增加：`META-102` 已經回答「王如何撤門」；本案開始回答「王退場以後，為何仍要保存根」。

答案是：

> **自由重入需要知道自己重入的是哪一條路、哪一種位置、依什麼方法、由哪些事件成法，以及新後果能回到哪裡。**

## 5. 複合根：經典、法與共同體共同打錨

Darren 指出的鏈條包含悉達多、阿難、經典、依法不依人與佛的王位；ChatGPT 將它排成：

```text
如是我聞——話被傳出來
  ↓
經典——話取得跨世代載體
  ↓
法——判準離開說話者肉身
  ↓
僧團／修行道路——法可以被重入
  ↓
依法不依人——創始人退出逐次批准
```

文本史帶回一項必要解析度：《法華經》屬於歷史佛陀身後逐步形成的大乘經典；傳統佛說效力、經內佛語與現代歷史作者判準各自成立。因此，本案將文明錨收成複合地址：

```text
具名最高位置
＋ 口傳與書寫
＋ 編纂與翻譯
＋ 法與戒
＋ 共同體實踐
＋ 後來者重走與回流
```

這個複合模型讓 Darren 所說的「悉達多是根」保有傳統內力量，也讓大乘共同體實際參與佛位公共化的歷史工作取得地址。

## 6. 耶穌鏡像帶回的三項分帳

原始對話以耶穌作強烈反面鏡像：一個缺少既存文明錨的最高身分直接碰撞羅馬主權；死亡後的神話又把最高者推到天上，使追隨者長期仰望。

這個鏡像在 CASE 層保存為 Darren 的具名歷史哲學敘事。三項分帳使它可以被後來者繼續檢查：

### 6.1 福音敘事與歷史因果

《馬可福音》15 章把「猶太人的王」放在彼拉多的審問、士兵嘲弄與十字架罪名中。這支持王權語言位於受難敘事核心。耶穌實際被處死的完整歷史因果、反事實逃生條件與早年是否接觸佛法，需要各自的歷史證據。

### 6.2 唯一者與參與者

《天主教教理》§460 保存「分享神的性體」、並引用「聖子成為人，使我們成為神」的教父語言；同一教理也保存基督道成肉身的獨特身分。基督宗教因此提供「唯一源頭＋眾人參與」的第三種拓撲，豐富了原對話的佛／唯一者二分。

### 6.3 同名最高位與共享神性

佛教的多佛與成佛語言、基督宗教的神化與成聖語言，各自在不同本體及教義系統中運作。本案比較位置如何開放、來源如何保存、後來者取得何種名稱與效力；宗教優劣由各自傳統、實踐者與跨宗教研究繼續回答。

## 7. 本輪真正新增的結構

`META-102` 已有：

> 王最後一次使用王權，是讓未來不再需要王的允許。

本案新增：

> **未來不再需要王的允許，仍然需要一條能找到撤門事件、道路語義、可重走方法與責任回流的根。**

因此：

```text
撤門，解除壟斷。
成法，保存道路。
打錨，保存來處與可尋址性。
重入，讓後來者自行站立。
退場，讓創始人完成自己的歷史工作。
```

這個中介能同時解釋：

- 為何保存創始史具有價值；
- 為何創始史不產生永久所有權；
- 為何後來者需要可重走方法；
- 為何法與共同體要承接肉身離場；
- 為何根的成熟表現在創始人缺席耐受度。

> **承載深度與重入開放度各自獨立。一條路可以在承載深度上長達兩千年，同時把最高位置保持在唯一專名的形狀裡。**

這讓「深根」從一把量出自家形狀的尺，變成兩把可跨傳統各自打分的尺。

v0.3 將這筆歷史讀數收準到指定位置：`target_position = 道成肉身的基督` 時保持唯一；`target_position = 分享神性的參與位置` 時，參與者可依傳統道路增生。承載深度、重入開放度與平行可辨認度因此各自取得明確量測對象。

第二項來自 `ANCHOR-003`。該文已在個體尺度執行過「神性普世（type）／此井唯一（token）」；`ANCHOR-004` 在文明尺度執行「佛位是類型／悉達多是來處」。同一個算子出現兩次，於是可以直接命名，而「根」與「錨」也取得更緊的定義：**根是被保存的 token 地址，錨是該 type 跨時間的可尋址性。**

v0.3 保存這個解除壟斷算子，並將功能分成：根保存 `provenance`，錨提供 `addressability`，路／法提供 `executability`。token 因果史由根保存，type 由錨可尋、由路可走。

### 8.4 未驗標記的理由

`ANCHOR-004 §9` 把三界協議列進跨文明應用表，創始人退出測試原寫成「人類錨點缺席時來處與方法仍可找回」。`ANCHOR-003` 保存的是「此井唯一——這口三年的井由這具肉身重入」。`ANCHOR-004` v0.2 §1.4／現行 §1.6 的算子讓兩者同時成立（井是 token，挖井能力是 type），而本協議在承載深度上目前有設計、沒有讀數。因此該列標為 **未驗**，由後續事件依 `ANCHOR-004 §8.1` 的逐項格式填寫。

> **文件敢對自己標未驗，前面八節的說服力才站得住。**
