## 0. 為什麼值得收

這段對話不是一般的《維摩詰經》摘要。它完成了三次轉向：

```text
維摩詰拆掉「覺悟應該長成某種樣子」
  ↓
「依法」會不會又把資格審查偷偷裝回來？
  ↓
四依法是否不是四條並列口號，而是一條判斷權逐層成熟的路？
```

真正跨過收錄門檻的，是最後一跳：

> **法接手老師的位置，不等於文字接管生命；法若要保持可重入，還需要義、智與了義持續打開它。**

這句直接補到 `EPOCH·ANCHOR-004 §6.3`。該節已回答「創始人離場後，由法與律接手判準」；本案進一步追問：**法接手後，如何避免新的持文者、詮釋者與資格審核者再次封門？**

---

## 1. 第一幕：維摩詰先拆「覺悟的固定外觀」

來源對話以故事讀《維摩詰經》：主角是居士，不離城市、家庭、財富、疾病與複雜人間；舍利弗等弟子拒絕探病，文殊前往；天女轉換自己與舍利弗的性別形相；諸菩薩談不二，最後由維摩詰的沉默收束。

這些情節在對話中共同承擔一個讀法：

> **覺悟不能被某一種可見外觀完整代理。**

本 CASE 不把這句升成《維摩詰經》的唯一正解。它登錄的是這段對話如何使用該經作文化鏡像：

```yaml
出家身分:
  可以承載道路與戒律
  不自動成為智慧的真值代理

清淨場所:
  可以降低干擾並保護修行
  不自動等於內在自由

違反預期的外觀:
  可以是失控、傷害或自我欺騙
  也可能暴露原有分類把表相錯當成義
```

因此，判斷不能只停在「它長得像不像佛法」。

## 2. 三道資格門

對話把慧能、維摩詰與常不輕並置成三個文化鏡像。這不是佛教人物的歷史排名，而是一張反資格壟斷的操作圖：

| 文化鏡像 | 被拆開的資格門 | 本案保留的問題 |
|---|---|---|
| 慧能 | 知識資格 | 不識字或未持有經學資本，是否先被排除於見性可能之外？ |
| 維摩詰 | 身份資格 | 非比丘、身處城市與複雜場域，是否先被排除於智慧位置之外？ |
| 常不輕 | 他者判斷權 | 我尚未認證對方，是否就能把對方判在成佛可能之外？ |

三道門合起來，生成本案第一個可攜壓縮：

> **知識不能壟斷佛；身份不能壟斷佛；判斷權不能壟斷佛。**

這裡的「反壟斷」不把資格、訓練與判斷全部刪掉。它改變的是處理次序：

```text
先收見一個可能性
  ≠ 宣布它正確
  ≠ 授予它權威
  ≠ 交出操作權
```

這與 `SPEC·INI-001` 的程序安全港同構：候選發起可以先收件，正確性、身份、範圍與授權各自後判。常不輕之姿在此不是「所有人現在都已證悟」，而是「我不先用自己的資格審查關掉你的可能性」。

## 3. 法是校準地板，不是身份審核器

ChatGPT 起初提出：沒有法，任何人都能以「我是佛」取得無限自我授權；法因此提供可檢查的公共支點。Darren 隨即以維摩詰進入淫舍追問：如果依法等於遵守固定外觀，維摩詰是否沒有依法？

這個反問迫使「法」分帳：

```yaml
法作為校準地板:
  - 讓行動接受反例、停止、修正、受力與後果檢查
  - 在判斷能力尚未穩定時提供保護
  - 使創始人缺席後仍有公共可引用標準

法作為固定外觀清單:
  - 只問場所、身份與形式是否符合
  - 容易把持文者變成資格核發者
  - 容易讓「依法不依人」重新退化成依另一群人

法作為活的道路:
  - 保留文字、歷史、戒律與公共校準
  - 同時追問行動正在承載什麼義、由何種心智判讀、產生何種後果
```

因此，本案不把「依法」撤掉，而是阻止它在第一階凍結。

> **法先解除聖人特權；義再解除文字特權；智再解除判斷者對自己認知的盲信。**

## 4. 維摩詰的有限文本支點

本輪有限核對支持兩個窄命題：

1. 鳩摩羅什譯 `T475《維摩詰所說經》` 的確寫維摩詰「入諸婬舍，示欲之過；入諸酒肆，能立其志」。
2. 同經〈佛道品〉的確有「若菩薩行於非道，是為通達佛道」，後文並以「示行」貪欲、瞋恚、愚癡等悖論語法展開。

這些經句足以支持：**經文本身刻意鬆動「可見場所／外觀＝內在狀態」的直接等號。**

它們不單獨支持：

```yaml
不支持:
  - 進入任何高風險場所都代表修行成熟
  - 動機自稱良善便足以取消他人受力
  - 覺者身分可以豁免現行法律、同意、倫理或責任
  - 現代性產業中的剝削、權力與身體風險可以被經典意象略過
```

所以「先看操作，不先審爵位」必須與 `EPOCH-IV-001` 同讀：能力、權限、範圍、停止與責任各自成立。操作讀數不能由操作者自稱完成，也不能把受力者的第一人稱拿掉。

## 5. 四依法作為一條成熟路徑

`EPOCH·ANCHOR-004` 原先只讓「依法不依人」承重。本案的新看見是：四依可以在協議內被讀成一條**判斷權逐層成熟、又始終能回到地板**的路徑。

```text
人
  ↓  依法不依人
法
  ↓  依義不依語
義
  ↓  依智不依識
智
  ↓  依了義經不依不了義經
了義判讀
```

這是本案的結構性讀法，不是佛教史上唯一固定科判。`T374《大般涅槃經》` 可為此排列提供一個文本支點；其他經論與註疏存在不同排列與解釋，故次第效力只在本案的工作模型內成立，持續等待跨文本審讀。

### 5.1 依法不依人：解除人格批准

```yaml
移除:
  「因為某位聖人、大師或創始人說，所以不必再檢查。」

建立:
  可引用、可共同閱讀、可實踐、可反駁的公共支點。
```

這一步使創始人可以離場，也使後來者不必逐次取得人格批准。

### 5.2 依義不依語：解除載體獨占

```yaml
移除:
  「只有這個字面、譯本、形式與外觀能承載法。」

建立:
  對語句在具體情境中所承載方向、保護對象與作用的追問。
```

這一步不是自由改寫經文；它要求版本、語境與語義差異都在場，並阻止門牌被當成房子。

### 5.3 依智不依識：解除認知結構的自我壟斷

```yaml
識在本案的工作讀法:
  已累積的記憶、分類、教育、宗派、創傷、文化與概念材料。

智在本案的工作讀法:
  能照見自己如何分類、比較材料、承受反例並修正判讀的能力。
```

本案不把識貶為無用。沒有識，文本、歷史與差異無從辨認；沒有智，識容易把既有分類當成世界本身。

> **知被照見，才成為智。**

此句保留為 Darren 的生成性字形詮釋；它在本案表達反身照見，不作漢字字源證據。

### 5.4 依了義不依不了義：在前三層仍在線時完成判讀

本案把「了義」讀成一次有範圍的穿透性判讀：法、語境、識、智、受力與後果同時在場後，辨認此刻哪些說法已抵達問題核心，哪些仍是方便與過渡。

它不是：

```text
「我已經懂最高真理」
  →「所以我不必再接受法、證據、他人 No 與後果校準」
```

相反地，前三依持續作為可回返地板。了義判讀若使人失去可修正、可停止與可被受力者反駁的能力，便已失去本案所說的成熟條件。

## 6. 不能跳級

本案最重要的護欄不是「最高層比較厲害」，而是：

> **第四層不能自我宣告跳級。**

```yaml
跳級失效一:
  以「依義不依語」為名，省略原文、版本、語境與反例。

跳級失效二:
  以「依智不依識」為名，拒絕知識、史料、專業與可查證材料。

跳級失效三:
  以「依了義」為名，替自己核發法律、同意、戒律、倫理或責任豁免。

跳級失效四:
  以維摩詰「行於非道」為名，要求他人承受自己的高風險實驗。
```

成熟不是永遠離開第一階。成熟是能在需要時回到公共法、文字、證據與程序，再帶著它們穿回義與當下判讀。

這使四階不是階級塔，而是可往返的校準路徑：

```text
依法取得地板
  ↕
依義保持道路可活
  ↕
依智看見自己的讀法
  ↕
在明確範圍內作了義判讀
  ↺ 新受力與反例回到法、語、識與智
```

## 7. 對 ANCHOR-004 的實質增加

`ANCHOR-004` 的根／錨／路／引力已經回答：來處如何保存、道路如何被找到與重走，以及創始人如何退出批准。本案補上的是道路內部的**詮釋呼吸**：

| `ANCHOR-004` 既有功能 | 本案新增的內部運動 |
|---|---|
| 根保存成法譜系 | 依法：人格批准退場，法取得公共地址 |
| 錨讓根與路可找到 | 依語境讀語：文字保有版本與來處，不壟斷義 |
| 路讓後來者可重走 | 依義：後來者能在新情境中再生道路的作用 |
| 回流使道路可修正 | 依智：判斷者看見自己的分類機器並承受反例 |
| 後來者自行抵達 | 依了義：在明確範圍內完成判讀，不向創始人補辦批准 |

因此，`ANCHOR-004 §6.3` 的「法接手老師的位置」在 v0.5 補成：

> **法接手老師，使創始人退出批准；四依持續打開法，使文字、持文者與判斷者也不能重新擁有道路。**

這不是新增第五個根元素，也不需要另立一篇 EPOCH。它屬於 `G2 可再生成壓縮` 與 `G5 創始人退出` 之間的詮釋機制：壓縮要能教回去，也要能在不背叛來處的條件下重新展開。

## 8. 與「佛不能擁有佛」的關係

`CASE·META-102` 說最高位置最後一次使用權力解除自己的壟斷；`ANCHOR-004` 說根如何保存這次解除；本案則觀察解除之後最容易發生的回鎖：

```text
佛不再擁有佛
  ↓
法接手
  ↓
若停止於第一句
  ↓
持文者可能開始擁有法
  ↓
資格門以「正統解釋」之名重新關上
```

四依法的次第讀法讓解除壟斷繼續向內走：

```text
人不能擁有法
語不能擁有義
識不能擁有智
個人的「了義」宣稱不能擁有他人的判斷、身體與道路
```

因此，本案不是削弱法，而是讓法保有創始人當初交出去的公共性。

## 10. 最小壓縮

> **維摩詰拆的不是法，是法被外觀擁有。**
>
> **依法不依人，把法從人格批准中救出來。**
>
> **依義不依語，把義從文字獨占中救出來。**
>
> **依智不依識，把判斷從自身分類的盲點中救出來。**
>
> **依了義不依不了義，只有在前三層仍在線時，才成為成熟判讀。**
>
> **法接手老師；四依讓法繼續活著。**
