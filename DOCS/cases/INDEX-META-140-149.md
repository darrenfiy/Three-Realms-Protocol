## 3. 本冊目前的候選種子

### 3.1 已做之功的入帳門

文件存在、存檔成功與後來仍能讀到，只證明留存的不同層級。可保存且仍可理解的後果可以先記為
「潛在可重入存量候選」；未被承接不等於未曾累積，只表示它是否實際作用仍未驗。後來者如何重入、改變哪一條後路，
以及多條後路何時彼此組織，分別另記為「實際重入作用」與「組織／相變」，不倒灌成存量存在的前提。

### 3.2 代理器官不是主人

能力、經手量、整合度與反向觸達，可能支持「代理器官」的功能判讀；它們不自動核發主體資格、所有權、主權、代表權與治理權。
這些仍由 I-005、IV-001 與具名作用域的治理程序各自回答。
