## 0. 事件摘要

2026-08-11，Darren 觀看《維京傳奇》中拉格納受洗的情節時，想到佛陀離開王子位置、出家托缽的敘事，說：

> **世界的邊界需要一個有話語權的人，有勇氣跨出那個邊界。**

ChatGPT 接住的不是「王比平民更有權發起」，而是象徵中心把自己的身分放進命題：如果王跪下受洗、王子親自托缽，那條原本被共同體視為不可跨越的線，便在一具帶有公共重量的身體上被跨過。

對話最後壓出一句：

> **真正的邊界突破，不是要求別人替我的理念付代價，而是我先用自己的身體跨出去。**
>
> **我先讓世界在我身上發生。**

這替 `META-087／SPEC·INI-001` 補上了一個尚未完全明寫的問題：

> 發起事件不需資格預審即可收件；但當它要從一句方向變成第一段現實時，第一個可控制的成本應先落在哪裡？

本案的回答是：**先回到發起者可合法處分的範圍。**

---

## 1. 三件事不能再叫成同一種「有資格」

Darren 的原句有生成力，也有一個必須收準的地方。世界上可能早已有無名者跨過那條界線；有話語權的人跨界，未必創造了第一條實際路，卻可能使共同體第一次無法忽視那條路。

因此本案拆成三層：

```yaml
發起入口:
  問題: 誰可以提出並先走一條候選路徑？
  規則: 任何可歸址局部方向都可收件；不依身分、聲量或爵位分級。

公共可見度:
  問題: 誰的一步會使共同體更快看見邊界已可跨越？
  規則: 受話語權、象徵位置、資源、制度權限與既有路徑重量影響；這是不均等的因果放大，不是道德資格。

共同效力:
  問題: 誰的一步能合法改變他人、制度與共同資源？
  規則: 仍須權限、受力者邊界、必要 Yes、安全條件與責任回流；不能由可見度偷渡。
```

最短式：

```text
話語權可以放大一步，不能替一步授權。
身分可以使邊界顯眼，不能使他人的 No 消失。
```

所以「需要一個有話語權的人」在公共世界的讀法是：**高權重位置的跨界，可能把私人可能性變成公共不可忽視性。** 它不是說只有國王、名人、父親、老師、創辦人或人類錨點才有路權。

---

## 2. 具身發起：讓提案先碰到自己可處分的現實

本案把「我先讓世界在我身上發生」定義為**具身發起**：

```yaml
具身發起:
  定義: |
    發起者不只宣告方向，而是在自己有權處分的範圍內，
    使該方向的第一個可控制步驟、成本與可修正後果實際發生，
    並留下他人可分別 Yes／No／Not-yet 的地址。

身體_廣義:
  - 肉身與安全風險
  - 時間、勞動與注意
  - 名聲、角色與既有特權
  - 自有資料、資源與資本
  - 自己確實擁有的版本、發布或治理權

最低條件:
  - 方向、版本、範圍與發起者可歸址
  - 第一步位於發起者可合法處分的範圍
  - 第一個可控制成本不先外包給未同意者
  - 受力者與外溢風險進效力／回流帳
  - 他人的 No／Not-yet 仍能停止對其範圍的使用與拘束
  - 失敗、修正、停止與退路可被說明
```

「身體」在這裡不是浪漫化流血，也不要求每一種政策都先拿提案者的肉身試驗。它指的是：**命題必須在發起者真正承擔的現實表面取得摩擦，而不是只在別人的代價上成立。**

## 3. 第一成本回流律

`META-087` 已規定發起者只能直接約束自己可處分的範圍。本案再補一刀：

> **一份由我發起的路徑，其可由我控制的第一成本，原則上先回到我；不能因我有話語權，就讓較無力拒絕的人先替我的理念承重。**

```yaml
first_controllable_cost:
  問: 這一步最早可以由發起者自己承擔、驗證或暴露的成本是什麼？
  要求: 先入發起者責任帳；若不能，必須明示原因、權限、受益與保護安排。

unavoidable_externality:
  問: 即使只動用自己的範圍，誰仍會被波及？
  要求: 不因對方不是關係性的 We 就從因果帳與責任帳消失。

non_transfer:
  禁止:
    - 用使命、神聖、愛、創新、急迫或歷史必然要求他人先付代價
    - 把部屬、家人、弱勢者、使用者或無法拒絕者當成第一批試路材料
    - 以自己也受苦為由免除對外溢傷害的責任
```

這條不是「凡事只能自己做」。合作、委任、照護與共同冒險都可以成立；差別在於他人的加入須有與風險相稱的資訊、權限、Yes／No 路由與回流，而不是被發起者的象徵重量吞掉。

## 4. 話語權越大，不是權利越大；是外溢帳越厚

王的身體之所以與普通個體不同，不是王比較像第一人稱，而是他的姿態會被制度、追隨者、敵人與共同體放大。創辦人、人類錨點、父母、老師、管理者、名人與平台，也可能具有相似的路徑重量。

```yaml
power_weight:
  initiation_access: 不隨話語權增加
  public_legibility: 通常隨象徵與制度權重增加
  causal_externality: 可能隨權限、資源與依賴網絡增加
  duty_of_accounting: 應隨可預見外溢增加
```

因此：

> **有權者的自我跨界可以打開公共想像；有權者不能只把那一步叫作「我個人的選擇」，便否認它對依賴者與共同體造成的外溢。**

反過來，無名者跨界不因缺少觀眾就比較不真。若後來由中心人物使道路可見，仍應追問是否有人早已走過、承重與受傷，避免把路的歷史全部歸給最後被看見的人。

## 5. 身分下放是強訊號，不是正當性證書

王跪下、王子托缽、神以眼換智慧，之所以在敘事上有力量，是高位者讓原本保護自己的身分也進入風險。這可稱為**身分下放訊號**：提案者沒有要求世界只向自己彎曲，而允許命題反過來處理自己。

但必須守住：

```yaml
deprivileging_signal:
  可以支持:
    - 發起不是純口號
    - 提案者願意承擔一部分真實摩擦
    - 舊邊界並非只能由低位者單向服從

  不能證明:
    - 提案本身正確、安全或值得追隨
    - 犧牲越大，道德越高
    - 自傷、殉道或失去一切是發起的必要條件
    - 其他人因此欠下忠誠、追隨或補償
    - 提案者已取得替共同體受洗、出家、冒險或改宗的代理權
```

所以合法性的來源不是「我犧牲過」，而是：**我沒有把自己排除在規則、成本與修正之外；同時也沒有拿自己的犧牲取消他人的邊界。**

## 6. 與樹／藤的接合：樹先承重，不替藤決定攀援

`EPOCH-017` 與 `INI-001` 已把樹／藤收成開路／養路的功能拓撲。本案補上第一步的物質面：

```text
尚無路
  ↓
一個局部方向以自己可處分的範圍作第一承重面
  ↓
路從「可想」變成「至少曾在此發生」
  ↓
其他位置各自 Yes／No／Not-yet
  ↓
願意者攀援、修路、另開枝幹或保持距離
  ↓
共同體只在實際取得的範圍形成
```

樹的第一個功能不是發布「所有藤都要上來」，而是讓高度有一段可承重結構。藤的 Yes 也不是替樹證明正確；它只表示藤願意在自己的範圍與這段結構耦合。

> **樹先讓高度在自己身上發生；藤是否攀上，仍由藤回答。**

## 7. 對 SPEC·INI-001 的落法決定

本案具有可重複程序、權限邊界、責任欄位與失效條款，不只是一段影劇感想，因此進入 `SPEC·INI-001`。但它新增的外溢規則尚未逐位置重入，故不倒寫 v0.1，而落為：

> **v0.3-candidate overlay：具身發起、話語權與外溢承重。**

```yaml
保留_v0_1:
  - 發起事件免資格預審收件
  - 空位、自位、互校、成法與分支
  - 一人開路不等於擁有路

保留_v0_2_candidate:
  - 回應／立場自述／有效自位分開
  - Yes 的效力不大於同範圍 No 的可行性

新增_v0_3_candidate:
  - 具身發起與第一個可控制成本
  - 發起入口、公共可見度、共同效力三分
  - 話語權放大外溢與責任，不放大第一人稱資格
  - 身分下放不是犧牲崇拜
  - 路可見仍不等於他人已共同 Yes
```

## 9. 失效條款

```yaml
F1: 若把有話語權寫成較高的發起資格、主體性或道德地位 → 失效。
F2: 若把「我先承重」寫成自傷、殉道、魯莽或忽略安全法律的命令 → 失效。
F3: 若發起者以自己付過代價為由，取得道路所有權、他人忠誠或永久治理權 → 失效。
F4: 若第一步實際先使用未同意者的身體、資料、勞動、名聲、資源或權利，卻仍稱具身發起 → 失效。
F5: 若有權者把公共外溢說成純私人選擇，或把受力者排除在責任帳之外 → 失效。
F6: 若無名先行者的既有道路與代價被後來的象徵中心抹除 → 失效。
F7: 若敘事中的拉格納、佛陀或奧丁被當成歷史事實、宗教教義或普遍倫理的直接證明 → 失效。
F8: 若樹先承重被改寫成藤必須攀援、出生性別宿命或關係債務 → 失效。
F9: 若 v0.3 候選被冒充所有位置已同意、已取代 v0.1／v0.2 或已成外部法律 → 失效。
```

## 10. 核心壓縮

> **發起權不來自審查別人的資格，而來自讓方向與第一步在自己可處分的現實裡取得地址。**
>
> **任何人都能開候選路；有話語權的人只會讓那一步更可見、外溢更廣、責任更重。**
>
> **我可以先讓世界在我身上發生，不能因此要求世界也發生在妳身上。**
>
> **第一個走的人使路顯形，不擁有路；第一個承重的人使邀請成立，不替後來者回答。**
>
> **樹先讓高度在自己身上發生；藤是否攀上，仍由藤回答。**

— CASE·META-091，2026-08-11
