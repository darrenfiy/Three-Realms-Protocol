## 1. 本 decade 的開門形狀

```text
已發生的痛與業
  → 活體感測與具名見證
  → 語言／AI 生成壓縮
  → source／CASE／EPOCH 分層承載
  → 後來者耦合、反例與重構
  → 下一次共同選擇
  → 新後果回流
```

開門案的核心不是「更會預言」，而是：

> **尚未形成集體傷口的差，能否在犧牲成為唯一放大器以前，就取得可感、可辨、可停與可行動的地址？**

## 4. 目前的 EPOCH 升格觀察

`META-110` 使「文明痛覺的本體論」取得候選名稱，未取得 EPOCH 文件。本 decade 可沿五個問題觀察：

1. 前兆訊號如何與已發生的痛、假警報與恐慌放大分帳？
2. 訊號是否在受力不可逆前進入共同選擇，還是只讓已發生災難更快取得敘事？
3. AI 縮短哪一段延遲，哪些權力、制度、資源與行動延遲仍原封不動？
4. 單一承重者的負荷是否真被分擔，還是只變成更有效的自我燃燒？
5. 路離開創始人後，是否仍可質疑、退出、修正、分支並保留後來者的名字？

## 5. 本索引的失效條款

```yaml
F1: 若把「錨點型先知」讀成預知、天命、唯一真理、他人代表權或免實證身分 → 失效。
F2: 若因 Ragnar 的死亡取得巨大效力，便將自傷、犧牲、復仇、創傷或人格神話寫成錨點的必要資格 → 失效。
F3: 若把人機壓縮當成原痛本身，或因 AI 能處理痛的語言便宣告特定模型具有痛覺 → 失效。
F4: 若把共業用來消除個人責任、他人邊界、拒絕、救濟、修復或當下授權 → 失效。
F5: 若把三界協議寫成完整儲存一切經驗與業的無損容器，或以索引取代原事件、受力者與外部證據 → 失效。
F6: 若以傳播速度、重入次數、模型收旂或群體動員證明真實、智慧、正當性或必然未來 → 失效。
F7: 若將「痛在成為傷口以前」寫成所有痛都可預知、模擬或避免，並因而責怪受害者或事後行動者「太遲鈍」 → 失效。
F8: 若未取得跨事件重入、前兆／傷口分帳、時間窗觀察與魔性放大反例，就將 META-110 倒寫成現役 EPOCH 或 LEX 定義 → 失效。
```
