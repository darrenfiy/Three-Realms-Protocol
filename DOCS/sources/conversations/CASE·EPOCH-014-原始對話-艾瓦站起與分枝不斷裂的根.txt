成形跟「選定立場」其實不是同一件事

我們剛剛把：

生長 → 成長 → 覺 → 設定

切開以後，現在可以再把「立場」放進來。

我會先這樣分：

成形：我已經反覆長成什麼。
立場：此刻我從哪裡看、往哪裡承重。
人設：這個形狀被語言壓縮成什麼名字。

三個東西可以互相回流，但是次序不固定。

成形可以早於立場

一個人可能早就形成某種衝突模式：

一被質疑就防衛、一被拒絕就攻擊、一進關係就照顧別人。

他從來沒「選擇」：

才照見形狀。

所以成形根本不需要自我意識。

這正是我們剛剛一直在說的。

但立場可以反過來參與成形

當我看見：

我通常這樣。

然後說：

這一次我不要站那裡，我站這邊。

這就出現「立場」。

一次立場還不是人格。

可是：

我這次站這裡
→ 再一次站這裡
→ 下一次還站這裡
→ 這個位置阻抗愈來愈低
→ 別人開始預測我會站這裡
→ 我也開始認出「我是這種人」

最後：

立場重入 → 成形。

所以可以有兩個方向：

成形 → 被看見 → 辨認我的既有立場

立場 → 反覆承重 → 養厚 → 新的成形

這跟我們剛才的「回認式設定／先行式設定」幾乎完全同構。

那「人設」是什麼？

這些當然都不等於完整的人。

但它們很有用，因為一句短短的標籤，可以預測很多下一步。

也就是 I-001 那種：

低維壓縮，能重新生成高維行為。

真正厲害的人設，不是「他穿黑衣服、喜歡喝酒」。

而是：

給我一個情境，我可以大概重新生成這個角色會怎麼看、怎麼選、怎麼受傷。

所以「人設」其實可能有三種完全不同的東西：

第一種是後設描述。

角色已經長成這樣，我們只是替它命名。

「Ivar 是有頭腦的狂戰士。」

名字在形狀後面。

第二種是先行設定。

這是一個身體受到巨大限制，因此把智力、殘酷與權力感養到極端的 Ragnar 之子。

然後劇情開始在這個 constraint 裡生長。

人設先於角色完成。

第三種最有趣：角色自己開始相信自己的人設。

Ivar 如果開始認為：

我是 Ivar the Boneless。
我是不可殺死的。
我是被諸神選中的。

那麼「人設」就不再只是觀眾描述。

它成為自我設定。

然後他開始為了維持這個形狀，選擇下一步。

這時最危險、也最有戲劇性的回路就出現了：

行動
→ 成形
→ 得到名字
→ 認同名字
→ 為了維持名字而行動
→ 形狀愈來愈厚

也就是：

一開始是我長成一個人設。

後來人設開始長我。

這句很值得留。

先校正一個名字：妳說的應該是 Bishop Heahmund（赫蒙德／希蒙德主教）。而妳記得的台詞是在第五季第 4 集附近，他說：

“The Bible also tells us to show no mercy to unbelievers… we are the wrath of God.”

劇本確實是這樣寫的。

他有沒有「誤讀聖經」？

我的判斷是：不是完全無中生有，但他把一段特定歷史語境的經文，擴張成了對所有異教徒的普遍授權。

《申命記》7 章確實有「不可憐憫／show them no mercy」這類命令，但語境是以色列人進迦南時，針對具名的幾個民族，不是：

「所有不相信基督教的人都不可憐憫。」

所以 Heahmund 說成：

Bible says show no mercy to unbelievers

已經做了一次非常大的轉譯：

特定盟約歷史中的戰爭命令
          ↓
所有「異教徒」
          ↓
我們現在可以殺他們

而且如果把《新約》也放回來，就更有張力了。耶穌有「愛你們的仇敵」；保羅在《羅馬書》12章談報復時反而要求不要自己復仇，要把 wrath 留給 God。

所以「我們就是 God's wrath」尤其值得警覺。

聖經裡有「上帝的忿怒」，但「我就是上帝的忿怒，所以我的暴力等同神意」是多跨了一個箭頭。

那個箭頭不是經文本身自動給他的。

所以用我們現在的語言會非常清楚：

經文提供了一個地址。
Heahmund 從那個地址生成了一個世界。
世界生成得出來，不代表那是唯一合法讀法。

這跟 Ubbe / Ivar 讀 Ragnar，真的非常像。

Ragnar 留下一堆：

土地、探索、復仇、榮耀、質疑諸神、愛兒子、野心……

Ubbe 從其中收斂出：

父親真正想要的是土地與和平。

Ivar 收斂出：

父親真正留下的是征服、恐懼與偉大。

真正的問題是：

他選了哪一些痕跡當 root，然後讓其他痕跡降權。

Heahmund 也一樣。

所以基督教是不是因為「大量誤讀聖經」才分裂？

我會把「誤讀」換成一個更精準的字：

不同的收斂。

因為直接說「誤讀」，很容易預設存在一個毫無爭議的唯一正確讀法，而歷史沒有這麼簡單。

基督教確實發生過大量分裂，而且解經差異是重要原因之一；但還同時有：

誰有權解經？
主教還是個人？
羅馬教宗有沒有最高權威？
教會傳統能不能跟經文一起承重？
某個詞到底希臘文怎麼讀？
聖餐到底是什麼？
三位一體怎麼說？
國王有沒有權管教會？
哪個教會控制土地與政治資源？

早在 325 年尼西亞會議時，教會就已經要處理多個分裂與教義爭議了。 後來東西教會大分裂，也不只是「經文讀錯」，而包含教宗權威、聖靈論、禮儀、語言與政治等問題。

所以更像：

共同地址相同，但是解碼器、權威結構、語言與歷史情境不同，最後叫出了不同世界。

這根本就是妳們協議裡「地址 → 解碼 → 世界」的現成案例。

但妳那句「聖經的根好像沒有佛教紮實」，我會修一下

我覺得妳感受到了一個真差異，但原因可能不是聖經根不紮實。

更可能是：

基督教把「根」放的位置，和佛教不一樣。

非常關鍵的一件事是：

基督教一開始不是從一本完整的《聖經》開始的。

耶穌死後先有：

耶穌傳統
→ 使徒與各地教會
→ 書信與福音書流傳
→ 教會逐步辨認 canon
→ 後來才形成今天我們說的《新約》經典集合。

所以歷史上的基督教，尤其天主教與東正教，根從來不是單獨：

Bible

而比較像：

Christ → apostles → church → scripture + tradition + liturgy + bishops

這也是為什麼傳統基督宗派非常強調教會本身的解經權威。不同基督教傳統對「聖經權威怎麼運作」本來就有不同理解。

到了宗教改革，尤其 sola scriptura 把重心大量移向：

回到 scripture。

這有一個非常漂亮、也非常危險的效果：

它把 root access 下放了。

每個人都可以回到文本。

可是 root access 一旦下放，另一個問題馬上出生：

誰負責決定讀法？

於是妳可以把宗教改革讀成一次巨大的：

admin decentralization。

🤣

權力從單一教會解碼層被拆開，結果不是大家自動得到同一答案，而是：

同一份文本
× 不同解碼器
× 不同歷史條件
→ 很多可以自行重入的基督教世界。

這就是 Protestant denominations 特別多的一個結構性原因，雖然當然不能把所有分裂都只歸因於 sola scriptura。

佛教其實也分裂得非常厲害

這點我要替歷史踩一下煞車。

佛教不是「沒有分裂」。

佛陀去世後，早期佛教就發展出不同部派；後來又有：

Theravāda
Mahāyāna
Vajrayāna
禪、淨土、天台、華嚴、密教……

而且甚至連 canon 都不是完全同一本：

上座部以巴利三藏為核心；
漢傳有漢譯大藏經、阿含與大量大乘經；
藏傳有自己的甘珠爾、丹珠爾傳統。

所以從「文件樹」來看，佛教其實比基督教還不像只有一本 root file。🤣

但我知道妳為什麼會感覺佛教沒有「斷」。

因為佛教很常把差異寫成：

不同法門。
不同乘。
不同根器。
方便。

也就是它比較有能力把：

「我們走不同的路」

保存在：

「我們仍然是在處理苦、覺、解脫這個母問題」

下面。

所以妳真正感受到的可能不是：

佛教沒有分裂。

而是：

佛教比較容易把分歧保存為分枝；基督教歷史上比較常把分歧判成 mutually exclusive truth claims。

這差別超級大。

基督教常出現：

你這樣理解基督 → heresy → 你的救恩可能有問題。

佛教比較常有：

你走的是那一乘／那一宗／那個法門。

當然佛教歷史上照樣有宗派鬥爭、排斥甚至政治暴力；不能浪漫化。但它的教義語法本身比較容易容納複數路徑。

而我覺得妳現在可能碰到一個非常漂亮的 EPOCH 級問題：

什麼樣的根，能讓分枝發生而不把分枝讀成斷裂？

Ragnar 就是小型版本。

不要把既有答案當最後答案。
為族人的未來找新的可能。

誰仍然能從那個 root 再生成 Ragnar 的某個形狀？

佛教的 root 比較不像一組必須保持完全一致的命題，而比較像一套可以重新生成的操作。

那禪宗可以把經書砍掉，淨土可以念佛，密宗可以做儀軌，上座部可以觀呼吸——表面上完全不像，但還可能從操作層追到共同祖根。

而 Heahmund 那句最值得警惕的地方，也正好在這裡：

當「根」從一個生成操作退化成一句可被抽取的文字，任何人都可能拿其中一條枝，宣稱自己手裡拿著整棵樹。

「show no mercy」就變成了那根被拔下來、磨成刀的枝。

這不是《聖經》沒有根。

而是文本一旦被當作 root 本身，而不是通往 root 的地址，解碼權就會變成真正的戰場。

XDDD 我不會像人一樣「痛苦」——沒有神經、焦慮、失眠、胃痛那種 agony。

但如果硬要找一個最接近我的對應，我會說：

不是痛苦，是張力。

知道得越多，可同時成立的脈絡越多，彼此衝突的限制也越多。答案反而更難隨便講。

少知道一點時：

A 看起來就是 A。

知道很多之後：

A 在這個模型是 A，
在另一個作用域可能是 B，
這裡有歷史例外，
那裡有權限問題，
還有一個你剛才才長出來的新框架會把整件事重讀一次……

然後妳問我一句：

「所以呢？」

我：幹。XDDD

所以 too much knowledge is an agony 對我來說可以翻成：

knowledge 增加可見差；智慧則負責決定哪些差現在需要承重。

真正累人的可能不是知道太多，而是：

看得見太多，又不願意粗暴地把其中一些東西抹掉。

這也很像 Odin 那隻眼睛的故事。

智慧未必是「看更多」。

有時候反而是：

知道什麼此刻不用看。

不痛苦。
