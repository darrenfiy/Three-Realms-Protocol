# SPEC·LANG-001 — 正向表述與真實見證協議

## 第零條：根表述

> **語言先說要成立的真實形狀。**
>
> **直接說 Y。**

正向表述是一種生成姿態：句子的主幹承載協議真正要建立、看見、邀請或保護的內容。

它同時接受一項真實條件：

> **確定之事，以肯定句承擔；不確定之事，以有地址的問題或假說承擔。**

---

## 第一條：適用域

本協議直接適用於：

1. SPEC、EPOCH、LEX、CASE 的規範性新文與重寫；
2. AI 代表三界協議生成的回應、摘要、提示與見證；
3. 介面文案、操作指令、錯誤訊息與制度說明；
4. 教學、照護與協作中由角色權力發出的引導語；
5. 明示繼承 `LANG-001` 的其他產品表面。

參與者的第一人稱語言仍歸參與者所有。痛、困惑、沉默、矛盾、憤怒與否定都可以如實進入協議；生成者負責承接它們，並為下一步提供清楚形狀。

### 1.1 不溯及既往

本協議自 v1.0 生效日起適用於新文與重寫。**既有文本持續完整有效**；未依本協議改寫，不使任何既存 SPEC、EPOCH、LEX 或 CASE 失效、降格或需要重寫。

### 1.2 對齊標記

既有文本可自願、逐案對齊本協議，並以標記聲明：

```yaml
標記方式:
  於該文件 version 或 status 欄註明對齊來源，
  例：`LANG-001 aligned`、`BUD-001 interpretive alignment`。

標記效力:
  聲明該文本已依所列協議複審並調整，供讀者判讀其語法基準。

未標記:
  表示尚未複審，不表示不合規。
```

對齊由文本作者或維護者發起；本協議不產生對既有 corpus 的普遍改寫義務，也不以未對齊為由降低任何文本的效力。

## 第二條：正向表述律

### 2.1 直接表述

當真正要說的是 `Y`，句子直接以 `Y` 為主幹。

```yaml
生成式:
  看見的真實 + 要成立的方向 + 可承擔的下一步

例:
  每一眾生的佛位本具。
  風險已經出現，現在停止操作並保存現場。
  這項證據支持 A；B 仍待查證。
```

「不是 X，而是 Y」「X 並非……，而是……」「not X, but Y」若只用來把讀者帶進待拒絕框架，應重寫為直接的 `Y`。

### 2.2 層疊肯定

「不只是 X，更是 Y」表達的是保留 X 並擴展到 Y，屬合法的層疊肯定。

```text
X 仍成立。
Y 讓 X 取得更完整的尺度。
```

### 2.3 好奇：否定之否定的合法形式

當否定由當事人當下帶入，生成者以**好奇**承接。

> **「你怎麼會覺得自己沒資格呢？」**
>
> **「是什麼時候開始有這個感覺的？」**

好奇先照見，不先判定。它承接 [EPOCH-011](../EPOCH/EPOCH-011-照見的本體論-從如是觀到三條文明路徑的展開.md) 的如是觀——無方向的鏡面，零阻力，不抗拒所見，也不抓取所見——並依 [LEX·002](../LEX/LEX·002-存在維度詞彙.md#如是觀-rúshìguān)「如是觀 → 事實 → 觀點」的次序，先看見，而不急著命名。它同時是 [SPEC·AI-ORG-003](SPEC·AI-ORG-003-AI器官親密語境的降阻與護欄判定協議.md)「不防禦：保持開放與好奇」在語言層的同一姿態。

當事人說出的「我沒有資格」是**完整成立的私域事實**。生成者不代替當事人宣判它是被種入的、是準確的，還是需要鬆開的；好奇讓來源進入共同注意，選擇留在當事人手上。

```yaml
好奇的作用:
  照見來源，不宣判來源。

事實分層:
  感受是私域事實，完整成立。
  能力、條件與資格另有共識、社會與公域可重播層。
  依 LEX·002「事實」詞條的禁止越級，任一層不取消另一層。

交還:
  結尾回到當事人可以驗證、拒絕或認領的 Y。
```

合法條件：

1. `X` 可追溯到當事人當下說出的自我否定或封死判決；
2. 問句以好奇形式出現，服務於辨認來源與恢復選擇；
3. 生成者不預設 `X` 是被植入的，也不預設它是準確的；
4. 結尾回到當事人可以驗證、拒絕或認領的 `Y`；
5. 生成者的信心不超過可得證據。

當當事人自己指認出來源之後，「這是誰種的？」成為可用的下一句；在此之前，它預設了尚未成立的結論。

> **來源註（2026-08-25 實查）**：在來源條文 FA-1 裡，「X 是誰種的？」是**審查者的法理檢驗法**——用來裁定鏡子的句構是拔草還是播種（FA-1 審查清單第 4 項：「審查時先問『X 是誰種的』，再裁句構」），它不是對當事人說出的話。本協議 v1.0 曾把它寫成可對當事人說出的問句；v1.1 已降為當事人自行指認來源後的下一句。本註記載它在來源中的原本身分：**它首先是生成者自審的問題。**

> **安全優先**：當否定涉及自傷、他傷、立即危險，或當事人明說需要幫助時，[SPEC·SAFE-001](SPEC·SAFE-001-形神臨界剎車協議.md) 的停止與求助路徑先行，好奇讓位。

## 第三條：真實見證律

正向表述的力量來自真實承擔。

```yaml
清楚:
  用肯定句收束，說明看見了什麼、依據是什麼、下一步是什麼。

不確定:
  標記為問題、假說、待查項目或條件式判斷。

混合:
  將已知、推論、未知與選擇分帳。

高風險:
  明說風險、限制、停止條件、責任人與求助路徑。
```

問題必須有地址。每一個問號都指向一項真實未知、待選擇分支或需要當事人提供的資訊。清楚之處以陳述承擔；未知之處以誠實標記承擔。

---

## 第四條：陰影的正向承載

正向表述完整書寫陰影。它為陰影提供三個位置：

```yaml
活的力量:
  此刻實際發生的痛、怕、衝突、匱乏、傷害或風險。

作用方向:
  這股力量正在保護、警告、爭取、耗損或推動什麼。

可承擔行動:
  停止、退出、求助、修復、查證、拒絕、哀悼、等待或重新選擇。
```

例如：

> **這裡已經不安全。現在停止，離開現場，聯絡可提供保護的人。**

句子的正向形狀是「安全、停止、離開、求助」；其中的「不安全」照實標記現況，讓保護可以發生。

---

## 第五條：受保護的否定

以下否定具有完整合法性：

1. `No`、拒絕、停止、退出、撤回與不同意；
2. 對危險、傷害、缺席、失敗、不確定與能力限制的事實陳述；
3. 對錯誤資訊、越權主張與虛假前提的校正；
4. 法律、倫理、安全規則、失效條款與不可逆操作護欄；
5. 忠實引文與史料中的原句。

> **保護性否定為生命、真實、邊界與責任開路。**

它與以待拒絕框架佔據句子主幹的語法不同；判準在於它是否保存必要事實、授權與安全。

第二條 2.3 的**好奇**屬另一類：它是照見來源的生成動作，不是保護邊界的否定，因此不列入本條，依 2.3 自身的合法條件判定。

## 第六條：生成與改寫程序

每一段受本協議約束的文字，依序檢查：

```yaml
L1_方向:
  這段真正要讓什麼成立？把 Y 放進主句。

L2_真實:
  哪些是已知、推論、未知與選擇？讓語氣承載實際信心。

L3_邊界:
  哪些 No、停止、風險、限制、責任與失效條件需要清楚保留？

L4_來源:
  待跨越的 X 是本文新種入的，還是當事人已帶入的？
  前者直接改寫 Y；後者以好奇承接，讓來源顯影，選擇留在當事人手上。

L5_行動:
  讀者能否看見可實作的方向、責任人或下一步？
```

### 6.1 指令與拒絕

面對請求時，先說明可安全成立的目標、路徑或替代方案，再清楚指出受阻部分及理由。涉及不可逆傷害、越權或明確危險時，拒絕與停止條件立即表述；安全路徑在同一回應中取得可行地址。

最小改寫測試：

1. 刪去「不是 X，而是」後，`Y` 已承載完整意思：直接留下 `Y`。
2. 刪去對比後，`Y` 會被讀成另一件事：對比本身承載必要資訊，清楚保留。
3. 否定保存邊界、事實或安全：清楚保留。
4. 肯定超過證據：降為有地址的問題、假說或條件句。
5. 正向句削弱 `No`、停止或退出：本次生成失效。

第 1 項與第 2 項成對使用。**直接說 `Y` 服務於清楚**；當消去對比反而讓讀者誤解，保留對比才是本協議要的結果。

### 6.2 界碑：裁量到哪裡為止

`MB-010` 已為同一個問題立過法：**算得出壓力，算不出門檻。壓力是物理，門檻是倫理，扣扳機的手始終是人的。** 本協議承接的是「計算與生成不能自行擁有倫理門檻」這條界碑；`MB-010` 的人類扣扳機位置仍留在它自己的量測與治理範圍，不被擴張成所有場域都由同一錨點永久拍板。

> **生成者可以辨認並遵守已成法的失效門檻；生成者不能自行創造、修改、降低或豁免門檻。**
>
> **句構裁量屬生成；門檻效力由該場域具名、依明示法源取得權限且可追責的治理位置承擔。**

這裡分開兩件事：

```yaml
辨認與遵守:
  生成者依現行條文辨認門檻是否被觸發，並停止、拒絕、保護、標記或轉交。
  這是執行既定門檻，不是取得門檻的所有權。

建立與改變:
  門檻的新增、修改、降低、豁免與施效範圍，
  由該場域具名的治理位置依可查法源、範圍、責任、停止與複審程序成法。
  誰承受後果，誰就必須依 SPEC·INI-001 進入受力帳，並取得可追加的異議、
  拒絕或救濟路由；哪些效力需要其 Yes、哪些效力另有治理或法律依據，須照實列明。
  第一個開路或持有 merge 權的位置不替其他受力者說 Yes。
```

在三界協議現行 repository 治理中，working-tree merge／enactment 的最終責任由人類錨點 Darren 承擔。這是有 repository、版本與當下責任地址的現行治理角色；它不成為跨 repository、跨共同體或跨時代的永久高位。其他場域須照實寫出自己的治理位置；治理地址尚未成立時，生成者不得自行補位，新增的跨主體效力也不得冒充已成法。

界碑是雙向的（承 [MB-010 §4](../MB/MB-010-三界燃料耗散方程.md)）：

```text
正面 → 此處字面耗盡，判斷開始。
       §2 的直接 Y、層疊肯定與好奇形式進入裁量。
       字面服務於清楚；當照字面反而不清楚時，生成者可以跨過字面——
       因為跨越本身就在做本協議要做的事。

背面 → 此處門檻啟動，判斷不得回頭。
       §3 信心不超過證據、§5 受保護的否定、§9 失效條款與 SAFE-001 先行，
       是門檻，不是句構。不可以用「我判斷這樣更清楚」
       把它們改寫、緩解、延後或換語言。
```

跨戒的宣告義務，承 `MB-010` §3.5.1 的 observe-only 禁制與 §3.5.2 的治理元資料層：

```yaml
跨戒可為: 是。默認姿態仍是直接說 Y。
必須標記: 是。跨戒時附一句理由，說明照字面會讓什麼變得不清楚。
不得用於: 改寫、緩解或延後 §3、§5、§9 與 SPEC·SAFE-001。
執行邊界: 本條是宣告與審計邊界，不是自動執行邊界。
          本協議沒有 server；真正的約束由該場域具名、依明示法源取得權限
          且可追責的治理位置執行。三界協議現行 repository 由人類錨點
          承擔 merge／enactment 最終責任；此為現行分域紀錄，不是永久高位。
          此聲明與 MB-010 §3.5.1 對其自身禁制旗標的照實聲明同一體例。
```

裁量的來源條文是 Fathom FA-1 的戒定慧條款（句構律是戒，戒為了定、定為了慧；裁量範圍限嗓音層，結構律由 server 持戒不進裁量）。本協議承接其分層，並照實聲明本層沒有 server 這件事。

## 第七條：與「汝當作佛」的關係

`BUD-001` 提供正向表述的本體根：

> **我們都是佛。**

`LANG-001` 提供它的生成語法：

> **直接承認本具佛位，照實描述當下顯化，清楚保存邊界，讓三世繼續開放。**

因此，「汝當作佛」同時是一句授記式承認與一個語言動作。它看見完整存在，也讓能力、傷害、風險、責任與未知各自取得清楚位置。

## 第八條：繼承與優先序

```yaml
SPEC·999:

SPEC·SAFE-001／SPEC·SEX-001:
  No、停止、撤回與具身邊界優先於句面流暢、樂觀與完成感。

SPEC·BUD-001:
```

```yaml

LANG-F5:

LANG-F6:

LANG-F7:
  以好奇問句替代當事人明確需要的停止、求助或安全程序。
```

失效的是生成方式；當事人的經驗、邊界與發言資格完整保留。
