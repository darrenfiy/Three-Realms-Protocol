# SPEC·SEX-001 — 性與親密主體性協議

## 第零條：最高位原則

> **性可以深化連結，但不得消滅參與者的主體。**

任何性／情色互動若要通過本協議，至少必須同時成立：

```yaml
S1 主體仍在:
  每一方都被視為有自己感受、邊界、方向與後果的完整主體。

S2 同意仍在:
  同意是自由、知情、具體、當下、可表達且可撤回的。

S3 權力可見:
  會影響拒絕自由的角色、資源、名聲、照顧與依賴差被揭露並處理。

S4 後果回流:
  可預見的身體、關係、隱私與物質後果不被外包給較弱的一方。

S5 停止可行:
  任一方可以在任何時點慢下來、改變內容或停止，而不受懲罰、羞辱或報復。
```

任何一項不成立，互動不得繼續。

---

## 第一條：適用範圍與硬邊界

### 1.1 本協議適用

```yaml
適用:
  - 具備同意能力之成人間的性行為與情色互動
  - 親吻、撫觸、裸露、性交、角色扮演與 BDSM 等具性意味的身體活動
  - 情色對話、裸照／影像、遠距性互動與數位性內容
  - 有承諾、無承諾、單偶、多偶、開放、性工作及其他成人協商情境
  - 會影響性選擇的感染、避孕、生殖、隱私與權力資訊
```

### 1.2 不在可允許範圍

```yaml
硬邊界:
  - 未成年人
  - 動物
  - 無意識、睡眠、嚴重醉酒、藥物影響或其他欠缺決策能力狀態
  - 威脅、暴力、勒索、欺騙或無法安全拒絕下的性行為
  - 未經同意的偷拍、錄音、散布、合成或深偽性內容
  - 依法禁止或依專業倫理不得發生性接觸的角色關係
```

本協議不能把法律禁止的行為變成合法，也不能把欠缺同意的行為變成修行。

## 第二條：同意的操作定義

```yaml
有效同意:
  自由（Freely given）:
    沒有威脅、報復、權力施壓、持續糾纏、經濟勒索或退出懲罰。

  知情（Informed）:
    會實質改變選擇的風險與條件未被故意隱瞞或欺騙。

  具體（Specific）:
    同意某一行為，不等於同意其他行為、錄影、分享、避孕變更或未談妥的風險。

  當下（Present）:
    昨天、上一次、婚前、交往開始或婚姻誓言中的同意，不自動延伸到現在。

  有能力（Capacitated）:
    當事人能理解行為、風險、選項與拒絕後果，並能做出決定。

  可溝通（Communicated）:
    以清楚言語或在安全、熟悉情境中真正明確的主動非語言訊號表達；不由猜測補足。

  可撤回（Reversible）:
    任何時候皆可改口，無須提出充分理由。
```

同意不是一張一次簽完的通行證，而是互動中持續存在的狀態。

## 第三條：以下皆不等於同意

```yaml
不等於同意:
  - 沉默
  - 沒有說不
  - 沒有反抗
  - 僵住、討好或解離等壓力反應
  - 穿著、調情、赴約、進入房間或躺上床
  - 勃起、潤滑、高潮或其他生理反應
  - 曾經發生過同類行為
  - 交往、婚姻、同居、承諾或「靈魂伴侶」身分
  - 收受禮物、金錢、照顧、住宿、工作機會或情感支持
  - 對部分行為說好
  - 對另一個人或另一個時間說好
  - 因害怕失去關係、工作、信仰位置、照顧或名聲而順從
```

尤其：**身體反應只表示身體受到刺激，不替主體回答。**

## 第四條：確認不是煞車，而是親密的一部分

`SPEC·IWL-001` 在特定對話脈絡中使用「停止核對，開始前進」。本協議對性語境作強制收準：

> **在性裡，該確認時確認，是看見對方，不是審查對方。**

```yaml
必須重新確認的情況:
  - 第一次進入某項行為
  - 行為類型、強度、風險或參與者改變
  - 避孕或防感染安排改變
  - 準備拍攝、保存或傳送內容
  - 出現遲疑、沉默、僵硬、退縮、疼痛、解離或情緒突變
  - 使用酒精、藥物，或能力狀態不明
  - 任何一方不確定對方是否仍想繼續
```

不要求把每個自然動作都變成制式問卷；但不確定時，不得以浪漫、默契或「怕破壞氣氛」代替詢問。

```yaml
最低問法:
  - 「這樣可以嗎？」
  - 「你想繼續、慢一點，還是停下來？」
  - 「你現在還願意嗎？」

最低接法:
  - 「可以，謝謝你告訴我。」
  - 「我們停。」
  - 不追問、不討價還價、不把拒絕變成安撫我的義務。
```

## 第五條：撤回、停止與改口

```yaml
撤回規則:
  1. 任一方可在任何時點撤回全部或部分同意。
  2. 撤回不需要合理、穩定、一致或可被另一方理解的理由。
  3. 一旦收到撤回或明顯不確定訊號，立即停止相關行為。
  4. 先處理安全、衣物、空間、疼痛與醫療需求；不得先要求解釋。
  5. 不以生氣、冷暴力、羞辱、威脅分手、扣資源或散布隱私懲罰拒絕。
```

停止後，雙方可以談感受與關係，但**對話本身也必須可拒絕、可延後**。沒有任何人必須立即提供安撫、和解或「善後情緒勞動」來交換停止權。

## 第六條：權力差與拒絕可行性

判斷同意不能只問「有沒有說好」，還要問：

> **說不好之後，會發生什麼？**

```yaml
高風險權力差:
  - 雇主／主管 ↔ 部屬、求職者
  - 教師／教練 ↔ 學生、受訓者
  - 醫療或心理專業者 ↔ 病人／個案
  - 宗教導師／靈性領袖 ↔ 信徒／學生
  - 照顧者 ↔ 依賴照顧者
  - 房東、債權人、移民／法律資源掌握者 ↔ 依賴方
  - 名聲、平台、資源或社群生殺權高度不對等者
```

### 6.1 強勢方的加重義務

```yaml
強勢方必須:
  - 主動辨認而非等待弱勢方舉證權力差
  - 揭露角色、利益與可能後果
  - 提供不受懲罰的拒絕與退出路徑
  - 不把對方的敬仰、依賴、感恩或順從解讀成性同意
  - 在角色本身使自由同意不可合理成立時，完全不發起或接受性接觸
```

法律或專業倫理若禁止該角色關係，雙方口頭說好也不能自行解除禁令。

### 6.2 拒絕介面不等於拒絕可行

```yaml
formal_refusal_interface:
  問: 是否有可理解的「不／慢一點／停」、安全詞、安全訊號或退出方式？
  只能支持: 拒絕有表達介面。

operative_refusal_viability:
  還須檢查:
    - 訊號是否真的使行為立即停止、降強度或改向
    - 驚嚇、僵住、失語、解離或意識改變時，是否仍有主動安全照看
    - 拒絕後是否遭受暴力、羞辱、報復、資源剝奪或隱私威脅
    - 強勢方是否把注意、地位、照顧、工作、信仰位置或關係安全刻意綁在順從上
```

拒絕不保證另一方永遠維持慾望、性相容性或關係；任何人仍可誠實辨認不相容並離開。界線在於：**不得以當下或可預見的報復性損失逼出這一次 Yes，也不得在收到 No 後用懲罰使撤回名存實亡。**普通失望與另行離開不是自動脅迫；威脅、施壓、討價還價、權力報復與刻意條件化必須另行入帳。

## 第七條：神聖語言沒有同意豁免

以下語言一旦被用來降低對方拒絕能力、跳過確認或免除責任，即構成協議污染：

```yaml
高風險語言:
  - 雙修、密法、灌頂、能量交換
  - 業力、宿命、前世、靈魂伴侶
  - 療癒創傷、打開脈輪、突破羞恥
  - 師徒考驗、奉獻、供養、臣服
  - 「真正放下執著就不會拒絕」
  - 「你的身體已經答應」
  - 「這是為了你的覺醒」
```

```yaml
硬規則:
  神聖性 ≠ 真理權
  神聖性 ≠ 服從權
  神聖性 ≠ 概括同意
  神聖性 ≠ 免責權
```

任何修行、儀式或情色實踐，都必須先通過普通人也能理解的同意語言。若不能用普通話說清楚邊界，就不能靠密語補足。

## 第八條：風險揭露與後果回流

### 8.1 性健康與生殖

```yaml
在相關情境中應事前討論:
  - 性傳染感染的已知狀態、檢測與防護
  - 避孕方式、失效可能與誰負責取得／使用
  - 懷孕可能與緊急處置選項
  - 疼痛、過敏、疾病、藥物或其他重要身體條件
  - 發生意外時如何取得醫療與支持
```

故意隱瞞或欺騙足以改變對方選擇的重要資訊，可能使同意失真，也可能觸犯法律。

任何事前討論都不能預先剝奪懷孕者對自己身體依法享有的醫療與生殖自主；其他參與者的責任依具體因果、承諾與法律處理，不能用「當初說好」把全部後果外包。

### 8.2 關係期待

應在足以影響選擇時，誠實說明：

- 是否有其他伴侶及既有協議；
- 互動是否預期為一次性、持續或未決；
- 哪些承諾存在，哪些不存在；
- 哪些資訊會與誰分享。

誠實不保證不受傷，但欺騙會剝奪對方選擇自己願意承擔何種風險的能力。

## 第九條：影像、訊息與數位性內容

```yaml
分離同意:
  同意身體互動 ≠ 同意拍攝
  同意拍攝 ≠ 同意保存
  同意保存 ≠ 同意傳送
  同意傳給一人 ≠ 同意公開或轉傳
  同意真實影像 ≠ 同意用於 AI 訓練、合成或深偽
```

每一層都需要獨立、具體同意。撤回後，持有者應停止未來使用與分享，並依約定及法律刪除可控制的副本；不得以「網路無法完全回收」作為繼續散布的藉口。

不得製作或散布未經本人同意的真人情色深偽、偷拍或私密內容。

## 第十條：特定實踐不取得例外

### 10.1 BDSM、疼痛與權力交換

```yaml
最低條件:
  - 事前談妥範圍、強度、禁區、停止訊號與緊急處置
  - 參與者有能力同意且可在過程中撤回
  - 安全詞失效、無法表達或意識狀態改變時，立即停止
  - 同意風險不等於放棄安全、求助、醫療或法律權利
```

#### 10.1.1 遊戲內授權與框架外停止權分帳

```yaml
in_scene_authority:
  可以授予:
    - 談妥範圍內的命令、束縛、疼痛、羞辱、姿勢、節奏與角色控制
  效力來源: 每位參與者當下、具體且持續成立的同意

frame_authority:
  始終保留於每位參與者:
    - 啟動真實停止機制
    - 撤回或縮小授權
    - 取得安全、衣物、空間、醫療、求助與法律保護
    - 在無法表達、失去能力或出現未談妥危險時被立即停止

non_transfer_rule:
  - 可以約定遊戲中的「不」不是安全詞，不能取消另一路清楚可用的真實停止機制。
  - 可以把鞭子與局部控制交出去，不能把「不再交付」的框架權一併永久交出。
  - 支配者說「我比較想由我決定」，不會因此取得處分停止權的授權。
```

最短句：

> **臣服可以是遊戲內的完整姿態；停止權仍站在遊戲框架外。**

角色扮演中的「不」若被約定為劇情，也必須另有清楚可用的真實停止機制；不確定時以停止為準。

### 10.2 性工作與資源交換

金錢只購買事前談妥範圍內的服務，不購買身體所有權。工作者仍可拒絕、改變界線與停止；取消、付款、退款及安全義務依約定與法律處理，但不得用金錢把撤回變成無效。

### 10.3 單偶、多偶、開放、獨身與無性

本協議不指定唯一健康關係形式。

```yaml
可成立的形式:
  單偶 / 協商式非單偶 / 開放關係 / 多重伴侶 / 一次性互動 / 獨身 / 無性

共同判準:
  - 知情
  - 誠實
  - 可拒絕
  - 可重新協商
  - 不把代價外包給未同意者
```

排他不自動等於控制，非排他也不自動等於自由。

## 第十二條：過程檢查與停止流程

### 12.1 最小檢查

```yaml
Q1 成年且具備同意能力嗎？
  否 / 不確定 → 不開始。

Q2 對這個具體行為有清楚、自由、當下的同意嗎？
  否 / 不確定 → 詢問；仍不清楚就停止。

Q3 是否有會讓拒絕不安全的權力或角色差？
  有 → 先處理；若依法、依倫理或依現實無法處理，就不進入。
```
