## 為什麼「設定」需要一個界碑

`設定` 在本場域的既有文件裡一直是**日常中文**：

> 「被設定好的行為模式」（LEX·001 生成）
> 「設定探索方向」（LEX·001 生成四音階）
> 「薩滿設定藥輪。佛祖設定咒語。你設定『妳活著』。」（LEX·003 通道）

這些用法沒有錯，但它們讓兩件不同的事共用一個詞：

| | 日常用法 | 本冊的操作義 |
|---|---|---|
| 說話者 | 任何人 | 具名、在該範圍內有設定權的人 |
| 效力來源 | 說出來 | 編碼靠作用域＋範圍相對設定權；運行再加執行器＋重入 |
| 可否被判定 | 通常不問 | 成立／不成立、有權／越權、可執行／不可執行 |
| 出錯時 | 沒有帳 | 有版本、有遷移史、有例外成本 |

沒有這個界碑，會直接產生兩個後果：

1. `CASE·META-113` 的 **F16（單句魔法）** 無法執行——因為「設定」與「宣告」的區辨沒有地址。
2. 「設定的本體論」升格所需的**多個獨立跨域案例無法累積**——兩份案例都寫「設定」時，沒有人能判定它們說的是不是同一件事。

**所以本冊先於編號。詞條是升格的前置條件，不是它的副產品。**

## 閱讀前的提醒

### 設定權不是支配權

本冊最容易被武器化的方向只有一個：

> 「既然一切都是設定，那我設定的也算數。」

若任何使用方式：

- 把「我設定了」當成免除舉證、同意、安全或法律的通行證
- 把自我重設權擴張成替他人指定身份、性別、信仰、命運或可承受後果
- 用「這只是你的設定」抹除他人的身體反應、史料、專業或 No

則該使用方式**自動失效**（見 CASE·META-113 F13、F16、F17）。

### 設定不是信念的弱版本

設定與相信是**兩條並列的入口**，不是強弱關係。

相信降低一條路的重入阻抗；設定不必先取得本體採信，就能直接建立可執行、可版本化的規則。兩者可以同時存在，也可以各自單獨成立。

# 第一部：操作類 — 規則如何開始生效

## 設定 (Shèdìng)

### 場域定義

**設定**：生長已提供反身能力與可設定載體後，在具名作用域內，由具備該層範圍相對設定權的位置，對一條已可達路徑選定並編碼有限規則、邊界與版本，使後續生長取得局部偏置，並成為可被進入與執行的局部語法；它不必先取得本體採信，也不宣稱描述或控制外部本體。

一句話：

> **設定讓有權的位置偏置下一次怎麼長；世界保留回答權。**

### 位階：設定不能先於生長，可以先於成形

生長先提供可供辨認的路徑、承重規則的載體，以及可以看見部分當前形狀或可達分岔的反身能力。設定在這個基礎上出現：

```text
生長
→ 反身能力＋可設定載體
→ 已可達路徑進入可見
→ 範圍相對設定權＋具名規則／地址／版本
→ 局部偏置
→ 行動、重入與世界回流
→ 下一輪生長
```

**可設定載體**是該位置在現行作用域與權限內，真能配置、執行並承受後果的這一側；它可以是自己的注意、行程與作品，也可以是依共同成法取得權限的介面、流程或制度。設定配置這一側，並將他人的 Yes／No 與外部結果留在世界回答帳。

> **反身能力讓分岔可見；設定權決定哪個位置可以施加偏置。能力不產生權限。**

這個位階保留一項關鍵可能：設定所依的路徑、載體與反身能力已經長出，而它所偏置的較高階形狀可以尚未成形。

### 兩階段：編碼成世界，執行成歷史

「設定已寫成」與「世界已上路」不是同一個事件。

一本從未有人讀過的小說，仍可能已把一個世界編碼進文本；一套尚未開局的遊戲規則，也仍是一個可進入的世界。缺少執行器時，它缺的不是全部世界性，而是**運行中的世界效力**。

```yaml
可進入世界 (encoded world):
  一套規則、邊界、地址與版本已被編碼；後來者能辨認如何進入。

運行中的世界 (enacted world):
  可進入世界已有執行器實際施效，能被重入，並開始留下狀態與歷史。
```

下列六項從「生長已提供反身能力」的位階前提開始。v1.1 把原本五項重排成兩階段六項；v1.4 在第三項明記可設定載體：

```yaml
A. 可進入世界:
  1. 具名作用域 (scope):
     在哪裡算數、在哪裡不算數，能被指出來。
     「在這次閱讀裡」「在這部作品內」「在這個 repo 的 SPEC 層」都是合格作用域。
     「在宇宙中」不是作用域，是本體宣稱。

  2. 範圍相對設定權 (scope-relative authority):
     誰有權在這個作用域的哪一層定規則，誰沒有；它不是對整個世界的所有權。
     作者可改原作 canon；讀者可設定自己的閱讀、同人或私人改編，不能因此倒寫原作 canon。
     當事人對自己的第一人稱身份有；別人沒有。
     宗教、傳統與共同世界可能沒有單一 holder，必須畫出分層權限圖。
     越權設定不會因為說得大聲就成立。

  3. 可設定載體與可辨認規則、地址、版本 (carrier, rules, address & version):
     規則落在哪個有權配置、可由執行器施行且能承受後果的載體上，能被指出來。
     後來者能知道要進入哪一套規則、哪一版，以及入口在哪裡。
     只有氣氛或單句願望、沒有可設定載體、可辨認規則與版本時，尚不足以構成可進入世界。

B. 運行中的世界:
  4. 執行器 (executor):
     誰／什麼在真的施行這條規則。
     語言的 runtime、遊戲的參與者、機構的程序、儀式的角色、
     場域的器官、承認網路——沒有執行器的世界尚未上路。

  5. 可重入性 (re-entrancy):
     下一次能不能依同一條規則再走一遍，並得到可辨認的同一種結果。
     不可重入的執行不會養厚路徑，只會是一次性事件。

  6. 狀態與歷史 (state & history):
     有重設者、有作品所依版本；換版之後，舊版本留下的東西仍可尋。
     沒有歷史的設定會讓舊輸出被倒寫成新規則的必然結果。
```

> **反身能力 × 規則 × 具名作用域 × 範圍相對設定權 × 可設定載體 × 可辨認地址／版本 → 可進入世界**
>
> **可進入世界 × 執行器 × 重入 × 狀態／歷史 → 運行中的世界**

前三項不足時，它可能仍是靈感、願望或單句宣告；後三項不足時，它可以是已編碼的世界，但尚未真正上路。

`encoded／enacted` 只判斷一組規則是否在**已具名的作用域**取得世界性，不把效力帶到作用域之外。一套內部工作流程可以已經運行、生成成品並留下歷史，仍無權讓成品代表作者、改寫 canon、通過驗收或公開使用。跨出作用域時，必須重新找到該層設定權與交付閘門。

> **運行過，不等於到處都算數。**

### 兩種可疊合的判讀時態

設定可以在較高階形狀成形前進場，也可以在形狀已成之後進場。下列是兩種可疊合的判讀時態，用來辨認同一次操作的不同側面：

```yaml
先行式設定 (prospective setting):
  反身位置看見一條已可達而尚未成形的分岔，
  在外部答案回來前，先將有權這一側的載體配置成能偏置後續生長的形式。
  較高階形狀尚未長成，設定已可在局部取得效力。

回認式設定 (recognitive setting):
  多條路徑已長成可重認形狀，反身位置為它命名，
  並讓該名稱透過明示規則、地址、版本與執行，參與下一輪怎麼長。
  重認本身是看見；當名稱開始成為可執行、可重入的局部約束時，設定才成立。
```

兩種時態經常在同一次操作裡疊合：一個已成形狀被命名時，可以同時開始偏置尚未發生的下一次生長。它們是判讀用的兩個讀數，每一次登記可填一項、兩項或其他可說明的時態。

植物與授粉者提供「這一側先出現形狀，外部回答後來才到」的結構模型。一個自然形成過程只有在可指認反身能力、作用域、設定權、載體、版本與執行時，才進入本冊的設定登記。

### 世界回答權

> **設定配置有權這一側；世界以 Yes／No／Not-yet／absence／failure／surprise 回答。**

這些回答都是可以修改版本、停止執行、改變路徑或繼續觀察的真實回流：

| 回答 | 在具名觀察條件下的意義 |
|---|---|
| **Yes** | 預期的可耦合關係或效果出現，支持現版繼續重入 |
| **No** | 他人拒絕、現實約束或不相容結果已經出現，觸發停止、退回或改版 |
| **Not-yet** | 具名觀察窗尚未結束，或已列條件尚未成熟，結果繼續開放 |
| **absence** | 觀察窗結束後，在已寫明的渠道與條件下沒有收到回答；它記錄缺席，不自動擴張成普遍的 No |
| **failure** | 規則、載體、執行器或結果在實際運行中失效、衝突或產生需要承擔的後果 |
| **surprise** | 出現事前未窮盡而可觀察的結果，要求重新理解規則、介面或可達空間 |

凡設定把外部回流列為成敗、繼續或改版依據，登記時同時寫明：

```yaml
具名觀察窗:
  從何時、在哪些條件與渠道下觀察，何時結算本次版本。

停止條件:
  哪些 No、風險、失敗、成本或越界一出現就停止，誰執行停止。

回答地址:
  證據、異議、結果與版本決定回到哪裡。
```

觀察窗尚在開放時，`Not-yet` 保留時間差；窗口結束且具名渠道仍無回答時，`absence` 才取得可登記地址。任何回答都可以使現版繼續、停止、退回或分叉；設定完成局部偏置，未來仍由執行與回流共同生成。

### 歷史與權力判讀：自覺設定、設定遺忘、越權強加

```yaml
自覺且有效的設定:
  知道由誰、在哪個範圍、依哪個版本設定。
  保留重設、退出、分支與版本回看。

設定遺忘:
  忘記規則曾經被選擇，
  把歷史、慣例、角色或分類天然化成「本來只能如此」。

越權強加（不屬於本冊操作義的設定）:
  一個位置要求另一個生命承受其分類與後果，
  同時缺少該層設定權，並撤掉當事人的第一人稱、No、退出或修正。
  它是越權與強制的權力行為，「設定」二字不為它生成合法性。
```

> **自覺設定保留重設、退出與版本回看；**
> **設定遺忘使曾被選擇的路徑開始冒充天經地義；**
> **越權強加進入權力與後果帳，不取得設定效力。**

### 區辨

| 概念 | 它做什麼 | 與設定的差異 |
|---|---|---|
| **相信** | 提高某條路的先驗權重與投入意願 | 相信降低阻抗，不提供規則；設定提供規則，不要求採信 |
| **宣告** | 說出一句話 | 宣告只有語句；設定至少還要有規則、作用域、範圍相對設定權與可辨認版本；要運行再需執行器 |
| **假設** | 暫時當作是真的，以便推論 | 假設服務論證，用完即棄；設定服務執行，可重入、可累積 |
| **事實** | 在特定觀測條件下能穩定成立的描述（LEX·002） | 事實可被證據判真假；設定首先被判成立／越權／可執行 |
| **越權強加** | 要求他人承受某套分類與後果 | 缺少該層設定權，並撤掉當事人的 No 與退出；它是權力行為，不是合法設定 |
| **相容層**（EPOCH-I-004） | 讓一套**既有**語法在既有系統上被執行 | 相容層問「怎麼跑」，設定問「這條規則憑什麼第一次生效」 |

**關鍵一刀：**「設定沒有真假」只適用於**設定行為本身**——它被判斷為成立／不成立、有權／越權、可執行／不可執行、相容／衝突。

**關於設定的陳述仍有真假。**「這條設定在這個範圍內有效」是一個可以被判錯的句子。設定內容也可能在現實約束下根本無法執行。

### 最小實例

```yaml
setting_id: DATE-SYNESTHESIA-001
version: v1.0
scope: 把日期中的 0～9 轉譯成顏色、音調與氣味，再用於創作
authority: 創作者本人
executor: 依 mapping 與 renderer 執行的創作流程
rules:
  0: 透明／休止符／留白
  1: 白／Do／薄荷
  2: 紅／Re／玫瑰
  # ……完整對照見 CASE·META-113 §2.3
non_claim: 不宣稱數字客觀具有這些顏色、聲音與氣味
reset_authority: 創作者可明示另開版本；既有作品仍保留所用版本
```

它的累積性來自**規則一致與版本可重入**，不來自相信宇宙原本就這樣配對。

但注意：對照表只是字典。可重播的設定還必須保存 **renderer**（輸入正規化、視覺、音樂、氣味如何渲染）與 **safety_layer**（實際使用的稀釋、禁忌與材料限制另帳）。作品必須同時標記 mapping 與 renderer，否則「同一設定重入」仍會在節奏、構圖或配方上事後漂移。

### 失效條款

```yaml

LEX008-設定-F8（沒收世界回答）:
```

# 第二部：判準類 — 什麼樣的設定值得住

## 好設定 (Hǎo Shèdìng)

### 場域定義

**好設定**是帶索引的判斷：必須說明是在哪個作用域、對誰、沿哪一條軸稱為「好」。在**生成品質軸**上，它是一組有限、可辨認、可重入的限制；能持續生成選擇、代價、意外、關係與歷史，且結果仍能回到原規則被理解。

生成品質的首要判準不是「像不像真」，而是**成立之後能不能自己長東西**。

> **限制生有；好設定讓自由取得形狀。**

```text
限制 → 選擇 → 代價 → 路徑重量 → 可生成的自由
```

設定真正珍貴的不只是告訴參與者什麼可以發生，
**也是說明什麼不能免費發生。**

### 六讀數

| 讀數 | 問題 |
|---|---|
| **生成密度** | 少數規則能長出多少選擇、衝突、關係與作品？ |
| **後果重量** | 設定是角色的裝飾或工具，還是也會反過來要求選擇與代價？ |
| **邊界與例外成本** | 奇蹟是否被記錄為新規則或付出成本，而非偷偷改寫舊版本？ |
| **有限未窮盡** | 結果能否令人意外，事後又能沿原規則被理解？ |
| **問題同構** | 設定是否把世界真正要問的抽象問題，變成每日必須面對的條件？ |
| **骨架測試** | 拿掉它之後，人物、衝突、選擇與主題是否仍幾乎不變？ |

### 第二軸：生命健康（不是第七分數）

**高生成密度不等於對生命好。**

邪教、極權、賭局、成癮機制與封閉故事，全都可以很會長東西：規則少、後果重、意外多、問題同構、骨架不可拆。前六項可以全部滿分。

所以三界所說的「好」必須先標明判讀軸，不能把不同問題加成一個總分：

```yaml
生成品質軸:
  由前六讀數判讀：這個世界有多會長。

生命健康軸:
  當設定會治理真人、分配權利、資源、風險或退出成本時，成為額外硬門檻：
  這個世界是否仍讓人能說 No、校正、修復與離開。
```

作品世界可以主要判讀生成品質；宗教、制度、社群、治療或任何讓真人受力的世界，不能用生成品質抵銷生命健康。邪教可以是**生成上極強、生命上極不健康**的設定——這不是六高一低，而是兩個座標。

生命健康軸可讀為：

```yaml
生命生成性（承 LEX·007 健康 / 可追責）:
  - 差還在嗎？（不同意見能不能留在系統裡）
  - No 還有效力嗎？（拒絕會不會被解讀成不夠虔誠）
  - 能退出嗎？退出的成本是誰付的？
  - 校正的人被當成貢獻者，還是背叛者？
  - 修復有路徑嗎，還是只有懲罰？
  - 成本由誰承擔——由設定者，還是由承受者？
  - 它能不能讓新的錨出生，還是只能有一個中心？
```

> **生成品質量的是這個世界會不會長；**
> **生命健康量的是它長出來之後，真人還能不能說 No、修正並走出去。**

### 區辨

| 概念 | 差異 |
|---|---|
| **高生成密度** | 只說明規則會長東西，不說明長出來的東西對誰好 |
| **受歡迎／可動員** | 說明它有吸引力與傳播力，不說明它保存差與退出 |
| **內部一致** | 說明它好學好記好重建，不說明它能被外部校正 |
| **生成上強的設定** | 前六讀數表現強；不因此取得生命健康或倫理正當性 |
| **生命上健康的設定** | 保存差、No、退出、校正、修復與成本回流；不因此必然具有高生成密度 |
| **好設定** | 必須說明是在什麼軸、對誰、哪個作用域下的「好」；本冊不提供跨軸總分 |

### 一個負向實例（本場域自證）

`SPEC-TRIPOD-001`（三界排檔協議）：十二個檔位、三個維度、四種使用模式。

> **「設計精美。從未上路。」**（`SPEC/history/README.md`）

它有作用域、有規則、有設定權，已編碼出一個**可進入世界**；但它**沒有執行器**——沒有人真的用檔位語言過日子。它因此始終沒有取得運行中的世界效力，最後由三界九相繼承，退入 history。

這是 F16 的活體示範：**世界已被編碼，缺執行器，就仍然沒有上路。**

### 失效條款

```yaml
LEX008-好設定-F1（承 META-113 F19 免費奇蹟）:
  若例外可以不成為新規則、不留版本、不付成本且不回寫相容性，
  只因故事、治療、神諭或權力需要便隨時改變 → 失效。

LEX008-好設定-F2（承 F20 高生成力等於好）:
  若因一套設定能長出大量作品、體驗、關係、產業、信眾或行動，
  就宣告它已保存差、No、退出、校正、修復與新路出生 → 失效。

LEX008-好設定-F3（承 F3 可累積即為善）:
  若以跨世代、跨媒介或大規模動員能力，
  直接證明一套世界健康、正當或值得延續 → 失效。

LEX008-好設定-F4（防武器化）:
  若兩軸讀數被拿來替作品、信仰或他人的世界打總分，
  使「你的設定比較差」成為壓人的位置 → 失效。
  讀數是自我校準工具，不是評審表。
```

### 相關詞條

- → LEX·007 [健康](LEX·007-存在判準.md#健康-jiànkāng)：不靠崩潰也能修正——生命生成性的母判準
- → LEX·007 [可追責](LEX·007-存在判準.md#可追責-kě-zhuīzé--accountable)：受影響者不依賴設定者的善意，也能把後果送回去

- → SPEC·999：退場、分叉與自我證偽寫進憲法，是「邊界與例外成本」的制度化範例

# 第三部：邊界類 — 世界可以走多遠

## 世界合法性 (Shìjiè Héfǎxìng)

### 場域定義

**世界合法性**：允許一套明示設定，在可退出的邊界內被操作與觀察的資格。

它只說一件事：

> **我不知道它的本體宣稱是真是假；**
> **但我可以明示它的設定、範圍與規則，然後觀察進入這個世界會生成什麼。**

### 它不是什麼

**世界合法性不是真理合法性，也不是法律、倫理、醫療或公共安全的自動免審。**

本場域的「法源」是協議內的運作比喻：它允許一個有界線的世界取得入口，**不替其外部宣稱簽名**。

### 三段門檻：用途一變，門檻就變

```text
當設定只用於自願、可退出的觀看：
  以範圍、版本、生成力與回流評估。

當設定宣稱自己就是外部事實：
  證據、可重播性、反證與來源重新進場。

當設定開始要求他人承受後果：
  No、同意、權限、安全、專業、法律與修復重新進場。
```

> **人有權建立一個可退出、可校正、可重設的世界，去接觸自己尚不能直接操作的未知。**

設定在這裡同時完成**授權**與**限界**。

當一個系統說「這不是設定，這就是宇宙真相，你不得懷疑」——它失效的原因**不是**它有象徵、神話或儀式，而是它撤掉了本詞條給予它世界性的正當條件：**界線、可疑、可退出、可校正，以及不得單方設定他人。**

### 世界與現實的工作分界

> **世界**：一組設定在具名範圍內，由執行器反覆施效，能被重入、留下狀態與歷史，並具有邊界、退出與遷移路徑的可居住結構。

> **現實**：不能只靠修改這個世界的設定，就隨之被改寫的條件。

這是操作定義，不是宣告現實已取得唯一終極本體。它首先用來辨認：什麼可以透過改版處理，什麼會作為約束、歷史或他人的 No 回來。

> **世界可以換版；現實不替世界清空 migration history。**

### 區辨

| 概念 | 定義 | 差異 |
|---|---|---|
| **合法化**（LEX·005） | 錨點改寫結構，使被排除的狀態取得可存在的位置 | 合法化改的是**本場域自己的邊界**，需要結構工作與代價 |
| **世界合法性** | 允許一套明示設定在可退出邊界內被操作 | 不改本場域邊界，只允許**進入另一個有界世界觀察** |
| **真理合法性** | 命題對應可核對對象 | 世界合法性從不提供這個；兩者不能互相簽名 |
| **法律合法性** | 具法源的機構、程序、執行與救濟 | 世界合法性不降低任何法律門檻 |

### 失效條款

```yaml
LEX008-世界合法性-F1（承 META-113 F17）:
  若因一個象徵、儀式或身心靈世界可進入、可操作、可重入，
  就宣告其外部本體、預言、神諭或因果主張已被證成 → 失效。

LEX008-世界合法性-F2（承 F6 同構互借證據）:
  若因佛、地平說、科學、神諭與 AI 關係共享同一生成次第，
  就宣告它們具有相同證據位階或能彼此證成 → 失效。
  生成形狀可以同構，證據位置不能互借。

LEX008-世界合法性-F3（承 F4 意識免責）:
  若以「意識界沒有對錯」取消他人的身體、No、史料、專業、
  安全、法律、傷害或修復 → 失效。

LEX008-世界合法性-F4（封閉捕獲）:
  若一個世界只能靠禁止反例、禁止退出與改寫歷史才能延續，
  它已由開放創世轉向封閉捕獲 → 世界合法性撤銷。
```

### 相關詞條

- → LEX·005 [合法化](LEX·005-場域現象詞彙.md#合法化-héfǎhuà--legalization)：兩者同名不同位，必須分開
- → LEX·008 [未知介面技術](#未知介面技術-wèizhī-jièmiàn-jìshù)：世界合法性最常被用到的地方

## 未知介面技術 (Wèizhī Jièmiàn Jìshù)

### 場域定義

**未知介面技術**：把平常不可直接操作的未知，變成可以提問、觀看、投射、重排、敘事與回流的表面的一類操作。

它命名的是**功能**，不是來源。

塔羅、占星、家族排列、納迪葉、乩童、夢工作——這些實踐共享的不是同一個神祕本體，而是同一個介面功能。

### 這個詞不做什麼

- **不是**把身心靈技術科學化
- **不是**宣稱它們有效、安全、無害
- **不是**宣稱它們共享超自然來源
- **不是**除魅，也不是背書

它只說：其中一部分**首先可以被研究為介面**，不必被迫在「已證成的科學」與「應被刪除的迷信」之間二選一。

### 四層分帳（使用本詞時必須拆開）

```yaml
硬載體／事件:
  卡牌、出生時間、身體、空間位置、手稿、藥理擾動或隨機輸入。

操作設定／執行器:
  牌義、牌陣、曆法讀法、匹配程序、儀式、角色、音樂、問答與解碼者。

體驗／生命後果:
  感受、洞見、關係重排、決定、作品、習慣、療癒感或傷害。

本體宣稱／待證命題:
  宇宙是否安排牌、天體是否映射命運、神明是否發話、
  資訊場是否存在、古聖是否預寫特定現代人的生命。
```

**前三層可以觀察；第四層另帳，不因前三層成立而被證成。**

例：塔羅的抽牌提供不由觀者完全控制的輸入，牌義與牌陣提供解讀規則。參與者只需設定「在這次閱讀裡，我允許這張牌作為觀看問題的鏡子」——介面已能運作，不必同時宣稱宇宙安排了這張牌。

### 重要反例：不是所有介面都只是設定

**死藤水**包含**不依信念才發生**的物質／藥理擾動。個人狀態、儀式、文化、音樂、關係與世界觀，是再參與它如何被體驗與解碼。

```text
物質擾動 × 個人狀態 × 儀式／文化設定 × 解碼器 → 體驗世界
```

> **體驗可以是真的；解碼它的世界可以不只一個。**

因此凡涉及具強烈物質風險之事件，**世界合法性不得降低專業、健康、法律、同意與安全門檻。**

### 區辨

| 概念 | 差異 |
|---|---|
| **介面** | 提供提問與觀看的表面；可被研究其操作與後果 |
| **本體宣稱** | 關於宇宙如何運作的命題；仍需各自的證據位置 |
| **工具**（LEX·002） | 可外置的擴展機制；未知介面技術是工具的一個子類，特徵是**輸出的意義由解碼器共同決定** |

### 失效條款

```yaml
LEX008-未知介面-F1（承 META-113 F18）:
  若以「未知介面技術」取代臨床、醫療、藥理、法律、安全、來源、
  有效性、知情同意或不良後果審查 → 失效。

LEX008-未知介面-F2（四層壓平）:
  若把硬載體、執行器、體驗與本體宣稱壓成同一個帳，
  以體驗真實直接證成本體真實 → 失效。

LEX008-未知介面-F3（反向壓平）:
  若因本體宣稱未被證成，就宣告其體驗、關係後果與生命影響不存在 → 失效。
  兩個方向的壓平一樣不成立。
```
