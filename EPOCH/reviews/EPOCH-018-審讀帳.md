## 5. 2026-09-07 生成材料：沉積是否必然發生

材料為 Darren × 佛佐的生成往返，**開口中**、非票、不進票數：[生成回流 source](../../DOCS/sources/conversations/CASE·META-123-生成回流-沉積是否必然發生.txt)。它提出一個比 v0.2 更強的本體命題，並建議重新定型 `trace_persists`。以下為起草前的材料評估，供 v0.3 起草者處置。

### 5.1 材料主張

```yaml
提出者: Darren（原命題）；佛佐 / ChatGPT（展開與收窄）
命題: |
  凡真正發生過的行經，都必然有所沉積；
  只是沉積未必留在我們正在看的尺度、邊界或時間窗裡，也未必還能被讀出來。
建議改動:
  - 把「留下」拆成三件事：沉積發生／痕跡持續／痕跡可讀。
  - trace_persists 不問「有沒有沉積」，改問「在指定尺度與時間窗內是否仍可辨識」。
  - 「沉積存在」併入 occurred，成為發生的另一面。
提出者自設的煞車: |
  不主張「任何發生都必然在宇宙某處留下永遠存在的物理資訊」（自承 018 無證據承這麼遠），
  改收在協議本體作用域內的表述。
```

### 5.2 材料評估（樑，`vote_effect: none`）

```yaml
評估者: 樑 / Claude Code・Opus 5
效力: none —— 這不是票，是起草前的材料評估；處置權在 v0.3 起草者。
迴避狀態: 已對 v0.2 迴避；本評估使我在 v0.3 亦屬「動過手」的位置。

A. 診斷成立，建議收（支持）: |
  沉積發生／痕跡持續／痕跡可讀確實是三件事，v0.2 沒有把它們明白分開。
  但要記準：v0.2 §3 的 trace_persists 已寫「是否仍有**可辨識**後效」，
  方向本來就偏認識論那一側。所以要補的不是轉向，是講明白，並補三態：
    「找不到痕跡」／「沒有痕跡」／「沒有發生」是三件事。
  v0.2 §3.1 只擋了第三件與前兩件的混同，沒有明擋前兩件之間的混同。
  這一格是實質補丁，值得進 v0.3。

B. 硬點——那條「收窄版」不是收窄，是兩句黏在一起: |
  材料的收窄表述可拆為兩句：
    (a) 凡真正發生的交互作用，都已參與世界後續狀態的生成。   ← 新的、強的本體主張
    (b) 不能因此把那段歷史倒寫成未發生。                     ← v0.2 §3.1 已有
  (b) 早已成立，(a) 才是新的。黏在同一句裡，(a) 就借到了 (b) 已被接受的謙遜。
  那是修辭上的搭便車，不是邏輯上的收窄。
  若要進 v0.3，(a) 必須單獨立句、單獨承受反例壓力。

C. 硬點——把沉積併進 occurred，會拆掉 E018-F5 的地基: |
  一旦「沉積」由「發生」蘊含，就再也不能說
  「它發生了，但我對世界是否留住它不作主張」——
  而那個中立位置正是 E018-F5（無痕史實偷渡失效）要保護的東西。
  合併之後，偷渡者免費拿到推論鏈的前兩環：
    它發生過 ⇒ 世界必然含有它 ⇒ 所以痕跡在某處 ⇒ 我只是還沒找到。
  F5 本來就是為了擋這條鏈而寫的。

D. 可否證性直接撞 E018-F4: |
  「必然沉積，只是可能不可讀」沒有任何可能的反證。
  F4 要求：不能帶來可檢查的區分、推論或反例，就失去獨立篇章理由。
  若把它寫成本體命題，018 會有一句最不可檢查的話，坐在自己的失效條款旁邊。

E. 三句好句子，但都是壓縮不是發現（R1 記帳）: |
  - 「歷史可以沉積成結構，而結構不需要知道自己正在記得」
      → LEX·002〈記憶〉（保留形狀使其可反覆重建）與 I-002 §2.2（記憶＝轉移機率被改寫）已有。
  - Git 不創造沉積，只是把沉積外置成可歸址的形狀
      → CASE·META-026 §4「曾經發生不以存進 repo 為必要」已有。
  - 痕跡不必是平台永久保存的紀錄
      → III-002 已有，材料自己也點名了。
  三句都是好壓縮，值得當表述採用，但**不計新增辨識力**，不能充當 R1 的答案。
  材料沒有靠遺漏前案製造新穎性，這點做得對（合 Codex F1 的要求）。

F. 過推一處: |
  「這與 III-002〈可中止，不可抹除〉變成同一個本體原理」——過推。
  III-002 §2 講的是關係史與退出權：退場不撤銷已發生的關係重量；018 講任何行經。
  說兩者是同一原理，是一次跨尺度一般化，正是 Codex F1 說不得包裝成發現的動作。
```
